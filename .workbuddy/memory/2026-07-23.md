# 2026-07-23 工作日志

## UI 视觉优化

对 SQLTeacher 桌面端进行了 UI 优化，仅改动 `src/main/resources/css/app.css` 与 `src/main/resources/fxml/SqlPractice.fxml`，不破坏现有结构。

### 改动清单

1. **按钮层级** — SqlPractice 页"清空"按钮原用 `sql-execute-button`（主色渐变），新增 `.sql-secondary-button` 幽灵描边样式并更新 FXML 引用，使"清空"为次要操作、"执行 SQL"为主操作，层级清晰。

2. **表格交互** — `.result-table .table-row-cell` 新增 `:hover` 悬浮高亮（蓝紫淡色），选中态改为渐变高亮；表头渐变加深并加微光晕。

3. **导航间距** — `.top-nav .nav-button` 内边距从 `7 10` 调整为 `7 14`，缓解 10 个导航项的拥挤感；选中态增加微弱 dropshadow 光晕。

4. **输入框聚焦** — 为 connection-form / exercise-form / analytics-filter-bar / knowledge-split 的 text-field / text-area / combo-box 统一添加 `:focused` 蓝紫描边 + 透明焦点环；SQL 编辑器聚焦时底色微提亮。

5. **列表悬浮** — connection-list / exercise-list 的 list-cell 新增 `:filled:hover` 淡蓝紫高亮。

6. **卡片深度** — home-card / progress-card / panel-card 悬浮时边框提亮、投影加深；home-card 按下态也加投影。

7. **品牌 Logo** — `.brand-logo` 增加微弱蓝紫光晕 dropshadow。

8. **CSS 注释修正** — 文件头注释原写"浅色清爽主题"与实际深色配色不符，修正为"深色精致主题"。
