# 软件著作权提交前核对清单

## 1. 申请主体与权属

- [ ] 学校法定全称与证照完全一致。
- [ ] 全部共同著作权人姓名、证件信息、排序及申请代表均已书面确认。
- [ ] 合作开发协议、项目任务书或学校成果归属文件齐备；如由代表办理，授权文件齐备。
- [ ] 开发完成日期、首次发表状态、首次发表日期和地点已经按事实确认。

## 2. 版本冻结

- [ ] 确认最终软件名称、简称、版本号均为 `SQLTeacher SQL 教学与智能练习软件`、`SQLTeacher`、`V1.1.0`，或已同步替换为学校确认值。
- [ ] 登记提交已打标签或留存提交号、完整源码压缩包和 SHA-256。
- [ ] 在冻结工作区运行 `mvn test`，保存通过记录。
- [ ] 最终安装包/app-image 已生成、可启动，且保存哈希值。

## 3. 程序鉴别材料

- [ ] 执行 `generate-source-material.ps1`，留存母版和元数据。
- [ ] 前、后各 30 页来自同一母版，程序每页不少于 50 行。
- [ ] 已检查排版后的代码无乱码、截断、重复、漏页、敏感信息和第三方代码。
- [ ] 页眉、页码、软件名称、版本号和著作权人署名一致。

## 4. 文档鉴别材料

- [ ] 说明书选取前、后各连续 30 页；不足 60 页时提交全文，文档每页不少于 30 行。
- [ ] 截图均来自冻结版软件，且不含真实学生信息、密码、API Key、令牌或内部服务器地址。
- [ ] 截图覆盖文档中实际展示的主要用户路径；如补充高风险 SQL、练习、题库、看板、知识、AI、设置或云端页面，应全部来自同一冻结版本并进行脱敏。
- [ ] AI、云端功能均明确为可选；AI 草案必须经安全校验和用户预览，不描述为模型自动执行。

## 5. 最终递交

- [ ] 申请表、程序材料、说明书、权属文件和身份证明交叉核对完成。
- [ ] 采用受理机构当期线上系统的字段和格式要求，已核对附件数量、文件格式和签章要求。
- [ ] 最终 PDF、源文件、签章件和递交回执在校内合规位置归档。
