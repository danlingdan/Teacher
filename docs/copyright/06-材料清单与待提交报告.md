## 五、当前版本的已知限制（应如实保留）

当前 Windows 打包版可以启动并进入访客模式；实际检查时，自由 SQL 执行和表结构连接提示“服务器连接缺少临时凭据，请先在设置页测试连接”。因此，本材料没有伪造查询成功或表结构加载截图。该限制不改变文档中已经实现的安全设计说明，但若要作为现场演示版本，应先在设置页完成实际数据库连接配置与测试，并在重新冻结后更新截图和测试记录。

## 六、递交前最后操作顺序

1. 申请主体补齐并书面确认第四部分的全部事实和证明文件。
2. 确认本次 `V1.1.0` 是否就是最终递交版本；如否，切换到最终提交并重新运行源程序材料生成、两份 PDF 生成和测试。
3. 在最终冻结环境运行 `mvn test`，保存测试输出；重新生成安装包并保存 SHA-256。
4. 复核两个 PDF 的软件名称、版本、著作权人署名、页码、截图和敏感信息；源程序 PDF 与软件文档 PDF 均以最终生成文件为准。
5. 在中国版权保护中心当期线上系统中按实际字段上传申请表、程序鉴别材料、软件文档鉴别材料及权属/身份证明文件，并以当期格式、签章和附件要求为准。

## 七、规则依据与边界

依据国家版权局《计算机软件著作权登记办法》第九至十二条，申请通常包括申请表、程序和一种文档的鉴别材料及相关证明文件；一般提交程序和文档前、后各连续 30 页，不足 60 页提交全文，程序每页不少于 50 行、文档每页不少于 30 行。合作开发可由全体著作权人协商确定代表办理。

- [国家版权局《计算机软件著作权登记办法》](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)
- [国家版权局《计算机软件保护条例》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/200701/t20070109_50527.html)

本报告是项目材料准备和交付清单，不构成法律意见；正式递交以中国版权保护中心当期系统、地方受理要求及申请主体真实权属文件为准。
