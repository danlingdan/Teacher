## 1. 软件概述

SQLTeacher 是面向数据库课程教学、实验练习和课后辅导的桌面应用。软件以本地优先方式提供 SQLite 演示数据库、SQL 编写与安全执行、题目闯关、确定性评测、学习记录、教师分析和课程知识检索；在用户启用网络服务时，还可使用账号、班级、任务、学习事件同步和 AI 辅助能力。

软件遵循“先分析、后执行”的原则。用户输入及 AI 生成的 SQL 均进入 Java 侧风险分析路径；AI 只生成待预览的草案和解释，不直接访问 JDBC 连接，也不能自行执行 SQL。

## 2. 运行环境与启动

- 操作系统：Windows 10 或 Windows 11 64 位。
- 开发运行环境：JDK 21 和 Maven 3.9 或更高版本。
- 正式安装包：自包含 Java 运行时，安装运行时无需用户单独安装 JDK。
- 显示环境：建议不低于 1366×768。
- 本地数据：Windows 正式版默认保存至 `%LOCALAPPDATA%\SQLTeacher`；开发环境使用项目内 `app-data`。
- 可选服务：本地 Ollama，或用户自行配置的兼容 OpenAI Chat Completions 网络 AI 服务；云端教学功能需要可用的学校部署服务。

开发环境可执行 `mvn javafx:run` 启动。首次启动时，软件会创建或迁移本地应用数据，并初始化演示数据库。若初始化失败，界面显示可理解的错误信息。

## 3. 登录、访客与角色入口

启动后显示登录入口。用户可通过邮箱和密码登录或注册学生账号，也可选择访客进入；访客数据仅保留在本机，不上传到账号。软件按访客、学生、教师、管理员等身份显示相应导航并在控制器层再次校验权限。

正式截图建议：登录入口、访客进入后的身份标签、教师身份导航、角色无权限时的提示。

## 4. 首页与自由 SQL

主窗口提供首页、自由 SQL、闯关练习、教师题库、教师看板、课程知识、AI 助手、表结构、设置与数据、云端教学等导航入口。页面在主窗口中切换，耗时操作期间显示加载状态，防止重复提交。

在“自由 SQL”页面中，用户输入 SQL 后点击执行。软件先识别语句类型和风险，再决定允许执行、请求确认或直接拦截。允许执行的查询展示列名、数据行、执行耗时及结果截断状态；语法或数据库错误转化为面向学习者的提示。

典型查询示例：

```sql
SELECT name, score
FROM student
WHERE score >= 60
ORDER BY score DESC;
```

正式截图建议：自由 SQL 初始页、查询成功结果、空结果或语法错误、结果行数限制提示。

## 5. SQL 风险分析与确认

软件根据语句类型、语法结构和禁止规则给出风险等级。只读查询通常可直接执行；数据修改和结构修改需要明确确认；多语句及禁止操作默认拦截。风险分析用于教学和操作提示，不能替代真实数据库的权限、备份和审计机制。

当前主要规则包括：默认阻止一次执行多条 SQL；默认阻止 `DROP DATABASE`、`GRANT`、`REVOKE` 等禁止语句；对 `UPDATE`、`DELETE`、`ALTER`、`DROP` 等高风险语句展示确认信息；查询结果设置最大行数。

正式截图建议：高风险 SQL 确认对话框、禁止 SQL 拦截提示。

## 6. 表结构与数据库连接

“表结构”页面展示当前数据库的表及字段，包含表名、列名、类型、可空性和主键标记。该信息可辅助学习者理解演示数据，并可作为 AI 生成 SQL 时的受控上下文。

“设置与数据”中的数据库连接页允许维护非敏感连接配置，并可对 SQLite、MySQL、MariaDB 连接进行测试。密码仅用于本次连接测试，不作为长期配置保存。真实外部数据库应使用最小权限账号，并由用户独立复核所有修改操作。

正式截图建议：表结构浏览页、数据库连接配置与测试结果。

## 7. 闯关练习、题库与评测

学生可在“闯关练习”中查看题目、阅读题目说明、编写 SQL、获取分级提示并提交。每次练习使用隔离会话，系统根据题目定义的列、数据行、行序、指定行数和关键结构等规则进行确定性评测，返回通过状态、差异信息或改进建议。

教师可在“教师题库”中创建、编辑、启用或停用题目，维护知识点、难度、数据集、参考 SQL、评测规则和提示；题包支持导入和导出，导入发生冲突时整体回滚，避免产生半完成数据。

正式截图建议：学生练习页、提交评测结果、教师题库编辑页、题包导入或导出提示。

## 8. 学情看板与课程知识

“教师看板”汇总学习事件和练习进度，可按日期、题目、知识点和错误类型筛选，并支持导出 UTF-8 CSV，帮助教师识别常见困难和学习进度。

“课程知识”支持导入本地课程文档，建立 SQLite FTS5 全文索引，按关键词检索并展示来源；教师可移除不再需要的索引。导入资料和学习记录属于敏感教学数据，应按学校要求保管。

正式截图建议：教师看板筛选与导出、课程知识导入、检索结果及来源信息。

## 9. AI 助手与安全降级

AI 助手支持本地 Ollama 模型选择，也支持用户自行配置的兼容 OpenAI Chat Completions 网络服务。用户输入自然语言需求后，软件结合必要的表结构信息请求模型返回结构化内容；Java 侧随后解析 JSON、校验字段与方言、执行 SQL 风险分析，并将 SQL 以草案和教学解释形式展示。

用户必须预览草案，并将其复制或带入自由 SQL 页面后才可能执行。网络 AI 的 API Key 只驻留当前进程内存，不同步、不备份、不写入日志。当模型未安装、服务不可用、超时或输出不符合结构要求时，软件给出降级提示，手写 SQL、题目练习、统计和知识检索仍可继续使用。

正式截图建议：AI 可用状态、SQL 草案与解释、AI 不可用降级状态、风险检查结果。

## 10. 云端教学与学习同步

启用云端服务后，教师可管理班级成员、发布任务并查看班级任务；学生可加入班级并查看任务。学习事件采用幂等上传和增量下载，本地按账号标记事件所有者，访客及其他账号的事件不会上传到当前账号。退出登录后，旧令牌不能继续访问服务。

云端不可用时，本地核心教学功能不依赖云端继续运行。当前云端和网络 AI 均为可选增强，不应在申请材料中描述为离线核心功能的必备条件。

正式截图建议：云端教学页、班级成员管理、任务发布、同步结果、未登录或网络异常提示。

## 11. 版本与本地数据维护

软件在升级前自动备份本地应用与演示数据库，也支持立即备份、恢复所选备份、SQLite 完整性检查和演示数据库复原。卸载应用时默认保留用户数据，避免误删课程和学习记录。恢复操作会给出确认或状态提示，用户应在重要数据操作前保留独立备份。

正式截图建议：版本与本地数据页、备份列表、恢复确认或完整性检查结果。

## 12. 异常处理与当前限制

- 数据库初始化失败时，检查用户数据目录的写权限和磁盘空间后重试。
- SQL 语法错误时，根据提示检查关键字、列名、括号与逗号。
- 查询无结果时，检查筛选条件和演示数据。
- AI 不可用时，启动本地服务或检查网络配置，也可继续手写 SQL。
- 云端暂不可用时，使用本地练习功能，待网络恢复后再执行同步。

当前网络 AI 仅适配兼容 OpenAI Chat Completions 的 HTTPS 接口；不同厂商专用协议需要另行适配。云端服务应在正式域名和 HTTPS 环境下承载正式教学数据。AI 生成结果可能不准确，用户仍需核对表名、列名、条件和数据影响。

## 13. 总体设计与模块组成

软件采用 Java 桌面应用架构。桌面层负责 JavaFX 页面、视图模型、加载状态和用户交互；应用层定义 SQL 执行、风险分析、题目练习、学习事件、知识检索、AI、连接管理和云端协作等服务契约；领域层承载异常、练习规则和值对象；基础设施层实现 SQLite/JDBC、Ollama、网络 AI、配置、日志和 Spring 装配；云端服务实现账号、角色、班级、任务和同步接口。

模块依赖遵循“桌面层调用应用层，基础设施层实现应用契约”的方向。JavaFX 控制器不直接操作 JDBC 连接；业务对象不依赖 JavaFX、文件系统或模型服务。该设计使 SQLite、外部数据库和 AI 服务发生故障时，界面可以返回可理解的状态，而不是暴露底层堆栈。

主要模块包括：

- `com.sqlteacher.desktop`：JavaFX 启动器、FXML 控制器、页面、全局加载和视图模型。
- `com.sqlteacher.application`：稳定服务契约、请求/结果 DTO、用例编排。
- `com.sqlteacher.domain`：练习规则、值对象、领域异常和核心约束。
- `com.sqlteacher.infrastructure`：SQLite、JDBC、AI、配置、日志、Spring 与运行环境适配。
- `com.sqlteacher.server`：可选云端教学服务及账号、班级、同步相关实现。

## 14. 关键处理流程

### 14.1 SQL 执行流程

用户在自由 SQL 或练习页面输入 SQL 后，控制器将请求提交给应用服务。应用服务先调用风险分析，根据语句类型、多语句、禁止规则和高风险规则决定允许、确认或阻止；通过校验的请求才由 JDBC 执行服务访问当前数据库；结果被映射为列、数据行、耗时或面向学习者的错误信息，随后记录执行或拦截事件并回到界面展示。

该流程保证 SQL 风险检查位于数据库执行之前。用户确认高风险 SQL 仅表示其确认当前操作，不改变数据库实际权限；被禁止的语句不能通过 AI 输出、自由输入或多语句拼接绕过风险规则。

### 14.2 AI 辅助 SQL 流程

用户输入自然语言需求后，软件收集必要的表结构信息并向本地 Ollama 或兼容网络 AI 服务请求结构化输出。模型输出作为不受信任输入先经 JSON 解析、字段校验、数据库方言与 SQL 风险分析，再以 SQL 草案和教学解释形式返回。用户须在界面预览草案，并带入自由 SQL 页面后再次执行风险分析和必要确认。

模型服务不可用、模型未安装、响应超时或输出格式错误时，应用返回降级提示。降级不影响手写 SQL、题目评测、统计、知识检索和本地数据维护。

### 14.3 学习事件与云端同步流程

本地学习事件带有账号所有者标记。已登录用户发起同步时，软件仅选择属于当前账号的事件进行幂等上传，并按版本号执行增量下载；访客事件和其他账号事件不会上传到当前账号。云端按登录身份、角色和班级成员关系控制班级、成员和任务访问，退出后旧令牌无法继续访问。

## 15. 数据设计与安全设计

本地应用数据保存应用事件、题目、练习进度、连接配置、知识索引和备份元数据；教学演示数据保存在独立 SQLite 演示数据库。升级前自动备份，恢复前执行 SQLite 完整性检查，演示库可单独复原。运行期数据、日志、导出文件和本地数据库不纳入源程序鉴别材料。

软件不长期保存连接测试密码；网络 AI 的 API Key 只驻留当前进程内存，不同步、不备份、不写入日志。截图、测试数据、导出文件和问题反馈均应进行脱敏，避免出现密码、令牌、学生姓名、邮箱、学号、生产服务器地址或未授权课程资料。

## 16. 测试环境、结果与已知限制

登记基线的阶段验收环境为 Windows 11、JDK 21、Maven，以及阿里云 ECS Ubuntu 24.04、OpenJDK 21、Nginx。阶段验收记录显示 `mvn test` 共 237 项通过，0 失败、0 错误、0 跳过；Windows app-image 与压缩包生成成功，打包后的 `SQLTeacher.exe` 启动 5 秒未提前退出。

已覆盖的验证包括 SQLite 初始化、JDBC 查询结果映射、SQL 风险分类、多语句与禁止语句拦截、AI 输出解析和降级、题目评测、学习事件记录、知识检索、备份恢复、FXML 资源、角色授权、班级任务、学习事件幂等上传与增量下载。云端测试入口仅用于联调；正式学生数据必须在配置正式域名和 HTTPS 后使用。

当前打包版在未提供服务器临时凭据时会在自由 SQL 和表结构页显示连接提示。这是受控错误状态，不应通过填写真实密码来制作软著截图。登记文档中使用访客模式的登录、首页与自由 SQL 页面截图，并对外部连接成功、真实学生数据、网络 AI 密钥和生产服务器信息保持脱敏或不展示。
