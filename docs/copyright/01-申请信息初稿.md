## 二、软件用途和适用对象

SQLTeacher 是面向数据库课程教学、实验练习和课后辅导的 Java 桌面软件。软件将安全 SQL 练习、题目管理与自动评测、学习过程记录、教师学情分析、本地课程知识检索和 AI 辅助 SQL 草案整合在同一应用中；可选云端功能支持账号、班级、任务和学习事件同步。

主要适用对象为高等院校、职业院校的数据库课程学生与教师，以及在本地环境练习基础 SQL 的学习者。

## 三、主要功能

1. 自动初始化本地 SQLite 应用数据库和教学演示数据库，支持本地备份、恢复和演示库复原。
2. 展示数据库表、字段、类型、可空性和主键信息，并支持受控的 SQLite、MySQL、MariaDB 连接配置与测试。
3. 接收 SQL 输入，限制查询结果数量，展示结果列、数据行、耗时和可理解的错误状态。
4. 对查询、数据修改、DDL、多语句和禁止语句进行风险分析；高风险操作要求用户确认，多语句及 `DROP DATABASE`、`GRANT`、`REVOKE` 等默认拦截。
5. 提供教师题库维护、题包导入导出、分级提示、隔离练习会话和确定性 SQL 评测。
6. 展示学习进度和教师学情，支持按日期、题目、知识点、错误类型筛选并导出 UTF-8 CSV。
7. 导入本地课程知识文档，建立 SQLite FTS5 索引，提供检索、来源展示和索引删除。
8. 调用本地 Ollama 或兼容 OpenAI Chat Completions 的网络服务，根据自然语言生成 SQL 草案与解释；AI 输出经 Java 侧 JSON 解析、方言校验和 SQL 风险检查后才可供用户预览。
9. 在本地 AI、网络 AI 或云端不可用时，保持 SQLite 练习、题目评测、统计和知识检索等核心本地功能可用，并给出降级提示。
10. 提供账号登录、访客模式、学生/教师/管理员权限、班级成员与任务管理，以及学习事件的幂等上传和增量下载；网络 AI 的 API Key 仅保留在当前进程内存。

## 四、技术特点

软件以 Java 21、JavaFX 和 FXML/CSS 构建桌面端，以 Spring Context 组织服务依赖，使用 JDBC 访问 SQLite、MySQL 和 MariaDB，使用 Jackson 解析 AI 结构化输出，使用 SLF4J/Logback 记录运行日志。代码按应用、领域、基础设施、桌面界面分层。AI 模型不直接持有 JDBC 连接，所有 SQL 均进入 Java 侧风险分析及用户确认路径。
