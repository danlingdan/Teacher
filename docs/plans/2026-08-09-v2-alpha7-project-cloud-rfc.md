# v2.0 alpha.7 项目学习与 Cloud 2.0 RFC

> 目标版本：`2.0.0-alpha.7`

## 决策

- `PROJECT` 成为通用活动类型；自动评价器只检查版本、里程碑、证据摘要和反思，不替代教师量规评审。
- 项目 artifact 不包含源码、仓库地址或凭据；成果档案按当前 owner 查询，只导出证据哈希和最小评价元数据。
- 课程包使用格式 2 信封：许可、包标识、课程版本、原始 payload 与 SHA-256；导入前必须服务端预检并确认许可。
- Cloud 2.0 先协商能力，再同步限定聚合类型的最小摘要；操作号和聚合版本共同形成幂等与冲突门禁。
- 旧事件同步和 v1.4 课程 API 保持兼容；Cloud 2.0 不改变生产 URL，也不要求项目公开托管。

## 拒绝条件

- 未知活动/包格式、超限包、摘要包含源码/路径/凭据字段、许可未确认、预检后哈希改变；
- 操作号复用、陈旧版本、版本断层；
- 非教师课程包操作，或跨 owner 作品集读取。

## 完成门禁

项目成功/失败评价、版本化提交、本人作品集、课程包篡改/许可/冲突/幂等、Cloud 能力协商/重复/冲突/隐私字段拒绝均需自动化覆盖。
