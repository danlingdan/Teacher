# SQLTeacher 2.1 目标驱动数据库学习计划

> 制定与完成日期：2026-08-09
>
> 实施基线：`2.0.1`
>
> 状态：已按小版本一次性交付

## 决策

2.1 是功能小版本，不采用 Alpha、Beta、RC 分段流程。版本直接完成一个可验证的本地纵向闭环；大版本再使用完整成熟度门禁。

本版本参考 [SQL Teacher Web 项目](http://8.130.47.235:5173/) 的任务卡片、引导/直接辅助、需求建模和网页数据练习，但继续使用现有 JavaFX 应用壳和 SQL 安全链。参照站点只用于体验取样，不作为架构或安全依据。

## 已完成范围

1. 新增“数据库学习”聚合入口，访客也能在本地使用。
2. 提供“SQL 应用开发”“数据库设计”“公开数据整理”三类目标；每类目标引用当前课程地图中的真实活动，不制造静态完成进度。
3. 提供学生选课、电商订单、图书借阅三个确定性建模示例，输出表职责和 DDL 草稿。
4. AI 助手提供“教学引导”和“直接草稿”两种反馈方式；两种方式共用 `Nl2SqlSafetyService`，均不能直接执行 SQL。
5. 公共数据练习复用 `SafeWebContentFetcher`：只允许公开 HTTP(S) 地址，拒绝本机、私网、过大响应和不支持的内容类型。
6. 数据预览最多 50 行、16 列、单元格 256 字符；只生成最多 25 行的单条 `INSERT` 草稿，并送入实验工作区继续检查。

## 明确边界

- 不新增数据库 schema、Cloud API 或云端服务部署。
- 不保存网页原文、数据库凭据或学生私人数据。
- 不从网页直接写库，不生成 `UPDATE`、`DELETE` 或 DDL。
- 建模草稿不自动执行；未知需求要求学生补充信息，不猜测表结构。
- 不迁移到 Electron、React 或其他桌面技术栈。

## 验收

- 三类目标能够打开当前课程中的真实活动。
- 三个建模示例生成可审查 DDL，未知需求不生成 SQL。
- 教学引导和直接草稿只改变提示组织，不改变风险分析与执行边界。
- 公开 CSV/文本可形成有界预览；非法目标表名不能生成草稿。
- 新页面 FXML、导航权限、中英文资源和完整 Maven 测试通过。

## 后续候选

可编辑关系图、任意 HTML 表格/JSON 结构化解析、草稿恢复、教师阶段视图和事务化导入不属于 2.1；应根据真实教学使用反馈另行决定，不在本小版本中预埋 schema 或云端合同。
