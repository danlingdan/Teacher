# SQLTeacher v2.0.1 教学文案整顿计划

> 状态：已完成
>
> 基线：v2.0.0

## 目标

2.0.1 聚焦用户可见文字，不改变活动类型、课程结构、评测规则、数据库 schema、Cloud API 或安全边界。界面应围绕学习任务、教学操作和可执行反馈组织，不再向学生展示产品内部的软件设计原则。

## 范围

- 重写首页、课程地图、实验工作区、答题检查、模拟活动和教师内容管理中的内部实现术语；
- 同步维护简体中文与英文资源；
- 区分“课程正在教授的专业术语”和“产品实现细节”，前者保持准确；
- 为主教学流程增加文案回归检查，并形成长期维护规范；
- 审计控制器动态提示、主教学流程空状态和错误信息，并保留课程本身需要教授的专业术语。

## 边界

- 不以文案调整改变 SQL 或本地代码运行责任、安全确认和权限行为；
- 不重写历史发布说明与历史计划；
- 本计划不包含发布、Git 标签、GitHub Release 或生产部署。

## 验收

- 主要学生流程能直接说明任务、操作、结果与下一步；
- 教师流程优先使用课程目标、学生提交和反馈语言；
- 中英文键集合一致，FXML 引用完整；
- 聚焦测试及完整 Maven 测试通过。
