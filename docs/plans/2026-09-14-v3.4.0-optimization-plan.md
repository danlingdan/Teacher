## 1. 目标与范围

v3.4.0 定位为"质量版本"而非功能版本，四个目标：

1. **解决 bug**：消除探索发现的正确性与健壮性缺陷，含一项 v3.3.4 未闭环的生产事故跟进。
2. **代码质量与可维护性**：拆分上帝类、收敛跨端重复、补齐前端工程化底座，让后续功能版本有可施工的起点。
3. **清理老版本兼容妥协**：先做一次"最低支持升级起点"战略决策，再按风险分层移除妥协代码。
4. **规范文档**：修正 v3.1.0 以来积累的"现状 vs 文档"漂移，把发布状态回写固化为流程。

### 明确不做

- 不做用户可见新功能；不改 SQL 安全边界（本版只补防御性测试，不放宽策略，多语句/高危确认门/FORBIDDEN 语义维持 v3.3 表述）。
- 不做需跨桌面+云协同设计的积压项：学习队列 N+1 批量端点、interventions 分析批量化、干预状态机产品规则（建议 v3.5.0+，见第 7 节）。
- 不引入 PR 工作流或成员所有权边界（维持单开发者 `main` 直提）。
- 不做 Monaco 体积优化与 CDN loader（收益/风险比一般，挂起待定，见第 7 节）。
