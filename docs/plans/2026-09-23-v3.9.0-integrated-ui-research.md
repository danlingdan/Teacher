# 2026-09-23 v3.9.0 一体化界面调研

> 性质：规划输入，不代表功能已实现。代码基线：`main` @ `cf0d586`，`pom.xml` 与
> `ui-web/package.json` 均为 3.8.0，最新本地标签 `v3.8.0`。本次为代码、文档与公开设计规范调研；
> **尚未运行打包客户端、采集新截图或开展真实用户访谈**。实施前须补齐这些观察。

## 1. 调研问题与方法

用户希望 3.9.0 “全面一体化、优化改进 UI”。这里把“一体化”解释为：学生、教师在同一桌面壳内，
沿“找到任务 → 打开正确对象 → 完成操作 → 看见结果/下一步”的路径连续工作；视觉、状态、文案与
键盘交互遵守同一套规则。是否重组七个主入口，应由任务走查与用户验证决定，不能仅凭页面数量。

核对了 [3.8.0 调研](2026-09-21-v3.8.0-account-ui-research.md)、
[3.8.0 计划](2026-09-21-v3.8.0-account-ui-plan.md)、[发布说明](../releases/v3.8.0.md)、
[能力基线](../guide/00-capability-overview.md)、当前 `ui-web` 路由、页面、样式、组件和 E2E。
旧调研中的文件行数和“缺口”只代表当时版本；下表以当前代码复核。

## 2. 当前产品与界面证据

| 维度 | 已确认的 3.8.0 基础 | 3.9.0 需要验证或改进的点 |
| --- | --- | --- |
| 结构 | `ui-web/src/App.tsx` 有今天、课程与知识、练习与实验、数据与 SQL、教学空间、班级与云端、设置七个主路由；教师路由有 `RoleGuard`。 | 学生与教师任务跨页面时，入口名称和下一步是否清楚，尚无 3.8.0 任务完成数据。先测任务，再决定是否调整导航分组；不得用隐藏教师入口替代 Java 权限检查。 |
| 找到对象 | `paletteSearch.ts` 可搜页面、题目、知识文档、班级、连接，并生成对象深链；知识、练习、班级、连接页面已读取部分 URL 参数。 | 深链规则分散在各页；`actionRoute.ts` 的 `COMPLETE_ASSIGNMENT`、`REVIEW_FEEDBACK` 只返回 `/cloud`。实施核对又发现 `HomeApiSection.homeSummary` 只输出本地诊断，这两类云端动作**当前不会出现在今天页**；已装配的 `StudentLearningQueueService` 未接桌面桥。应先决定云端队列的独立加载路径，再设计目标、回退与权限契约。 |
| 学习流程 | 今天页有下一步动作；练习页有 SQL、活动、自由编程、错题本四个模式；知识页可跳文章。 | 需实测“今天/知识 → 指定活动 → 提交/诊断 → 返回相关知识或下一步”，特别是离线、空内容、无匹配知识点、草稿与浏览器后退。避免重做判分和学习状态。 |
| 教师流程 | `TeachingPage.tsx` 管本机题库、学情；`CloudPage.tsx` 管班级、任务、提交反馈，另有账号中心。 | 教师需在本机题库、班级任务、学生画像和反馈间切换；两个入口的边界及上下文保持需要任务走查。教师数据必须继续按角色、班级和服务端权限校验。 |
| 状态与设置 | `shared/ui` 已有 Button、Dialog、ConfirmDialog、Loading、EmptyState、Feedback；3.8.0 统一了确认交互、图标和部分原语。`SettingsPage.tsx` 与云端页都有同步偏好入口。 | 同一偏好的读写缓存和保存反馈是否一致，需要核对；加载、空、离线、失败、权限不足的文案与可执行下一步要按页面盘点。重复入口可保留，但含义与状态须一致。 |
| 视觉与布局 | `App.css` 约 4009 行，有主题、对比度、紧凑密度、减少动效、间距/圆角 token；Tauri 窗口默认 1280×800，最小 960×640。 | CSS 仍以一个大文件维护，存在后置覆盖；`html/body/#root` 最小宽 960px。需按**实际窗口内容区**与缩放测可用空间，检查横向滚动、遮挡、焦点和表格/编辑器布局。不能仅由 CSS 静态检查宣称视觉问题已修复。 |
| 语言与可访问性 | 现有 axe 组件测试和打包态桌面 E2E；`uiI18n.ts` 是运行时 DOM 文案替换。 | [积压清单](backlog.md)已记录新增面板英文覆盖缺口。若保留英文模式，关键任务文案应改为显式 key，不能再依赖 DOM 文本碰巧匹配；需手动检验键盘、焦点与屏幕阅读器。 |

当前大页面规模可作为维护风险线索，而非用户体验结论：`CloudPage.tsx` 1486 行、
`SettingsPage.tsx` 1340 行、`KnowledgePage.tsx` 1075 行、`DataSqlPage.tsx` 1032 行。
拆文件只有在能降低任务改动冲突和回归风险时才有价值。3.8.0 留存的 UIX-1 CSS 归位、
UIX-5 页面拆分、UIX-6 中宽走查、UIX-7 仪表盘精修，需要先复核现状，再按用户价值纳入 3.9.0；
它们不是“已交付”的 3.9.0 能力。

## 3. 外部设计依据与适用边界

| 来源 | 可借鉴的原则 | 对 SQLTeacher 的推论 |
| --- | --- | --- |
| [Microsoft Windows 导航基础](https://learn.microsoft.com/en-us/windows/apps/design/basics/navigation-basics)、[NavigationView](https://learn.microsoft.com/en-us/windows/apps/design/controls/navigationview) | 顶层导航要稳定、清楚；窗口变窄时可调整侧栏占用。 | 保留稳定的主目的地，对 960–1280px 内容区验证折叠方案；不能直接照搬 WinUI 控件或其断点到 React/Tauri。 |
| [Microsoft 窗口断点指南](https://learn.microsoft.com/en-us/windows/apps/design/layout/screen-sizes-and-breakpoints-for-responsive-design) | 断点按应用**窗口**而非显示器尺寸确定。 | 以 960×640、1280×800、1366×768 内容区及 125%/150% 缩放实测布局，按内容失效点定 CSS 断点。 |
| [Carbon 空状态模式](https://carbondesignsystem.com/patterns/empty-states-pattern/) | 区分首次无数据、筛选无结果和系统错误，给出与当前任务相关的下一步。 | 统一状态词汇，但各页须根据真实操作提供动作；“暂无数据”不能覆盖加载失败或权限不足。 |
| [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/)、[ARIA APG](https://www.w3.org/WAI/ARIA/apg/about/introduction/) | 重排、焦点可见/不被遮挡、键盘可操作与控件语义需要验证；APG 提供交互模式建议。 | 把自动 axe 与人工键盘走查结合；WCAG 具体准则以适用等级和例外核对，不能仅凭 axe 零告警宣称整体合规。 |
| [GOV.UK 逐步导航模式](https://design-system.service.gov.uk/patterns/step-by-step-navigation/) | 只有存在有用顺序的任务才适合显式步骤。 | 学习路径、作业闭环可用“当前/下一步”提示；自由 SQL 工作台和探索性阅读不应强制向导化。 |

这些来源提供设计判断，不是本产品用户研究，也不证明某种风格会提高学习成效。

## 4. 优先验证的任务与研究缺口

1. **学生初次使用**：离线打开课程、找一篇知识文档、做指定练习、看结果并回到相关知识；记录误入、
   无数据和环境缺失时能否继续。
2. **学生有班级任务**：从今天/通知进入指定作业，完成或查看教师反馈；核对 URL、后退、登录返回、
   离线队列及不同账号切换时的上下文。
3. **教师日常**：找到指定班级与作业、查看本班学生提交、给反馈并确认学生端可见；本机题库与云端
   任务的边界要用真实流程说明。
4. **数据与 SQL**：选择连接、看表结构、写查询、理解风险确认和结果；无连接、连接失败、权限不足
   时提供准确的下一步。不得改变 Java SQL 风险/执行路径。
5. **跨页面系统状态**：账号、同步、更新、组件/工具链和设置的状态与错误说明一致；验证已有
   [winget 缺失](2026-09-21-component-install-winget-unavailable-findings.md)和
   [悬空 junction](2026-09-21-toolchain-junction-crash-findings.md)诊断所述问题是否仍可复现。

建议用同一组匿名/合成夹具做学生、教师、未登录三种身份的基线走查；记录任务是否完成、错误路径、
误点/返回次数、完成时间和截图。没有基线前，计划中的数量阈值仅是**拟定验收门槛**，
不能写成已测得的现状。公开教育产品的旧调研可参考，3.9.0 的具体取舍以上述本产品任务证据为准。

结论与执行安排见 [v3.9.0 计划](2026-09-23-v3.9.0-integrated-ui-plan.md)。
