# SQLTeacher v1.5.5 UI Foundation 2.0 计划与实施记录

> 制定与实施日期：2026-07-29
> 基线：`v1.5.0`
> 目标版本：`v1.5.5`

## 1. 目标

在不修改 SQL 安全、应用服务、数据库、AI 或云端权限边界的前提下，解决 v1.5.0 遗留的单体 CSS、固定侧栏、页面密度漂移、首页卡片不换列、SQL 结果需要长距离滚动和焦点状态不稳定问题。

## 3. 技术边界

- 保留 Java 21、JavaFX 21、FXML、Spring Context 和现有控制器注入方式。
- AtlantaFX 仅负责标准控件基础皮肤；SQLTeacher 语义 CSS 在其上覆盖。
- 响应式模式只根据 Scene 可用宽度改变表现，不持久化窗口内容或用户数据。
- 不引入 WebView、Node.js、Electron、Tauri、Kotlin 或新的本地服务。
- 不修改 SQL 执行、风险确认、AI 草案、连接凭据或云端鉴权流程。

## 5. 验证矩阵

- 自动化：断点分类、偏好持久化、FXML XML 完整性、CSS/FXML 资源契约。
- 桌面：登录页、访客首页、SQL 工作区；检查启动异常、样式解析警告、导航、编辑器、结果区和焦点。
- 回归：完整 `mvn test`，确保 SQL 安全、权限、同步、迁移和既有桌面资源无回归。
- 打包：`package-stage1.ps1` 生成 v1.5.5 EXE、ZIP、app-image 和 SHA-256；ZIP 验证包含 AtlantaFX 且不含运行数据或秘密目录。

## 6. 已知限制

- JavaFX 不提供网页媒体查询，断点由根节点样式类和少量 Java 布局状态实现。
- v1.5.5 优先完成应用壳、首页和 SQL 核心流程；其他页面立即获得现代标准控件、语义颜色和焦点基线，但复杂页面的结构性重排继续按页面逐步完成。
- Windows 125%/150% 缩放需要在对应显示设备上继续观察；本次自动化不会用像素截图作为唯一通过依据。
