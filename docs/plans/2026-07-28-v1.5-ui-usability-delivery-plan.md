# SQLTeacher v1.5.0 UI 与易用性升级计划

> 制定日期：2026-07-28
> 发布基线：`v1.4.0`
> 建议周期：6 个单人串行阶段
> 版本定位：桌面信息架构、核心工作流与可访问性升级版

## 1. 版本目标

v1.5.0 不扩展新的教学业务边界，而是把 v1.4.0 已有能力整理成更容易理解、更少跳转、更不容易误操作的桌面产品。

本版本完成后，学生应能快速进入练习、理解当前状态并完成运行与提交；教师应能沿着“课程 → 题目 → 任务 → 提交 → 反馈”的连续工作流完成教学操作；所有角色都应获得一致的导航、字体、图标、主题、表单、加载、空状态、错误、确认和快捷键体验。

UI 提升以可测量的任务效率和可访问性为准，不以单纯更换配色、堆叠动画或重写技术栈作为完成标准。

## 2. 当前基线与主要问题

当前桌面端已有 16 个 FXML 页面、16 个控制器和约 1700 行全局 CSS，功能覆盖完整，但随着版本增长出现以下问题：

- 顶部横向导航包含 11 个入口，需要横向滚动，角色主任务和低频工具处于同一层级。
- 页面命名、按钮层级、表单密度和状态提示不完全一致，用户需要重新学习每个页面。
- “课程协作”等复杂页面采用长滚动表单，课程、题目、任务、反馈和通知同时出现，当前上下文不清晰。
- 加载、失败、空数据、离线、保存成功和权限不足缺少统一组件与文案规范。
- 部分页面使用固定宽高；1366×768、125%/150% Windows 缩放和低高度窗口需要系统走查。
- 焦点样式、键盘顺序、快捷键、可读对比度和屏幕阅读提示尚未形成统一验收标准。
- 单一 CSS 文件持续增长，设计值和组件状态重复，后续修改容易造成页面间漂移。
- 当前 UI 主要依赖微软雅黑/Segoe UI 系统回退，不同字号和字重在深色背景上的观感与对比度不稳定；图标缺少统一来源、尺寸和语义规范，部分位置仍以文字或色块代替图标。
- 当前只有固定深色主题，用户不能切换浅色、深色或跟随系统主题，也不能调整界面字号/密度。
- `SETTINGS` 页面级能力目前只授予教师和管理员，学生与访客无法进入个人外观、字体等通用设置；权限粒度与设置项的真实风险不匹配。

## 3. 成功指标

发布前以固定演练脚本记录 v1.4 基线和 v1.5 结果，至少满足：

| 指标 | v1.5.0 目标 |
|---|---|
| 学生进入最近任务 | 登录后不超过 2 次主要操作即可打开最近未完成任务。 |
| 学生运行并提交 SQL | 主操作始终可见；运行、风险确认、提交的状态和结果不会混淆。 |
| 教师发布任务 | 从课程入口开始，课程/题目上下文不丢失；不需要在无关页面间往返。 |
| 教师查看提交并反馈 | 从待处理列表到发布反馈不超过 3 次主要操作，并能返回原筛选位置。 |
| 状态反馈 | 所有后台操作立即进入可见的忙碌状态；成功、失败、空数据和离线状态有明确下一步。 |
| 键盘可用性 | 核心流程无需鼠标即可完成；焦点可见、顺序稳定、快捷键不与文本输入冲突。 |
| 显示适配 | 1366×768、1920×1080，以及 Windows 125%/150% 缩放下无关键操作被遮挡。 |
| 字体与图标 | 中文、英文、数字和 SQL 代码层级清楚；无缺字/乱码；图标风格、尺寸、对齐和状态一致，并配有文本或提示。 |
| 主题 | 浅色、深色、跟随系统三种模式可即时切换并持久化；核心页面在每种主题下达到可读对比度要求。 |
| 设置权限 | 访客、学生、教师和管理员均可打开设置页；无权修改的设置项按策略禁用或隐藏并说明原因，后端敏感操作继续强制鉴权。 |
| 回归质量 | v1.4 的 SQL 安全、权限、离线、迁移和云端契约测试全部通过。 |

### 4.3 明确不纳入 v1.5.0

- 不新增正式考试、监考、排名、计费、多租户、移动端或 Web 端。
- 不重写为 Electron、Compose、WebView 或其他 UI 技术栈；继续使用 Java 21、JavaFX、FXML 与 CSS。
- 不为视觉效果修改 SQL 安全、权限、任务快照、反馈审计和离线隔离规则。
- 不引入新的云端业务模型；仅在确有必要时增加本地非敏感 UI 偏好迁移。
- 不引入重量级 UI 依赖或来源/许可不清晰的字体、图标库；字体和图标资产必须记录来源、许可、版本与包体积影响。
- 不以大规模动画、3D、复杂图表或自定义窗口边框作为主要交付物。

## 5. 信息架构目标

### 5.1 角色主入口

| 角色 | 一级入口 | 默认首页重点 |
|---|---|---|
| 学生 | 首页、我的学习、SQL 工具、课程知识、设置 | 未完成任务、最近反馈、薄弱知识点、继续练习。 |
| 教师 | 首页、教学工作台、题库与课程、学情、SQL 工具、设置 | 待处理提交、近期任务、课程快捷入口、服务状态。 |
| 管理员 | 首页、教学管理、系统运维、数据维护、设置 | 服务健康、账号/班级异常、备份与操作入口。 |
| 访客 | 首页、自由 SQL、表结构、AI 助手、设置 | 本地演示入口、连接状态和能力限制说明。 |

业务功能无权限时不显示；因登录状态变化而失去权限时，当前页安全退出并给出可理解提示。设置中心是所有角色的公共入口，页面内部再依据设置项权限决定可编辑、只读、禁用或隐藏。入口名称面向任务，不暴露内部模块名。

### 5.2 设置权限分层

| 设置域 | 访客 | 学生 | 教师 | 管理员 | 约束 |
|---|---|---|---|---|---|
| 外观、主题、字体、字号、密度、减少动态效果 | 可编辑 | 可编辑 | 可编辑 | 可编辑 | 仅保存非敏感本地偏好。 |
| 快捷键与通用易用性偏好 | 可编辑 | 可编辑 | 可编辑 | 可编辑 | 冲突时恢复安全默认值。 |
| 本人的本地数据库连接 | 可编辑 | 可编辑 | 可编辑 | 可编辑 | 凭据仍按现有本地加密/脱敏规则处理，不同步云端。 |
| 本人的缓存、日志查看与清理 | 可操作 | 可操作 | 可操作 | 可操作 | 只能处理当前设备和当前账号范围；删除前确认。 |
| 教学默认值与教师工作流偏好 | 不可用 | 不可用 | 可编辑 | 可编辑 | 非教师显示禁用原因或不显示敏感细节。 |
| 全局数据恢复、账号/班级、云端运维 | 不可用 | 不可用 | 不可用或只读 | 可编辑 | UI 权限不是安全边界，服务端必须再次鉴权。 |

页面级 `DesktopCapability.SETTINGS` 应授予全部角色；设置项权限使用独立策略对象或动作级 capability，不能继续用一个布尔值代表整个设置中心。禁止仅靠隐藏/禁用控件保护敏感操作。

### 5.3 页面布局原则

- 页面头部只包含标题、当前上下文、一个主要动作和必要的次要动作。
- 列表管理页面优先采用“导航/筛选区 + 主工作区 + 可选详情面板”，避免无限向下堆表单。
- 核心操作保持在首屏或固定操作区；低频配置折叠到详情或更多菜单。
- 选择课程、题目、任务或学生后，后续区域明确展示当前对象并保留返回位置。
- 空状态说明为什么为空，并提供当前用户有权执行的下一步动作。
- 错误信息使用学生/教师能理解的语言；诊断详情可复制，但不得暴露凭据或敏感路径。

## 6. 设计系统与实现边界

### 6.1 语义设计令牌

至少统一以下语义值，不在页面中散落重复色值和尺寸：

- 背景：窗口、导航、页面、卡片、浮层、输入区。
- 文本：主要、次要、禁用、链接、成功、警告、危险。
- 操作：主要、次要、文字、危险，以及普通/悬停/按下/焦点/禁用状态。
- 尺寸：4/8/12/16/24/32 间距阶梯、控件高度、圆角、边框和阴影。
- 排版：页面标题、分区标题、正文、辅助说明、数据与代码字体。
- 图标：导航、动作、状态、文件、角色和风险语义，以及 16/20/24/32 像素尺寸阶梯。

字体方案须分别定义中文 UI、拉丁字符/数字和 SQL 代码字体，验证正常/半粗/粗体在浅色与深色背景上的清晰度。若随安装包分发字体，必须使用允许再分发的字体文件并附许可；否则使用经过验证的 Windows 字体回退栈，不能依赖单一机器已安装字体。

图标优先使用可审计的 SVG/JavaFX 矢量资产，不使用 emoji 充当正式操作图标。仅图标按钮必须提供 tooltip、accessibleText 和清晰焦点；危险、成功、警告状态同时使用文字，不以图标或颜色单独表达含义。

JavaFX CSS 不支持网页 CSS 变量时，由构建期约定或少量语义样式类控制重复值；不得为模拟变量引入运行时字符串拼接样式。

### 6.2 代码边界

- FXML 负责结构，CSS 负责视觉，控制器只负责输入、状态绑定、导航和服务调用。
- 提取可测试的页面状态/view model，避免把筛选、校验和按钮可用性写成大量事件分支。
- 导航、对话框、提示、偏好和快捷键通过小型公共服务统一，不让页面互相直接引用控制器。
- 主题服务只切换语义样式表/根节点主题类，不在控制器中拼接颜色；切换后弹窗和已加载页面同步更新且无需重启。
- 设置中心使用页面访问策略和设置项策略两层授权；客户端负责呈现，应用服务/云端接口负责最终授权。
- 网络、数据库、导入导出和 AI 调用继续在后台执行；局部加载优先，不用全屏遮罩阻塞无关区域。
- 页面缓存必须定义刷新时机；身份切换、权限变化和账号退出时清理含用户数据的页面状态。

## 7. 六阶段单人串行计划

| 阶段 | 唯一主目标 | 主要工作 | 阶段门禁 |
|---|---|---|---|
| 阶段 1 | 基线与视觉系统 | 执行固定任务脚本；整理页面清单、角色任务地图、语义令牌、字体/图标候选与许可、组件状态、文案和显示矩阵；建立 UI 契约测试骨架。 | 基线数据和截图齐全；字体、图标、主题、P0 页面优先级、导航树和组件规范冻结。 |
| 阶段 2 | 应用壳、主题与设置权限 | 重构角色化导航、页面头部、身份/连接状态、返回路径、全局提示和偏好存储；实现浅色/深色/跟随系统主题；向全角色开放设置入口并加入设置项权限策略。 | 四类身份均可进入设置且只能修改授权项；主题即时切换并持久化；1366×768 下无需横向导航滚动。 |
| 阶段 3 | 学生工作流 | 重构首页、最近任务、学生练习与 SQL 编辑/结果区；统一快捷键、局部加载、错误恢复和提交确认。 | 学生脚本达到点击与状态目标；风险 SQL、离线和重复提交回归通过。 |
| 阶段 4 | 教师工作流 | 重构教学工作台、课程/题库、任务发布、提交列表与反馈；保留筛选、选择和返回位置。 | 教师脚本达到操作目标；版本冲突、越权、快照和反馈审计无回归。 |
| 阶段 5 | 全局一致性与可访问性 | 迁移其余页面到公共组件；完成字体/图标、表单校验、空态/错误态、键盘、焦点、缩放、三主题和文案走查。 | P0 页面通过各主题显示矩阵和无鼠标演练；无关键状态仅靠颜色或图标；无阻塞 JavaFX 线程调用。 |
| 阶段 6 | 稳定性与发布 | 修复 P0/P1 易用性缺陷；执行性能、升级、全量测试、Windows 包、课堂演练、手册和 Release 验收。 | P0 缺陷为 0；全部发布门禁通过后才创建 `v1.5.0` 标签。 |

每次只推进一个纵向页面闭环。完成组件或页面后运行聚焦测试；应用壳、学生流、教师流和发布候选完成时运行完整 `mvn test`。

## 8. 关键验收场景

| 场景 | 正常路径 | 必测边界 |
|---|---|---|
| 首次使用 | 选择身份并进入与角色匹配的首页，看到明确的第一步。 | 无网络、无模型、无课程、访客、窗口缩小、引导中断后重开。 |
| 学生继续任务 | 首页打开最近未完成任务，编写、运行并提交 SQL。 | SQL 错误、高风险确认、任务过期、断网重试、重复点击、结果列过多。 |
| 教师发布任务 | 选择课程和题目版本，核对快照并发布任务。 | 未保存编辑、无题目、停用内容、版本冲突、权限撤销和返回后上下文恢复。 |
| 教师反馈 | 从待处理提交进入详情，查看证据、生成/编辑草稿并发布。 | AI 不可用、反馈冲突、空评语、他人班级、切换学生和保存失败。 |
| 导航与身份 | 使用鼠标、键盘和快速入口切换页面，再切换身份。 | 隐藏入口、深层页面返回、加载中切换、退出后缓存清理和焦点恢复。 |
| 主题与排版 | 在设置中切换浅色、深色、跟随系统、字号和密度，当前页面立即更新。 | 重启恢复、系统主题变化、字体缺失、中文/英文/SQL 混排、禁用/焦点/弹窗颜色。 |

| 状态与恢复 | 后台操作显示局部进度，失败后保留安全输入并可重试。 | 超时、取消、重复回调、页面已离开、服务端 401/403/409/500。 |

## 9. 测试策略

### 9.1 自动化测试

- FXML/CSS 资源：全部页面可加载，fx:id、事件方法、样式类和资源引用有效。
- 导航与权限：角色入口映射、深层跳转、身份切换、返回路径和无权限降级。
- 设置权限：四类角色均可访问设置；通用偏好可编辑；教学/维护/运维项的可见、只读、禁用、执行权限矩阵；服务端拒绝伪造请求。
- 主题与偏好：浅色/深色/跟随系统切换、即时刷新、重启恢复、损坏配置回退、账号/设备作用域和敏感字段排除。
- 字体与图标资源：许可清单、字体回退、缺字检测、SVG 资源加载、accessibleText、tooltip 和无孤立 emoji 图标。
- 页面状态：加载、内容、空、离线、错误、成功、未保存和版本冲突状态转换。
- 表单：必填、长度、格式、就地错误、按钮可用性和重复提交保护。
- 快捷键：作用域、焦点冲突、危险操作确认和文本编辑兼容。
- 偏好：默认值、升级迁移、损坏回退、账号隔离和敏感字段排除。
- 回归：SQL 风险、任务快照、反馈权限、离线队列、通知和云端契约。

不把像素截图比较作为唯一自动化依据。优先测试结构、状态和行为；视觉一致性通过固定显示矩阵人工验收并保留关键截图。

## 11. 风险与裁剪顺序

| 风险 | 应对 | 工期不足时的裁剪 |
|---|---|---|
| “大提升”退化为纯换肤 | 每项 UI 变更绑定任务脚本、状态或可访问性指标。 | 保留工作流和状态改造，裁剪动效与装饰。 |
| 一次重写全部页面导致回归 | 先冻结应用壳和组件，再按学生流、教师流逐页迁移。 | 保留 P0 页面完整一致，低频页面仅迁移公共状态与导航。 |
| CSS 拆分造成级联漂移 | 使用语义样式类和资源契约测试，逐页迁移并做显示矩阵截图。 | 保留浅色/深色主题，先裁剪跟随系统的实时监听和非核心页面精修。 |
| 字体或图标资产增加包体/许可风险 | 优先评估系统回退栈和小型矢量资产；随包分发前保存许可证并扫描缺失引用。 | 不裁剪一致的排版与图标语义；可回退到合规系统字体。 |
| 多主题出现局部颜色硬编码 | 禁止业务页面直接写颜色，以三主题显示矩阵和 CSS 扫描发现遗漏。 | 跟随系统可降级为启动时读取，但浅色/深色手动切换不可裁剪。 |
| 设置页开放造成权限误解 | 页面与动作权限分层；受限项解释原因；所有敏感服务再次鉴权并测试直接调用。 | 可隐藏敏感运维详情，不得重新关闭全员设置入口。 |
| 控制器继续膨胀 | 先提取页面状态和小型导航/提示服务，再调整布局。 | 裁剪批量功能，不把新业务逻辑塞回控制器。 |
| 可访问性最后补导致返工 | 组件阶段即定义焦点、键盘、对比度和禁用状态。 | 不裁剪焦点与键盘主路径；先裁剪动画。 |
| 角色导航隐藏造成能力难发现 | 首页提供角色任务入口与搜索，设置/帮助说明权限边界。 | 保留角色首页入口，裁剪全局快速面板。 |

裁剪顺序：细节动效 → 快速入口 → 列布局持久化 → 跟随系统的实时监听 → 非核心页面视觉精修。角色导航、字体与图标一致性、浅色/深色手动主题、全员设置入口与设置项权限、学生/教师核心流程、状态反馈、键盘焦点、低分辨率适配和安全回归不可裁剪。
