# SQLTeacher 语义化 UI 主题重构记录

> 日期：2026-07-30
> 基线：v1.5.5

## 问题

旧版 `app.css` 同时承担布局、深色调色板和业务页面专属控件样式。页面级选择器的优先级高于亮色主题通用规则，导致教学工作台、题库、练习、表结构和云端页面在亮色模式中局部回退到深色背景或低对比度文字。

## 重构结果

- `foundation/tokens.css` 统一定义画布、表面、输入、文字、边框、状态表面和阴影令牌。
- `components/core.css` 保留应用壳和通用组件规则。
- `components/pages.css` 成为业务页面唯一的跨主题外观层，覆盖标准输入、列表、表格、标签页、教学工作台、练习、表结构、学情和云端页面。
- `theme-light.css` 仅保留登录页和少量确实只属于亮色主题的收尾规则。
- `app.css` 降级为旧布局基线，不再接受新的业务页面调色板规则。

## 本次修复

- 教学工作台标签内容区不再使用深色底，通知列表改为独立卡片。
- 云端状态条、账号标签和禁用内容在亮色模式下保持可读。
- 练习与题库的编辑器、列表、结果区、禁用输入和选择状态统一使用主题令牌。
- 表结构、设置、学情、课程知识和弹出列表采用同一套表面与文字层级。
- 深色与亮色共用页面规则，后续页面不再分别维护两套业务选择器。

## 对比度加固

- 明确区分主要文字、次要文字、弱化文字和禁用文字，亮色主题的文字令牌以白色表面上至少 4.5:1 为门禁。
- 直接设置 AtlantaFX 的 `-color-cell-fg` 等表格皮肤变量，避免单元格回退到旧深色主题文字。
- 禁止对整个业务容器叠加半透明禁用效果；控件逐项使用禁用背景和禁用文字，标题及说明仍保持清晰。
- 覆盖按钮、标签、输入框、选择框、列表、表格和滚动容器的禁用伪状态，消除多层 `0.4` 透明度相乘。
- 未登录云端时不再展示整屏不可操作按钮，改为清晰的登录提示；登录后暂不可用的按钮统一使用中性灰底和深灰文字。

## 验证边界

按发布负责人要求，本次由自动化资源测试和 Maven 回归验证代码与资源契约，不由开发代理启动 JavaFX 或执行视觉验收；最终显示效果由发布负责人在打包程序中确认。

## 体验与安全问题复核

根据 2026-07-30 的问题记录，本轮继续完成以下修复：

- NL2SQL 提示词从 Java 代码移至 `resources/prompts/` 并升级为 v4；允许模型生成单条 `SELECT`、`INSERT`、`UPDATE` 或 `DELETE` 草稿，再统一交给 Java 风险分析，禁止模型直接执行。
- SQL 风险规则禁止执行任何 `DROP`、`TRUNCATE`，即使用户确认也不能绕过；`UPDATE`、`DELETE` 统一标记为 HIGH 并要求明确二次确认，多语句继续禁止。
- “我的练习”扩大 SQL 编辑区，并在题目说明下展示当前数据集可用表和字段，避免学生猜测列名。
- 20 道内置题由两级提示升级为三级提示；仅自动升级未被教师修改过的 v1 内置题，不覆盖自定义题目。
- 云端任务截止时间改为日期选择器与半小时粒度时间下拉框，内部按本机时区转换为 `Instant`，不再要求手填 ISO-8601。
- 教学反馈页的班级、任务和学生筛选改为云端数据下拉选择；学生标识由系统带入，不再要求手工输入 UUID。
- 本地 Ollama 与 OpenAI-compatible 网络 AI 合并到“AI 助手”的统一模型来源卡片；网络 AI 不再出现在云端班级管理页，也不再受教师管理界面和身份入口限制。
- 两类模型共用同一 NL2SQL、提示词和 Java 风险分析链路。网络 API Key 仍只保存在当前进程内存；切回本地模型时立即清除网络配置。

自动化覆盖包括提示词资源、DML 意图、SQL 风险回归、内置题提示升级、数据集字段摘要、截止时间转换和 FXML 控件契约。JavaFX 视觉效果仍由发布负责人使用打包程序验收。
