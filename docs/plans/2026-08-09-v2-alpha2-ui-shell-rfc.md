# SQLTeacher v2.0 alpha.2 UI 2.0 应用壳 RFC

> 制定日期：2026-08-09
> 适用版本：`2.0.0-alpha.2`
> 总计划：[v2.0 计算机专业学习平台总计划](2026-08-02-v2.0-computer-science-learning-platform-plan.md)

## 目标

alpha.2 把 alpha.1 的通用活动内核变成可进入、可理解、可执行的桌面主路径：身份任务中心、课程地图、实验工作区和设置共享同一应用壳；SQL 是首个真实活动 Runner，而不是产品导航的顶层定义。

## 信息架构

应用壳固定为五个工作域：学习、课程、实验、教学和系统。`ShellRoute` 保存路由、工作域、能力和命令检索元数据，`ShellNavigationModel` 只返回当前身份可访问的路由。JavaFX 控制器继续拥有页面实例和转场，但不再单独维护另一份权限无关路由清单。

主内容顶部提供上下文栏，侧栏只表达工作域。访客保留完整离线主路径：任务中心 → 课程地图 → 实验工作区 → 设置；云端和教师页面仍按现有身份能力隐藏。

## 课程地图和工作区

课程地图只读取 schema 11 中已发布的 `course_definition`、章节、活动和知识点关系，不生成演示卡片。活动入口进入四区工作区：活动目录、Runner、活动要求、底部状态。宽屏显示上下文侧栏；低分辨率逐级折叠侧栏，保证 Runner 是首要可用区域。

alpha.2 只挂载已存在的 SQL Runner。它继续经过结构解析、风险分析、确认、限量执行和审计路径；其他活动类型没有 Runner，因此不创建可点击占位入口。

## 设计系统与可用性

- 继续使用 `foundation/tokens.css`、`components/` 和 `layouts/` 分层；新增页面只消费语义 token；
- 亮色、暗色和现有字体/密度设置即时生效；
- `Ctrl+K` 从能力过滤后的路由表建立命令入口，`Ctrl+1` 至 `Ctrl+9` 按相同顺序注册；
- 840×600 最小窗口折叠为图标侧栏，实验上下文侧栏隐藏，SQL 编辑器和执行操作保持可见。

## 边界

- 不改变 Cloud API、数据库安全策略、AI 信任边界或教师权限；
- 不在本阶段实现 Quiz、Trace、Simulation、Code 等新 Runner；
- 不以截图或静态假数据替代真实课程目录和活动定义；
- 不创建 Git 标签或 GitHub Release，除非另行授权。
