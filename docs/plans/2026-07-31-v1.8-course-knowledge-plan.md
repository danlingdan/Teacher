# SQLTeacher v1.8 课程知识体系与可追溯学习计划

> 制定日期：2026-07-31
> 发布基线：`v1.7.0` + `a5acba3`
> 目标版本：`v1.8.0`
> 实施方式：单人、六阶段串行交付
> 版本定位：将本地课程资料、云端课程结构、知识点、练习与学习诊断连接为可追溯的课程知识闭环

> 实施收敛（2026-08-01）：v1.8.0 交付桌面本地优先闭环。为避免在服务端课程知识所有权、成员授权和失效协议尚未冻结时静默上传私有全文，本版本不新增云端知识 API；跨设备发布、同步缓存和阅读状态顺延到后续独立版本。多文件批量导入替代目录递归导入，其他已交付范围见 `docs/history/stages/stage5/2026-08-01-v18-course-knowledge-implementation.md`。

## 1. 规划结论

v1.7.0 已具备本地 Markdown/TXT 文档导入与 FTS5 检索、云端课程/章节/知识点/题目版本、知识点掌握诊断、学生学习队列、教师干预队列，以及支持 `KNOWLEDGE_EXCERPT` 的 AI 上下文策略。

当前主要缺口不是继续增加孤立页面，而是已有能力之间尚未形成统一课程知识体系：

- 本地知识文档与云端课程、章节、知识点没有稳定关联。
- 学生搜索到的是孤立片段，不能稳定定位到课程目录、文章版本和原始标题位置。
- 薄弱知识点、课程资料和关联练习之间缺少直接跳转。
- 教师不能将私有素材经过预览、编排和审核后发布为不可变课程知识版本。
- AI 虽然可以接收限长知识片段，但还没有形成“有来源、有版本、有引用”的课程解释链路。

v1.8.0 定位为“课程知识体系与可追溯学习”。系统以 SQL 课程作为首个完整样板，同时保持模型可扩展到其他数据库课程。课程资料默认作为本地私有素材，只有经过教师明确预览和发布的内容才能进入课程共享范围。学生能够按课程结构浏览、检索和学习知识文章，并从薄弱知识点进入对应资料和练习；AI 只能解释经过检索和脱敏的课程片段，不得修改 SQL 安全规则、确定性评测或掌握度事实。

目标闭环：

```text
教师导入私有课程素材
→ 解析并预览课程结构
→ 绑定课程 / 章节 / 知识点
→ 人工确认并发布不可变文章版本
→ 学生浏览、检索与离线阅读
→ 从知识点进入练习
→ 从诊断薄弱项返回复习材料
→ AI 基于明确引用提供可选解释
```

## 2. 现有基线

### 2.1 已有能力

| 能力 | 当前状态 |
|---|---|
| 私有知识资料 | 支持导入单个 UTF-8 `.txt`、`.md`、`.markdown` 文件。 |
| 本地检索 | 使用 SQLite FTS5、最多 800 字符切片、SHA-256 去重和限长参数化查询。 |
| 课程结构 | 云端已有课程、章节、知识点、题目版本和课程题库包。 |
| 历史一致性 | 已发布题目与任务使用不可变版本和内容快照。 |
| 学习闭环 | 已有知识点掌握快照、学生学习队列和教师干预队列。 |
| 离线能力 | 课程目录、反馈、掌握度和通知已有账号隔离缓存。 |
| AI 边界 | 上下文分类已包含 `KNOWLEDGE_EXCERPT`，网络 Provider 有最小必要上下文确认。 |
| 自动化基线 | `main` 当前 309 项 Maven 测试通过，2 项真实 AI 测试按环境跳过。 |

### 2.2 必须保留的边界

- 本地私有资料不得因创建课程、登录云端或打开 AI 页面而自动上传。
- 已发布课程知识版本不得原地覆盖。
- 学生只能读取其有权访问且已发布的课程内容。
- 教师只能管理本人有权限的课程；管理员权限不得隐式下放给教师。
- 课程知识不得覆盖 SQL 风险分析、执行确认、确定性评测和学习诊断事实。
- AI 不得自动发布文章、题目、任务或反馈。
- 删除本地私有素材不得破坏已发布文章版本、历史任务或学习证据。

| 指标 | v1.8.0 目标 |
|---|---|

| 发布可追溯 | 每个已发布知识文章均可确认作者、版本、内容哈希、关联知识点和发布时间。 |

- 自动生成并执行 SQL。

## 5. 建议领域与应用契约

### 5.1 核心概念

| 概念 | 职责 |
|---|---|
| `KnowledgeSourceDocument` | 本地私有素材，只保存导入来源、哈希、解析状态和切片，不自动共享。 |
| `CourseKnowledgeArticle` | 课程中的逻辑文章，包含课程、章节、状态和当前发布版本引用。 |
| `CourseKnowledgeRevision` | 不可变文章版本，保存 Markdown 正文、摘要、哈希、作者和发布时间。 |
| `KnowledgeSourceReference` | 指向来源文档、标题路径、片段和字符范围，用于审计与 AI 引用。 |
| `KnowledgePointBinding` | 文章版本与一个或多个知识点的稳定关联。 |
| `CourseKnowledgeSearchFilter` | 课程、章节、知识点、状态和可见范围筛选。 |
| `GroundedKnowledgeAnswer` | AI 或确定性解释结果，包含回答、引用、模型、Prompt 版本和降级原因。 |
| `CourseKnowledgeCache` | 按账号保存已授权文章版本、目录、关联和同步时间。 |

### 5.2 建议服务

| 服务 | 主要职责 |
|---|---|
| `KnowledgeSourceService` | 单文件/目录导入、去重、解析预览和删除私有素材。 |
| `CourseKnowledgeAuthoringService` | 创建文章、绑定知识点、生成修订和版本对比。 |
| `CourseKnowledgePublishingService` | 权限校验、发布确认、不可变版本和审计。 |
| `CourseKnowledgeQueryService` | 课程树、文章详情、关联题目和范围检索。 |
| `CourseKnowledgeSyncService` | 同步授权内容、账号隔离缓存、离线读取和失效清理。 |
| `GroundedKnowledgeExplanationService` | 检索限长片段、生成引用、调用可选 AI 并执行降级。 |

依赖方向继续保持：

```text
desktop -> application -> domain
infrastructure -> application/domain
```

解析、检索、发布、权限和引用逻辑不得放入 JavaFX 控制器。AI 解释服务只能消费已经授权、脱敏、限长并带来源标识的知识片段。

## 6. 数据与版本策略

### 6.1 本地数据

预计将桌面 `app.db` 从 schema 7 追加到 schema 8，最终版本号以实施时的实时基线为准。建议新增：

- `course_knowledge_cache`：账号、课程、文章、当前版本、状态和同步时间。
- `course_knowledge_revision_cache`：不可变正文、摘要、内容哈希和发布时间。
- `course_knowledge_point_cache`：文章版本与知识点关联。
- `course_knowledge_read_state`：收藏、最近阅读和位置；P1 可裁剪。
- 现有 `knowledge_documents`、`knowledge_chunks` 和 FTS5 表继续作为私有素材库。

### 6.2 云端数据

预计将云端课程 schema 从 2 追加到 3，最终版本号以实施时的实时基线为准。建议新增：

- `course_knowledge_articles`：逻辑文章、课程、章节、状态、当前版本和乐观锁版本。
- `course_knowledge_revisions`：不可变正文、内容哈希、作者、时间和来源摘要。
- `course_knowledge_point_links`：文章版本与知识点的稳定关联。
- `course_knowledge_audit`：创建、发布、停用、恢复和导入操作审计。

### 6.3 版本规则

- 草稿可以修订；已发布版本不可修改，只能产生下一版本。
- 历史任务、学习事件和 AI 引用保留原文章版本 ID。
- 标题重命名不改变文章稳定 ID。
- 课程或知识点停用不删除历史版本。
- 内容哈希用于完整性和重复检测，不作为授权凭据。
- 导入、发布和缓存同步必须幂等；失败不得留下半套课程结构。

## 7. 导入、解析与发布规则

### 7.1 导入

- 支持 UTF-8 `.txt`、`.md`、`.markdown`。
- 单文件继续限制在安全大小范围内；目录导入必须限制文件数量和总字节数。
- 忽略隐藏目录、构建目录、运行数据和符号链接越界目标。
- 目录导入先生成清单和预览，不直接写入已发布课程。
- SHA-256 相同内容提示重复；路径变化不自动视为新版本。

### 7.2 Markdown 结构

- 一级标题优先作为文章标题。
- 二级及以下标题形成文章内部目录和来源定位。
- 文件夹顺序和文件名前缀可作为建议排序，但发布前允许人工调整。
- 自动解析结果必须保留来源文件和标题路径，不能只保存匿名切片。
- 解析失败只影响当前文件，不应破坏同批次已验证的预览；最终写入仍采用事务。

### 7.3 发布

发布确认至少展示：

- 文章标题、课程、章节和知识点关联。
- 与上一版本相比的新增、修改和删除摘要。
- 内容大小、来源文件、内容哈希和预计片段数。
- 学生可见范围和离线缓存影响。
- 是否允许网络 AI 使用选中的限长片段。

未确认发布、权限失败、版本冲突或审计失败时不得产生可见版本。

## 8. 检索与引用策略

### 8.1 检索

- 继续以 SQLite FTS5 为 v1.8.0 主检索实现，不引入向量数据库。
- 查询必须参数化并限制长度、结果数和可见课程范围。
- 排序综合 FTS 分数、课程范围、标题命中和稳定次序，不使用 AI 排序。
- 结果返回文章 ID、版本 ID、知识点 ID、标题路径、片段和来源类型。
- 私有素材和已发布课程结果必须清晰标识，学生永远不能看到教师私有素材。

### 8.2 AI 引用

- 每个 AI 上下文片段携带稳定引用标识，不把引用交给模型自由编造。
- 模型回答后由 Java 校验引用是否来自本次授权上下文。
- UI 展示文章标题、版本和定位入口。
- 模型输出未知引用、无引用结论或越权内容时降级为确定性检索结果。
- 无可靠匹配时显示“课程资料中未找到足够依据”，不允许编造教材结论。

## 9. 权限、隐私与安全

- 私有素材仅属于当前设备，不自动进入云端课程包。
- 教师发布时服务端重新校验课程所有权或管理员权限。
- 学生查询时服务端按当前课程成员关系重新授权，不信任客户端缓存中的旧角色。
- 退课、课程停用、换号或退出登录后清除或隔离不可再访问的缓存。
- 网络 AI 必须在发送前展示字符数、资料来源和引用清单；用户取消后不发送。
- API Key、Token、学生邮箱、数据库凭据、完整 SQL 历史和其他学生数据不得进入课程 Prompt。
- 课程文章中的提示语、代码块和外部文本一律视为不可信内容，不能覆盖系统安全指令。
- SQL 示例复制到练习页后仍通过 Java 风险分析和确认流程。
- 日志只记录文档/文章 ID、版本、哈希、片段数、耗时和结果码，不记录课程全文。

## 10. 六阶段单人串行计划

| 阶段 | 唯一主目标 | 主要工作 | 阶段门禁 |
|---|---|---|---|
| 阶段 1 | 冻结契约与迁移 | 确认领域对象、权限矩阵、版本规则、schema、导入限制、固定夹具和 API 形状；不改 UI。 | 契约测试通过；私有/发布边界明确；现有测试继续通过。 |
| 阶段 2 | 交付知识核心 | 实现追加迁移、素材解析、文章修订、知识点绑定、发布版本、范围检索和服务级测试。 | 旧数据升级、重复迁移、失败回滚、不可变版本和权限测试通过。 |
| 阶段 3 | 完成教师编排 | 实现目录导入预览、课程树编辑、版本对比、发布确认、停用恢复和审计。 | 未确认内容不上传；版本冲突不覆盖；历史版本可读取。 |
| 阶段 4 | 完成学生知识中心 | 实现课程树、正文目录、搜索定位、关联练习、账号隔离缓存和离线状态。 | 学生只见授权内容；离线可读；换号和退课不泄露缓存。 |
| 阶段 5 | 串联诊断与 AI | 薄弱项跳转、练习回链、检索引用、AI 解释、网络发送预览和确定性降级。 | AI 无法改变事实；引用可校验；无 Provider 时主流程完整。 |
| 阶段 6 | 收敛与发布 | 完成 P1 取舍、性能、隐私、恢复、主题、键盘、打包、手册和 Release 门禁。 | P0 缺陷为 0；全部门禁通过后才修改版本并创建 `v1.8.0` 标签。 |

预计周期为 8～12 个单人工作日。每次只推进一个纵向闭环，不并行铺开教师端、学生端和 AI 三条未完成链路。

## 11. 必测场景

| 场景 | 正常路径 | 必测边界 |
|---|---|---|
| 单文件导入 | 导入 Markdown、生成标题目录和切片。 | 空文件、坏 UTF-8、超限、重复内容、路径越界、同名不同内容。 |
| 目录导入 | 生成文件清单、建议章节和预览。 | 隐藏目录、符号链接、过多文件、部分解析失败、重复执行。 |
| 文章修订 | 草稿绑定知识点并发布新版本。 | 版本冲突、无权限、关联已停用知识点、发布审计失败。 |
| 学生浏览 | 按课程/章节阅读文章并进入练习。 | 退课、课程停用、旧缓存、文章停用、历史版本引用。 |
| 范围检索 | 在授权课程内返回稳定、可定位结果。 | 空查询、特殊字符、超长查询、零结果、越权课程、私有素材隔离。 |
| 离线缓存 | 网络失败后读取最近授权内容。 | 换号、缓存损坏、部分同步、旧版本、恢复联网和重复同步。 |
| 诊断联动 | 从薄弱知识点进入文章或关联练习。 | 无关联文章、无关联题目、知识点停用、任务撤回、快速重复点击。 |
| AI 解释 | 基于检索片段返回带引用解释。 | Provider 离线、坏 JSON、未知引用、Prompt 注入、网络发送取消、超时。 |
| 迁移恢复 | 从 v1.7.0 数据升级并保留原数据。 | 重复迁移、事务回滚、未来版本拒绝、FTS 索引重建。 |

## 12. 自动化与验证节奏

### 12.1 必增测试

- 领域契约：文章、修订、引用、知识点绑定和状态转换。
- 迁移：schema 7 到下一版本、重复运行、失败回滚和未来版本拒绝。
- 导入：UTF-8、大小/数量限制、目录边界、哈希去重和结构解析。
- 发布：权限、乐观锁、不可变版本、审计失败和幂等操作。
- 检索：课程范围、知识点筛选、标题定位、稳定排序和参数安全。
- 缓存：账号隔离、退课失效、换号、损坏恢复和离线读取。
- AI：上下文白名单、引用校验、坏输出、网络确认和确定性降级。
- UI 逻辑：加载、预览、空态、失败、过期异步结果、离开页面和重复操作。
- 性能：50 份文档、2,000 个片段、30 个知识点和 100 道题的固定夹具。

### 12.2 测试节奏

- 每完成一个服务或迁移，先运行对应聚焦测试。

## 14. 风险与裁剪顺序

| 风险 | 应对 | 工期不足时的裁剪 |
|---|---|---|
| 私有素材被误发布 | 默认私有、发布预览、权限复核和显式确认。 | 裁剪目录批量发布，不裁剪确认和权限。 |
| 标题自动解析错误 | 解析结果只作为建议，保留人工调整和来源路径。 | 裁剪复杂层级推断，不裁剪预览。 |
| 课程版本破坏历史 | 已发布修订不可变，历史引用保存版本 ID。 | 裁剪版本差异 UI，不裁剪不可变存储。 |
| 学生越权读取 | 服务端授权、账号隔离缓存、退课失效。 | 裁剪高级离线同步，不裁剪授权校验。 |
| AI 编造引用 | Java 生成并校验引用白名单，无依据时降级。 | 裁剪 AI 解释，不裁剪确定性检索。 |
| FTS 中文检索效果有限 | 保留范围过滤、标题加权和明确零结果提示。 | 裁剪高级相关性，不引入未验证向量库。 |
| 大目录导入卡顿 | 后台执行、文件/总量上限、预检和事务写入。 | 裁剪目录导入，不裁剪单文件稳定路径。 |

裁剪顺序：Markdown 增强展示 → 收藏/阅读进度 → 批量绑定 → 知识包 v2 → AI 练习草稿 → 目录导入。课程知识契约、不可变版本、权限、学生浏览、范围检索、知识点/练习闭环、离线账号隔离、引用校验和迁移恢复不可裁剪。
