# v3.0 Alpha.3 课程、知识与导入实施记录

> 日期：2026-08-11
> 阶段代码版本：`3.0.0-alpha.3`；批次最终代码版本为 `3.0.0-alpha.5`

## 完成范围

- 课程树、活动摘要、知识文档、检索与安全 Markdown 阅读迁移到 React 工作区，数据来自 Java 应用服务。
- 新增 Java 所有的 Obsidian 增量导入：规范化根目录、文件上限、指纹预览、冲突修订、Wiki 链接、附件解析和导入报告。
- 保留 YAML、GFM、公式、Callout、Wiki 链接、嵌入、Mermaid 与代码块首批渲染；原始 HTML、脚本、Dataview 和外部资源不执行。
- 导入执行只能消费限时预览令牌；预览后变化、符号链接、越界和超限文件会被拒绝。

## 边界

高级映射以课程标题、目录层级和附件开关为第一版稳定参数；动态 Obsidian 插件和任意 HTML 不属于本阶段。公开版本仍为 Alpha.1，本批次未提交、打标签或发布。

批次门禁见 [Alpha.3 至 Alpha.5 本地阶段门禁](../../../acceptance/2026-08-11-v3-alpha3-alpha5-stage-gate.md)。
