# v2.0.0-beta.1 一次性 Beta 实施记录

> 实施日期：2026-08-09
> 版本：`2.0.0-beta.1`

## 实际交付

- 完成 LAB 与 READING 领域模型、确定性评价器、Spring 注册、JSON 解码、数据库证据和 JavaFX 交互页面，关闭八种活动中最后两个占位契约。
- schema 17 新增内容来源和跨课程关系，增加独立综合项目课程；12 条课程路径均有来源、许可、作者与版本记录。
- 引入版本化活动证据权重，保留最小证据量并降低阅读/测验对掌握结论的单条影响。
- 修复预发布更新清单模型：签名载荷可以表达 alpha/beta/rc，稳定安装仍由 Java 强制拒绝预发布通道。
- 产品名冻结为 SQLTeacher；安装身份、数据目录、Java package、SQL 安全链、AI 边界和 Runner 模型保持兼容。

## 架构冻结

Beta 后不新增活动类型、数据库体系、Cloud 主端点或顶层工作区。现有 `app.css` 作为冻结兼容层保留，不再承载新组件；新增 UI 样式继续进入 token、component、page 和 responsive 分层。删除兼容层不作为 2.0 发布的功能门禁，以避免无用户收益的大范围视觉回归。

## 验证

聚焦测试覆盖 LAB、READING、证据策略、schema 17、持久化、Spring 八评价器、更新通道、i18n 和视觉资源。完整测试、性能夹具和 Windows 候选包结果记录在 [Beta 阶段门禁](../../../acceptance/2026-08-09-v2-beta1-stage-gate.md)。
