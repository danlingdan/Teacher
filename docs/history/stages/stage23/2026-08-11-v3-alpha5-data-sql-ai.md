# v3.0 Alpha.5 数据、SQL 与 AI 实施记录

> 日期：2026-08-11
>
> 代码版本：`3.0.0-alpha.5`
> 公开版本：仍为 `v3.0.0-alpha.1`，本阶段未提交、打标签或发布

## 完成范围

- 迁移非敏感数据库连接摘要、结构树与 Monaco SQL 工作台。
- SQL 分析与执行保持为 Java 两段式边界；高风险确认使用绑定连接和 SQL 哈希的五分钟一次性令牌。
- Java 执行服务继续二次分析、只读限制、10 秒超时、最多 500 行、结果截断和学习事件审计；WebView 默认每页只接收 50 行。
- 知识 AI 助手接入现有带引用检索、上下文分类、脱敏、字符预算、Provider 超时和审计，支持分段事件、取消与确定性降级。
- IPC v1 只做加法扩展，新增课程、知识、导入、练习、Runner、数据、SQL 和 AI 方法与事件；兼容版本仍为 `3.0-v1`。

## 安全边界

前端没有 JDBC、模型 Provider、SQL 风险豁免或权威学习状态。模型输出和导入内容继续视为不可信；SQL 确认令牌不可用于不同连接或不同语句；分页结果缓存限时且进程关闭时清理。

批次验证证据见 [Alpha.3 至 Alpha.5 本地阶段门禁](../../../acceptance/2026-08-11-v3-alpha3-alpha5-stage-gate.md)。
