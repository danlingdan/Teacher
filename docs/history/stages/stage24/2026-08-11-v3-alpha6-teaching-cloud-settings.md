# v3.0 Alpha.6 教学、班级、云端与设置实施记录

> 日期：2026-08-11
> 阶段代码版本：`3.0.0-alpha.6`；批次最终代码版本为 `3.0.0-alpha.7`

## 完成范围

- 教师工作台接入现有题库和练习学情服务，支持带版本检查的题目启停。
- 会话角色来自 Java 安全存储；学生和访客直接请求教师接口会被 Java 拒绝。
- 迁移账号登录、退出、班级读取与创建、同步状态和显式手动同步；默认页面加载不主动访问网络。
- 云端失败显示可恢复降级状态，本地学习和待同步队列继续可用。
- 设置向导接入现有 Java 配置、SQL 安全模式、存储统计、Runner 能力和托管组件探测。
- 密码、访问令牌、连接字符串与其他敏感配置不会进入响应、Web Storage 或前端日志。

## 安全边界

前端角色守卫只负责导航反馈；教师与管理员操作由 Java 再次授权，云端写操作由服务器第三次授权。SQL 开发者模式不会绕过禁用语句、只读策略、高风险确认、执行上限和审计。

操作说明见 [Alpha.7 教学、云端与设置指南](../../../guide/23-v3-alpha7-teaching-cloud-settings.md)。
验证证据见 [Alpha.6 至 Alpha.7 本地阶段门禁](../../../acceptance/2026-08-11-v3-alpha6-alpha7-stage-gate.md)。
