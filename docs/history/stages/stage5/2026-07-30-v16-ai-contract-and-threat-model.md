# v1.6 AI Provider 契约与威胁模型

> 阶段：V16-01 / V16-02 第一切片
> 基线：v1.5.6

## 1. 当前调用面

| AI 任务 | 当前入口 | 允许上下文 | 明确禁止 |
|---|---|---|---|
| NL2SQL | AI 助手 | 当前方言、限长 schema、用户自然语言 | 凭据、样本行、学生身份、自动执行权限 |
| SQL 错误解释 | AI 助手 | SQL 草稿、脱敏错误摘要、方言 | JDBC 原始异常、密码、连接串、自动修改数据库 |
| 教师反馈草稿 | 教学工作台 | 确定性结论、错误码、授权证据、基础草稿 | 改变成绩、编造学生信息、自动发布 |

三类任务将在 V16-04 迁移到统一任务编排。本切片先冻结公共枚举、Provider Profile 和元数据型上下文预览，不改变既有 Prompt 或执行链路。

## 2. 冻结契约

- `AiProviderKind`：当前只定义 `OLLAMA` 与 `OPENAI_COMPATIBLE`。
- `AiProviderProfile`：仅保存 ID、显示名、类型、端点、模型、启用状态和凭据引用，不包含密钥。
- `AiTaskType`：固定 NL2SQL、SQL 错误解释和反馈草稿三类任务。
- `AiContextCategory`：使用数据类别白名单表达上下文，不把正文放入预览 DTO。
- `AiContextPreview`：只包含任务、类别、来源、字符数和脱敏说明。
- `AiTaskErrorCode`：冻结未配置、不可用、认证、模型、限流、超时、响应过大、格式、安全和取消等稳定错误类别。

网络端点必须使用 HTTPS；只有 `localhost`、`127.0.0.1` 和 `::1` 可以使用 HTTP。后续能力探测和请求重定向必须重复执行同样检查。

## 3. 凭据与持久化边界

v1.5.6 的网络 AI 配置只存在内存中。本切片改为：

```text
app-data/ai-providers.json     非敏感 Profile 元数据
app-data/ai-provider-key.dat   Windows CurrentUser DPAPI 密文
```

- Profile 与密钥分离；JSON 只保存随机凭据引用。
- DPAPI 密文只能由当前 Windows 用户解密。
- 保存使用固定目录内临时文件和原子替换；凭据引用不匹配时配置整体禁用。
- API Key 输入数组、编码缓冲区和读取缓冲区在使用后清零。
- 应用退出只清理内存副本，不删除持久化配置；用户选择“使用本地 AI”时才显式清除网络 Profile 与密钥。
- 配置或密文损坏时删除该 Profile 并安全回退本地 AI，不阻止应用启动。
- 云登录会话改用同一个通用 DPAPI 二进制存储，保持原有文件格式和行为。

## 4. 威胁与控制

| 威胁 | 影响 | 当前控制 | 后续门禁 |
|---|---|---|---|
| 明文 API Key 落盘 | 凭据泄露 | DPAPI CurrentUser；Profile/密钥分离；测试扫描明文 | 包、日志、备份和导出扫描 |
| 公开 HTTP Provider | Prompt/密钥被窃听 | Profile 契约拒绝非回环 HTTP | Probe 与重定向重复校验 |
| 配置和密钥错配 | 错误账号或不可预测请求 | 随机凭据引用写入 Profile 和密钥载荷并严格匹配 | 原子性和崩溃恢复测试 |
| 损坏/篡改密文 | 启动失败或异常泄露 | 加载失败即清理并回退本地 Provider | 稳定错误码与设置页状态 |
| 日志输出 Prompt/密钥 | 教学数据或凭据泄露 | 新契约不提供敏感字段给审计 DTO | V16-08 日志字段白名单 |
| 无限模式放宽 AI | 生成危险 SQL 并自动执行 | AI 安全链与手动执行模式正交 | 独立回归样例 |
| Prompt 注入 | 绕过任务和安全规则 | 结构化任务、输出解析、Java 风险分析 | V16-05/V16-07 恶意样例集 |
| Provider 超时/限流 | UI 卡顿、重复请求 | 既有后台任务与超时 | V16-03/V16-04 取消和重试上限 |

## 5. 数据出站矩阵

| 数据 | 本地 Ollama | 网络 Provider | 默认策略 |
|---|---:|---:|---|
| 用户自然语言请求 | 是 | 是 | 限长，调用前预览类别 |
| schema 表名/字段名 | 是 | 是 | 仅当前连接所需结构，不含样本值 |
| SQL 草稿 | 是 | 是 | 限长；不得附带连接串或凭据 |
| 脱敏错误码/摘要 | 是 | 是 | 不发送 JDBC 原始异常 |
| 授权知识片段 | 是 | 是 | FTS5 选取、限数量、展示来源 |
| 确定性评测结论 | 是 | 是 | 只作为反馈证据，AI 不得改变 |
| 学生 ID、邮箱、姓名 | 否 | 否 | 始终排除 |
| API Key、令牌、数据库密码 | 否 | 否 | 始终排除 |
| 数据库样本行和完整课程文档 | 否 | 否 | v1.6 不支持出站 |
