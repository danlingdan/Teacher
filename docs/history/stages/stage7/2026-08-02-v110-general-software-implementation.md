# v1.10 通用软件能力实施记录

## 范围

本阶段按单人串行交付，将通用能力集中到 `application.system`、`application.update`、`application.support` 及对应基础设施；JavaFX 控制器只编排服务和界面状态。专业 SQL 教学规则、学习诊断策略和数据库业务模型未改变。

## 已实现

- 客户端可信更新协议、Ed25519 公钥轮换入口、稳定通道、SemVer、24 小时节流、白名单 HTTPS、流式下载和校验后安装。
- 通用设置与支持页、问题反馈、诊断包、异常启动标记、任务/通知、存储治理、网络检查、离线帮助和账号改密。
- 数据目录级单实例 IPC、可见屏幕窗口恢复、有界桌面执行器和干净退出状态。
- Cloud 反馈 schema、幂等回执、匿名查询 Token、限流、字段/正文大小限制、诊断键拒绝和能力协商。
- 发布流水线生成 CycloneDX SBOM 与签名更新信封；安装包携带隐私和第三方许可证材料。

## P1 处置

纳入 v1.10.0：本机回执基础、升级完成状态基础、深度诊断基础、受限目录打开基础、自动备份复用、通知偏好基础、本地操作历史基础和高级支持包白名单基础。

转入 v1.10.x：HTTP Range 断点续传、截图附件、受控镜像、命令面板、完整英文、系统原生通知、可信邮件密码重置、活跃会话管理、云端账号导出/注销、分阶段发布、按电量/计费网络策略和安装修复。原因是这些能力依赖额外平台通道或服务，不应在缺少完整验证时进入正式入口。

## 运维边界

- 生产环境通过 `/etc/sqlteacher/cloud.env` 配置反馈散列 Secret 和签名清单只读路径。
- 发布私钥只保存在本机受限目录与 GitHub Actions Secret；云端只部署公开签名信封。
- 发布前先完成数据库在线备份和完整性检查，再原子切换 `/opt/sqlteacher/current`；失败时回切上一版本。
