# v3.1.0 练习题目体系增强实施记录

实施日期：2026-09-08 · 计划：[练习题目体系增强计划](../../../plans/2026-09-08-v3.1.0-exercise-enhancement-plan.md)
· 基线：`main` @ `c161e6e`

## 交付内容

### W1 导入验证与安全闸

- `ExerciseDatasetSqlPolicy`（新）：数据集 setup SQL 语句白名单（仅 `CREATE TABLE`、
  `CREATE INDEX`、`INSERT INTO`），注释/引号感知；在导入自测、练习会话库初始化、评测库
  初始化三处生效，违规抛 `EXERCISE_DATASET_POLICY_VIOLATION`。
- `ExercisePackageValidator`（新）：导入自测 dry-run——每个数据集在内存库中真实建表，逐题
  执行参考 SQL 并验证其满足自身判定规则（行数、结构关键字）；解析预览逐项返回自测结论，
  自测不通过整包拒绝导入；单题保存（`teaching.exercise.save`）同样先自测
  （`EXERCISE_SAVE_INVALID`）。
- 错误归因：评测环境/参考答案失败返回独立错误码 `REFERENCE_SQL_FAILED`，反馈提示"题目数据
  异常，请联系教师或管理员"，不再记为学生执行失败。
- `SqlStructureMatcher`（新）：结构关键字归一化匹配从评测器抽出，评测与自测共用同一实现。
- 教师端导入预览 UI 逐项展示自测结论（✓/✕ 与原因），存在未通过项时禁用"导入题库包"。

### W2 判分契约对齐

- 列名判定失败反馈展示期望列名与实际列名（不含参考 SQL 与期望数据）。
- 预置题题面写明必需列别名（join-01、subquery-04 的 `course_name`）；
  subquery-02/subquery-03 配置 `KEYWORDS: IN` / `KEYWORDS: NOT EXISTS` 兑现题面结构承诺，
  导入自测以同一规则校验参考 SQL。

### W3 题库可升级通道与内容修正

- 内置题库从代码 seed（`insert or ignore` + hints 补丁）改为资源文件
  `src/main/resources/exercise/exercise-bank.dsl`（文字 DSL），启动时经
  `ExerciseBankApplier` 自测后按题目版本号 upsert（`ExerciseBankWriter`，与网络同步共用）；
  教师修改/停用过的题目（版本不低于内置包）不会被覆盖；旧数据集 `school-core-v1` 保留。
- 预置题升级为版本 3：题面列名声明、B 班题面、HAVING 阈值 75、子查询/NOT EXISTS 关键字；
  数据集更换为 `school-core-v2`：新增 7 号学生（52 分，filter-01 生效）、第 4 门无人选修
  课程（join-03 生效）、班级改名 A班/B班/C班（消除中文排序反直觉顺序）、显式外键声明。
- `ExerciseDatasetSchemaSummary` 改为内存库内省（`pragma table_info` +
  `pragma_foreign_key_list`），摘要追加外键关系（如 `enrollment.student_id → student.id`）；
  无效或违规 setup SQL 降级为占位文案。

### W4 选题目录

- `practice.catalog` 契约扩展为 `ExerciseCatalogItem`：按当前本机学习者聚合尝试次数、
  是否通过、最后尝试时间；数据不出本机。
- 前端目录抽为 `ExerciseCatalogPanel` 组件：按难度分组、难度/状态筛选、状态徽标、
  未完成优先排序；筛选与搜索写入 URL 参数；移除每页 10 条翻页。

### W5 网络题库（流式更新）

- 分发模型：清单（`bankVersion` + 各数据集/题目 `id, version, SHA-256`）+ 分块（单块文字
  DSL 片段）。客户端拉取清单后本地计算差集，仅下载缺失或版本更新的分块。
- 服务端：`V31ExerciseBankStore`（SQLite）+ `/api/v1/bank/manifest`、
  `/api/v1/bank/block/{type}/{id}` 只读接口与 `POST /api/v1/bank/publish`（管理员鉴权；
  服务端再次解析与自测，版本单调递增）。Java 服务保持 loopback 绑定。
- 客户端：`CloudApiClient` 新增 `fetchExerciseBankManifest` / `fetchExerciseBankBlock` /
  `publishExerciseBankPackage`（HTTP 实现带 30 秒超时）；`ExerciseBankSyncService` 负责差集、
  下载、哈希校验、重组自测（未变化数据集从本地解析）与单事务原子应用；应用后记录
  `exercise_bank_state`（迁移 20 新表）防止降级；任何失败回滚且不影响本地练习。
- IPC：`practice.bank.check`、`practice.bank.update`（`import.progress` 事件流式上报）、
  `teaching.exercise.publish`（教师角色，发布前本地先自测）；契约同步更新
  `contracts/ipc/v1/manifest.json` 与 `ui-web/src/shared/ipc.ts`。
- 前端：练习目录新增"题库更新"入口（检查 → 应用 → 刷新目录）；教学工作台新增
  "发布到服务器"。

## 安全不变量确认

- 模型与网络内容均不接触 JDBC 连接：网络分块重组后走与教师导入完全相同的确定性解析、
  自测与白名单闸门，任一失败整体回滚。
- 更新检查只 `GET` 清单并在本地差集，不上传学生数据；服务器不可达时检查返回友好状态，
  本地练习不受影响。
- 判定与进度仍全部由确定性 Java 代码产生。

## 视觉验证（打包桌面 E2E）

按验证阶梯在打包 Tauri 桌面上执行了视觉巡检（`ui-web/e2e/exercise-visual.e2e.js`，截图输出
`target/e2e-artifacts/exercise-*.png`），并复跑既有 `desktop.e2e.js` 全部 4 项用例确认无回归。
巡检发现并修复两个问题：

1. **深色主题令牌块失效（既有缺陷）**：`.theme-dark` 的令牌覆盖被两条滚动条规则从声明块中间
   截断，`--surface-3` 至 `--shadow` 的整段覆盖成为孤儿声明被丢弃——这正是构建中 esbuild
   `Unexpected "#203743"` 警告的来源，导致深色主题大面积低对比（预览卡标题/描述、教学工作台
   标签几乎不可见）。已把令牌收回 `.theme-dark` 声明块，构建警告清零。
2. **题库更新按钮与目录标题重叠**：窄侧栏中 `headerAction` 放在 `.section-heading` 行内会挤压
   标题逐字换行。改为标题下方独立工具行、按钮占满整行。

修复后巡检确认：目录按难度分组（入门 9 题/进阶 8 题/高级 3 题）、状态徽标、难度与状态筛选
（选"入门"后计数变 9）、"题库更新"入口均正常；预览卡展示新题面（含"列名为 course_name"）与
内省数据集摘要，外键关系（`enrollment.student_id → student.id`）独立成行完整可读；作答会话
（Monaco、Java 评价、提示 0/3）正常；教学工作台含"发布到服务器"入口。巡检中把摘要外键关系
改为独立行展示（`ExerciseDatasetSchemaSummary`）。

- 网络题库发布需服务器管理员凭据；正式环境的发布流程（shared 目录部署、Nginx HTTPS、
