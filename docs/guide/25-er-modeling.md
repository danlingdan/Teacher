# 数据建模：AI 生成 E-R 图

> 适用版本：**3.11.0 及后续兼容版本**。功能依据与记号规范见
> [v3.11.0 计划](../plans/2026-10-27-v3.11.0-er-modeling-plan.md)；本页是面向使用者的长期指南。

## 功能入口

侧边导航「数据建模」（`/modeling`）。在输入框用自然语言描述建模需求（≤2000 字符），点击「生成」，
AI 起草一张国内教材风格（陈氏记号）的 E-R 图，经 Java 确定性校验后展示在画布上。

生成前需要已配置 AI 引擎（顶栏「AI 引擎」按钮）：本地 Ollama 或网络厂商均可，与 NL2SQL 共用同一
引擎配置。未配置时页面会给出引导按钮，一键唤起 AI 引擎面板。

## 支持的记号

| 概念 | 图形 |
| --- | --- |
| 实体 / 弱实体 | 矩形 / 双线矩形 |
| 属性 / 主码属性 | 椭圆 / 名称加下划线 |
| 复合属性 | 椭圆 + 子属性子椭圆 |
| 多值属性 / 派生属性 | 双椭圆 / 虚线椭圆 |
| 联系 | 菱形，连线上标注 1 / n / m |
| 全参与 | 实体—联系双线 |
| 依赖联系（弱实体） | 双菱形，弱实体侧双线 |
| 概括 / 特化 | 三角形（ISA） |

## 画布操作

- 拖拽节点可微调布局；滚轮缩放、空白处拖动平移。
- 「适应视图」一键回到全图；「导出 PNG / 导出 SVG」把当前图保存为课件素材。

## 使用限制与失败提示

- 模型规模上限：实体 ≤16、每实体属性 ≤12、联系 ≤24、联系成员 2–4、层级 ≤8。需求过大时请拆分
  描述（例如按子系统分别生成局部 E-R 图）。
- AI 输出一律先经 Java 校验：基数只接受 1/n/m、引用必须指向已声明实体、弱实体必须配依赖联系等；
  校验失败时页面列出具体原因，可直接重新生成（服务端会自动带着错误原因重试一次）。
- 网络模型不可用、超时或输出不合规时给出明确中文提示，不影响其他功能；生成结果仅供参考学习，
  软件不会把 E-R 图直接转换为建表 SQL。
- 需求文本仅用于当次生成，不写入日志或学习事件。
