# 离线系统模拟实验指南

> 适用版本：`2.0.0-alpha.5` 及后续兼容版本

## 可用实验

课程地图中新增三门离线课程：计算机系统、操作系统和计算机网络。每门课程包含一个确定性模拟实验，分别覆盖指令周期、最短作业优先调度和分组交付。

这些实验不需要登录、网络、AI 服务、数据库服务器或编译器。它们使用内置课程定义和本地评价器，因此断网时仍可学习和提交。

## 操作方法

1. 在课程地图选择对应课程和模拟活动；
2. 阅读当前状态、观察说明和检查点；
3. 选择一个动作，工作区会显示新状态和动作历史；
4. 若顺序错误，使用“撤销”或“重置”后继续；
5. 达到目标状态后提交，查看每个动作、检查点和目标的评价结果。

界面会标示推荐的下一步，但课程是否通过以确定性评价器重放动作序列的结果为准。启用“减少动态效果”后，状态切换动画会按全局无障碍设置收敛。

## 结果含义

- `SIMULATION_PASSED`：动作序列合法，全部检查点与目标已达到；
- `SIMULATION_ACTION_UNKNOWN`：artifact 包含课程未定义的动作；
- `SIMULATION_TRANSITION_INVALID`：动作不适用于当时状态；
- 课程专用原因码：对应检查点尚未达到；
- `SIMULATION_GOAL_NOT_REACHED`：序列合法但还没有到达目标状态。

模拟结果会进入与测验、跟踪、代码和 SQL 相同的活动评价与学习事件链，可供后续诊断和推荐使用。

## 安全与隐私

模拟活动只处理内置状态标识和动作序列，不执行学生代码或 SQL，不读取用户文件，也不主动连接外网。代码活动的本地运行权限、SQL 的确认与拦截规则、AI 信任边界保持不变。
