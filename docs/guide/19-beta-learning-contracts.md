# Beta 学习活动、证据与兼容契约

> 适用版本：`2.0.0-beta.1` 及后续 2.0 兼容版本

## 八种活动

SQLTeacher 2.0 Beta 冻结八种活动：SQL、测验、跟踪、模拟、代码、实验、项目和主动阅读。所有活动通过同一提交、评价、证据和诊断生命周期；SQL 与代码仍使用各自独立的安全执行路径。

### 结构化实验

LAB 页面按步骤显示实验说明，每一步要求学生勾选完成并记录结构化观测，最后提交实验结论。自动评价只判断步骤、观测和结论是否完整，不把自由文本相似度当作科学事实或教师评分。需要运行程序时由学生在本地 IDE 中主动运行，LAB 本身不持有执行能力。

### 主动阅读

READING 页面显示内容来源和许可。学生完成阅读后还要凭记忆回答检查问题；“已读”状态不会单独形成通过或掌握证据。回答采用确定性规范化比较，错误原因和解释稳定可复现。

## 证据校准

诊断继续要求至少三条证据，同时按活动丰富度计算有效权重：READING 40、QUIZ 60、TRACE 80、SQL/SIMULATION 100、CODE/LAB 110、PROJECT 120。低权重阅读证据不能通过重复勾选压过真实执行和项目证据；不足时保持 `INSUFFICIENT_EVIDENCE`。

## 内容来源和跨课程关系

12 条内置课程路径都记录来源标题、仓库内引用、许可、作者、内容版本和复核时间。Beta 内置新增内容为 SQLTeacher 原创并采用 Apache-2.0。跨课程关系显式保存来源知识点、目标知识点、关系类型和理由，供课程地图和推荐解释使用。

## 预发布更新

更新清单允许 `stable`、`alpha`、`beta` 和 `rc` 四种签名通道。稳定安装只接受 stable；预发布安装接受 stable 或与自身相同的预发布通道。签名、HTTPS、主机白名单、大小和 SHA-256 校验保持不变。
