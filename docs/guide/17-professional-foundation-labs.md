# 专业基础离线实验指南

> 适用版本：`2.0.0-alpha.6` 及后续兼容版本

## 课程入口

课程地图新增软件工程、程序设计语言与编译、离散数学与理论基础、AI 与数据基础、计算机安全基础五门课程。每门课程包含一个可以离线完成的确定性实验。

打开课程后，按工作区显示的当前状态和观察数据选择下一步操作。检查点用于解释学习进度；最终提交会由应用层重新播放完整操作序列，不依赖 UI 的推荐提示。

## 五个单元

- 持续集成质量门禁：把需求变更转换为边界值与回归测试，再评审固定 CI 证据；
- 词法分析流水线：对 `sum=12+3;` 扫描词素、分类 Token 并验证完整性；
- 数学归纳法：结构化完成基础步、归纳假设、归纳步和结论；
- 分类结果评价：根据固定匿名结果计算混淆矩阵、precision、recall，并记录小样本与责任边界；
- 不可信输入防御链：演练字段约束、对象级授权、上下文编码和受控接受。

## 运行与安全

这些单元不需要网络、AI 服务、外部数据库、Git、CI、编译器或 Shell。安全单元只教授防御流程，不包含可执行攻击载荷、公网目标、扫描或凭据操作。AI 单元使用固定匿名数据，评价由确定性 Java 代码完成。
