# SQLTeacher 3.0 用户手册

## 安装与启动

Windows 10/11 用户可运行安装包，也可解压便携 ZIP 后运行 `SQLTeacher.exe`。程序自带 Java 25，
无需单独安装 Java。正常启动只显示 SQLTeacher 窗口，不会额外弹出命令行窗口；重复启动会激活已有窗口。

用户数据默认保存在 `%LOCALAPPDATA%\SQLTeacher`。从 2.3 升级会继续使用该目录中的数据库、学习记录和
通用设置。卸载程序不会自动删除用户数据，重装前不要手工删除该目录。

## 工作区与权限

左侧导航只显示当前身份可用的正式工作区：

| 工作区 | 主要用途 |
| --- | --- |
| 今天 | 查看确定性学习摘要、继续或暂不处理下一步动作。 |
| 课程与知识 | 浏览安全 Markdown、检索资料、阅读、使用有引用的 AI 解释；随包官方知识库可云端/离线更新；教师可导入、修订、发布和维护索引。与课程活动分开。 |
| 练习与实验 | 完成 SQL 题和课程活动，运行 Java/Python/C/C++ 本地实验。 |
| 数据与 SQL | 管理真实数据库连接，查看结构，经过 Java 风险分析后执行 SQL，或生成不会自动执行的 AI SQL 草稿。 |
| 教学空间 | 教师和管理员维护题库、查看学情并处理干预队列；访客和学生看不到此入口。 |
| 班级与云端 | 登录/注册、同步班级、查看任务；教师可维护成员与任务，所有云端写操作由服务器再次鉴权。 |
| 设置 | 管理外观、网络、开发组件、备份恢复、更新、通知、本地数据、关于与问题反馈。 |

页面不存在设计系统、迁移状态或测试数据入口。浏览器开发预览不提供模拟学习数据，日常使用请从桌面程序启动。

## 快速操作与外观

- `Ctrl+K` 打开快速导航，`Ctrl+1` 起按当前可见导航顺序切换工作区，`Ctrl+,` 打开设置。
- SQL 作答中，`Ctrl+Enter` 运行、`Ctrl+Shift+Enter` 提交、`F1` 获取分级提示。
- 设置可选择简体中文或 English、浅色/深色/跟随系统、现代/系统/经典字体、舒适/紧凑密度、
  高对比度和减少动态效果。语言切换保存后会重新加载界面；课程正文和用户数据保持原语言。
- 主窗口的位置和尺寸会自动恢复。第二次启动不会创建另一套数据库或 Java 核心。

## SQL 练习与课程活动

SQL 练习使用“选择题目 → 预览 → 确认并开始 → 运行/提交”的两阶段流程。未确认前不会创建隔离会话，
返回选题或关闭练习会安全结束当前会话。运行结果不是最终评分；提交后由 Java 确定性规则比较列、行、顺序、
数量和必需关键字。最多使用三级提示，重置只重建当前隔离练习数据。

v3.3 起练习扩展了题型与个性化反馈：

- **题型**：除查询题外还有写操作题（单条 INSERT/UPDATE/DELETE 等）、脚本题（多条语句按序执行、可要求事务关键字）与触发器题（提交 CREATE TRIGGER 后系统执行触发场景并比对结果）。写类题目在一次性沙盒库中执行、不弹确认框，可随时“重置练习”恢复初始数据；禁止类语句（如 PRAGMA、ATTACH、文件读写）在所有题型下都会被 Java 拒绝。
- **得分与对比**：提交反馈会显示 0–100 的参考得分（仅反馈，通过仍需全部分项达标）；失败时可查看“期望 / 实际”并排对比（是否展示期望数据由教师按题控制），也可点“AI 讲解（草稿）”获得仅供阅读的错因分析——它不写入任何学习记录。
- **错题本**：练习页新增“错题本”标签，聚合做错且尚未通过的题目（尝试次数、最佳得分、最近反馈），一键重练开新会话。
- **推荐下一题**：目录上方按本机作答历史给出确定性推荐（正确率 × 难度层级，无随机、无 AI），附推荐理由。
- **执行计划**：SQL 工作台新增“执行计划”按钮，对当前语句自动执行 `EXPLAIN QUERY PLAN` 并以表格展示，配合索引实验题使用；练习作答页不提供该入口。
- **题库目录与更新**：题目目录改为服务端式分页加载（每页 50 题，支持按关键词、难度与状态过滤翻页）；内置第二套“供应商-零件-工程”题库（10 题，覆盖连接、子查询与聚合）。设置页“题库更新”中可订阅题库频道并配置定时检查（默认启用：每次启动检查一次并每 6 小时复查；发现更新仅提示不打断，可随时关闭）。

课程活动先选课程，再从该课程的已启用活动中选择。预览确认后才显示真实交互。测验、阅读、追踪、模拟、
编程、项目和实验均由 Java 评价器处理；隐藏答案和测试数据不会发送到 WebView。

编程活动使用 Monaco 编辑器，提供语法高亮、本地补全和快捷键。本地 Runner 只在相应 Java、Python、C 或
C++ 工具链可用时运行；设置页可探测、安装或取消安装组件。运行源码会使用当前 Windows 账户的本地权限，
不要执行不可信代码。

## 数据库、SQL 与 AI 安全

数据库连接的入口在顶栏（通知按钮旁）：常态显示当前连接的名称与方言，点开是连接清单——**点行即设为当前连接**，
行内提供编辑、复制、删除（随包内置库不提供复制/删除），底部“新建连接”打开表单对话框；没有任何连接时入口会
变成醒目的“连接数据库”引导。“数据与 SQL”页的侧栏只保留当前连接指示、管理按钮与表结构树，是纯粹的表结构区。

新建/编辑表单沿用“傻瓜化”设计：数据库类型提供“常用类型”一键选择（MySQL、SQLite、PostgreSQL），其余方言
（MariaDB、SQL Server、Oracle、Db2、达梦 DM8、TiDB、OceanBase、GaussDB、DuckDB、H2 与通用 JDBC）收在
“更多类型”下拉里；选中类型后只显示该类型必要的字段，服务器型的端口会自动填入默认值。服务器型可点“列出数据库”
直接从服务器读取可选的库（自动过滤系统库），在下拉中选中即回填，也可手动输入；应用重启后首次列库需要先输入
一次密码（会话密码只保存在 Java 进程内存中）。文件型（SQLite/DuckDB/H2）只需“浏览…”选择数据库文件，或用
“新建空库…”另存一个新文件——文件不存在时测试结果会提示将创建新的空库，避免路径笔误造成“连接成功”的空库。
通用 JDBC 的 URL/驱动类/驱动 JAR、连接 ID、只读与启用开关都收在“高级选项”折叠区；连接 ID 与显示名称留空会
自动生成。点“测试并保存”会先用真实连接验证，失败的配置不会被保存；“仅测试”只验证不保存，成功后的密码在本
进程内暂存，编辑时留空即复用。密码不进入前端持久化。保护现有数据库时应启用只读连接（在“高级选项”中），并
使用最小权限账号。

左侧“表结构”是一个可整体折叠的区块（标题显示“共 N 张表”），展开后每张表默认收起，可用顶部筛选框按表名或
列名过滤，避免表多时侧栏过长；点开单张表会分区显示“列”（名称、类型、PK、NOT NULL）与“索引”（名称、列清单、
是否唯一，无索引显示“无”）。内置 SQLite 演示数据库
声明了完整的主键、外键与 CHECK 约束（Course 自引用先修课、SC 引 Student/Course、SPJ 引 S/P/J），并对演示库
连接强制外键：违规的写入会真实报 `FOREIGN KEY constraint failed` 等错误，可直接用于演示实体完整性与参照完整性。

SQL 工作台的执行结果可点“导出 CSV”保存为本地文件（由 Java 写入，带 BOM，Excel 可直接打开）；结果保留 10 分钟，
过期后需重新执行再导出。“执行历史”折叠区记录本机最近 200 条执行（默认展示 30 条），点击任意条目即可把语句填回
编辑器；历史只保存在本机应用数据库中，可用“清空历史”一键删除。

所有 SQL 都经过 Java 的单语句解析、风险分析、只读边界、高风险确认、超时、结果上限和审计。多语句、
用户/角色管理以及写文件类操作（`INTO OUTFILE`、`COPY ... TO FILE/PROGRAM`）会被阻止；`DROP`、
`TRUNCATE`、`GRANT`、`REVOKE`、`DROP DATABASE` 需明确确认后执行（删除整个数据库的确认弹窗会提醒先备份）。
首次进入 SQL 工作台时会请你在“教学模式（推荐，写操作逐条确认）”与“开发者模式（INSERT/CREATE 免确认）”之间
选择，之后可在设置中切换；CTE（`WITH ... SELECT`）与括号复合查询可以直接作答。连接失败等错误信息会附上
具体原因与错误分类，便于自查。

自然语言生成 SQL 一步完成：点“生成 SQL 草稿”后由本地组装模型输入（仅结构信息，不含表数据），组装明细
（字符数、类别、来源、脱敏）收在折叠区可展开查看，全程不外发。草稿不会自动执行，仍须人工检查并走同一 Java
安全路径；未配置 AI 或网络 AI 不可用时由本地确定性生成兜底，本地 SQL 学习照常使用。模型永远不会获得
JDBC `Connection`。AI 使用没有每日次数限制（长文本输入与超时限制仍然生效）。

## 课程知识与教师工作

“课程与知识”页只承载知识文档，与「练习与实验」里的课程活动是两套东西，互不混淆。页面按知识库状态呈现三种形态：
- **空库**（还没有任何知识文档）：不显示检索框和知识助教，改为引导——教师可「检查官方知识库」下载安装，或
  「导入知识库文件…」离线导入，也可用自己的 Obsidian/单篇导入；学生提示联系任课教师。
- **索引未就绪**（已有文档、正在建立向量索引）：顶部显示索引进度与降级说明，全文检索已可用，语义检索待本地向量
  模型就绪后自动完成。
- **正常**：检索、课程树浏览、阅读与知识助教照常。

侧栏是“课程 → 章节 → 文档”双层折叠树（按第 N 部分、第 N 章自然排序，当前文档高亮），顶部检索支持关键词
高亮、结果计数与所属课程/章节标注。文档阅读区占满主列；「知识助教」按钮会打开一个独立子窗口，自动携带当前
文档的上下文，在子窗口里可以连续追问、取消生成、清空对话，回答附可追溯引用。

**官方知识库**（《数据库系统概念》）随安装包分发，首次启动后台自动导入。侧栏底部的「知识库更新」对所有角色
开放：「检查云端更新」在云端有新版时提供「下载并安装」（经 sha256 与大小双校验），「手动导入…」可选择本地
知识库压缩包离线更新。官方文档以整包方式替换更新，你自己导入的文档（无官方标记）永远不会被覆盖。官方文档
中的插图在阅读时按需加载渲染（下载排队进行），缺失或读取失败会显示占位与原因而非静默破图。Obsidian 的
`\(…\)`、`\[…\]` 数学定界符会自动转换为标准公式渲染，加粗标记闭合前的多余空格也会自动容忍。

知识区按“输入问题 → 选择资料 → 阅读与练习”组织。Markdown HTML 会被忽略，公式和 Mermaid 以受限方式
渲染，动态 Dataview 不执行。AI 解释必须带可追溯引用，发送前显示上下文范围。

教师在高级区域可预览并执行 Obsidian 增量导入，或导入、修订、发布、转私有、停用和删除单篇资料；写入前
会显示冲突和缺失附件。题库支持新建、编辑、复制、启停、JSON 导入导出；学情和干预状态来自真实 Java 服务。

## 云端账号与班级

离线学习无需登录。侧栏底部的“登录或创建账号”和“班级与云端”中的登录按钮都会打开独立账号页；该页面
支持登录、注册、密码重置、显示/隐藏密码和返回离线工作区。登录后可同步班级、任务和学习事件。断网不会
删除本地记录，同步队列会保留状态供稍后重试。

学生只会看到可见任务，并可从已发布任务进入对应本地练习。学生可以在「可见班级」中输入教师提供的班级码自助
加入班级（v3.4.1 起；服务端对尝试频率有限流，码无效或云端服务版本过旧时会统一提示）。当前 3.0 候选尚未把本地练习提交与班级任务
上下文、离线 Outbox 和云端提交确认重新接成闭环，因此正式发布前不能把“进入练习”视为“已完成班级任务”。
教师/管理员可创建班级、添加成员、保存/复制任务并更改草稿、发布、关闭、撤回、归档状态，还可查看班级/
任务学情；每个班级自动生成 8 位班级码，教师可在「成员名单」中查看、复制并重置（重置后旧码立即失效，已加入的成员不受影响）。
界面隐藏不是授权边界，服务器会再次拒绝越权请求。其他旧版云端协作缺口见
[3.0 对照 2.3 及更早版本能力审计](../acceptance/2026-08-13-v3-v23-capability-parity-audit.md)。

账号安全区域可修改密码、查看并撤销其他会话、申请数据导出、申请/查询/取消账号删除。密码、令牌和导出内容
不会写入 Web Storage。

## 设置、备份与通知

设置页打开时只读取语言、主题、网络等轻量偏好，不会自动扫描工具链、访问 Cloud 或遍历本地磁盘。
需要检查 JDK、Python、Ollama、MSVC、WSL 和 Runner 时，展开“本机环境与组件”并点击“开始检测”；
需要查看可用空间和备份时再展开“备份与本地数据”。组件安装过程中可取消。

“AI 模型”面板管理本地/网络 AI 的切换：未配置时使用本地 Ollama，添加网络供应商（OpenAI 兼容端点 +
模型名 + API Key）后可“启用”切到网络 AI，“停用”即回本地；网络不可用时自动回落，本地学习主流程不受影响。
API Key 只保存在本机（Windows DPAPI 加密），保存与测试请求之外不会出现，也不回显；“测试连接”会实时探测
端点并列出可用模型。端点仅允许 HTTPS（本机 http://localhost 亦可）。组件安装过程中可取消。高影响本地数据
操作只对有维护权限的身份开放：

1. “创建完整备份”保存应用数据库和必要状态。
2. 恢复前选择已有备份并再次确认；恢复会覆盖当前应用数据库。
3. “恢复演示数据库”只重建演示数据。
4. 清理缓存只删除可重建内容；清空学习数据必须输入 `RESET LEARNING DATA`。

可手动检查签名更新、查看应用内通知和帮助。应用默认在每次启动时自动检查签名更新（v3.3.2 起，可在设置中关闭），发现新版本会弹窗提示，可在弹窗内直接下载官方安装包并启动升级，也可选择跳过此版本或稍后提醒；
顶部“通知”按钮也会显示当前本机通知及未读数。Windows 原生通知默认关闭；启用后仅显示更新、备份、任务等固定
白名单短语，不包含学生信息、SQL、Prompt 或附件。临时支持日志开启后 24 小时自动关闭，且仍不记录密码、
令牌、SQL、Prompt 和用户附件。

## 问题反馈

设置页“更新、通知与帮助”面板与“关于”面板均提供「问题反馈」按钮，打开反馈表单：反馈类型、严重程度、
摘要、详细描述（摘要与描述必填）、复现步骤、期望结果、实际结果与可选联系方式。反馈只在用户主动提交后发送，
应用不会自动上报；不要在表单中填写密码、Token、SQL、学生隐私数据等敏感内容。

诊断与凭据规则：

- 四个诊断勾选（本机环境、最近失败的任务、网络连通性摘要、更新设置状态）**默认全部关闭**，逐项勾选后才随反馈发送。
- 发送前必须点「预览诊断字段」：预览内容与实际发送内容完全一致（所见即所发），未预览时「提交反馈」不可用。
- 提交成功后显示反馈编号与查询凭据（queryToken）。查询凭据**仅显示这一次**，之后无法找回，请立即复制保存；
  它与反馈编号一起是查询进度、撤回或导出该反馈的唯一凭据。
- 同面板的「查询反馈进度」输入反馈编号与查询凭据后可查看处理状态或撤回反馈；撤回后服务端不再保留待处理内容。
  反馈关闭后 180 天删除明细，最长保留 365 天。

## 故障处理

- 显示“等待 Java 核心”：确认使用完整安装目录或完整解压便携 ZIP，不要只复制 `SQLTeacher.exe`。
- Runner 不可用：在设置中查看对应工具链状态，安装/修复后重新检测。
- 云端不可用：本地学习可继续；恢复网络后在“班级与云端”手动同步。
- 数据异常：先创建备份，再尝试缓存清理或恢复；不要直接修改 `%LOCALAPPDATA%\SQLTeacher` 中的数据库。
- 仍无法解决：记录界面错误码，通过设置页「问题反馈」提交（诊断字段默认全关、发送前强制预览）；不要在反馈中填写密码、Token、SQL 或学生隐私数据。
