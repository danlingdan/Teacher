# SQLTeacher v1.5 用户手册

## 云端教学与同步

应用启动后必须选择身份。已有账号可直接登录；注册时填写邮箱、昵称和至少 12 位密码，新账号默认获得学生身份；也可以选择“访客进入”体验本地功能。访客数据不会上传到账号，退出程序后也不能在其他设备恢复。

登录成功后，应用会先执行一次账号数据同步，再进入主界面。Windows 会使用当前系统用户的 DPAPI 加密保存会话；访问令牌临近失效时自动轮换刷新令牌，退出后本机密文和服务端令牌同时撤销。进入“云端教学”后，页面会自动选中第一个班级。选择班级即可查看已发布或已截止任务，点击“立即同步”可再次上传本机学习事件、下载其他设备的新记录。网络中断不会删除本地记录，同步会有限次退避重试并保留状态，稍后可再次同步。

页面顶部状态条会显示加载、成功或错误信息。网络请求进行期间相关操作会暂时禁用，避免重复提交。

## 身份与功能权限

| 身份 | 可用功能 |
|---|---|
| 访客 | 首页、自由 SQL、闯关练习、AI 助手、表结构和设置；仅本机使用，不显示云端和教学管理模块。 |
| 学生 | 访客功能，加课程知识、我的班级、学习反馈、任务查看和学习记录同步。 |
| 教师 | 学生功能，加教学工作台、题库管理、学情看板、班级成员管理和任务发布。 |
| 管理员 | 全部功能，并可查看所有云端班级。 |

## v1.7 下一步学习与教师干预

首页“下一步学习”使用本机练习事实生成确定性建议。登录学生还会看到未完成班级任务和未读反馈；云端不可用时只显示本机建议。选择建议后可继续题目或任务，也可暂时忽略当前证据周期；新的练习证据会重新评估。

教师在“学情看板 → 教师干预队列”查看当前账号有权访问班级中的逾期、连续失败和待跟进提交。选择记录后可标记已查看、已解决或忽略，也可进入现有反馈/任务工作区。干预项是待处理工作，不是对学生能力的自动判定；反馈发布仍需教师审核确认。

右上角会显示当前昵称和身份。点击“切换身份”会撤销当前云端令牌并返回登录页。

需要使用网络 AI 时，填写厂商提供的 HTTPS Chat Completions 地址、模型名和 API Key。密钥只在当前应用进程内存中使用，退出应用后需要重新填写；不得在共享电脑展示密钥。

## 开始使用

安装后从桌面或开始菜单打开 SQLTeacher。主界面左侧按“学习、教学/课程与反馈、SQL 工具、系统”分组，只显示当前身份可使用的业务入口；设置始终对所有身份可见。`Ctrl+1` 至 `Ctrl+9` 可切换常用可见入口。

## 外观、主题与设置权限

进入“设置 → 外观与易用性”可选择浅色、深色或跟随 Windows 系统主题，并选择现代中文、系统默认、经典清晰字体以及舒适/紧凑密度。点击“应用外观”后立即生效并保存在当前 Windows 用户下，无需重启。

所有身份都可以修改外观、快捷键和本人的本地数据库连接。版本信息对所有人可见，但整台设备的备份恢复属于高影响操作，仅管理员可以执行；受限页面会说明原因。隐藏或禁用按钮不是服务端授权的替代品。

## 自由 SQL 与安全确认

在“自由 SQL”选择连接、输入单条 SQL 后执行。查询默认限制结果数量；多语句、`DROP DATABASE`、`GRANT`、`REVOKE` 等操作会被阻止。高风险但允许的语句必须阅读风险说明并明确确认。不要在课程数据库使用高权限账号。

## 闯关练习

选择题目并开始会话，可运行草稿、使用分级提示并提交。`Ctrl+Enter` 运行查询，`Ctrl+Shift+Enter` 提交评测，`F1` 获取提示。最终判定由确定性结果规则完成，不由 AI 决定。每次练习使用隔离数据库，重置不会修改题库或应用数据库。

## AI 与课程知识

AI 助手仅生成草案，草案还需通过 Java 安全检查并复制到自由 SQL 页后由用户执行。Ollama 不可用时可继续手写 SQL。课程知识支持导入 UTF-8 `.txt`/`.md` 文档并展示来源；删除文档会同步删除索引。

## 备份与恢复

管理员进入“设置 → 版本、备份与恢复”：

1. “立即备份”保存 `app.db` 和演示库，最多保留最近 20 份。
2. 恢复前会校验 SQLite 完整性，并自动备份当前数据。
3. 恢复完成后应用会退出，重新打开即可使用恢复的数据。
4. “恢复内置演示库”只重建演示数据，不影响题库、学习记录和连接设置。

用户数据默认位于 `%LOCALAPPDATA%\SQLTeacher`，卸载应用不会删除该目录。
