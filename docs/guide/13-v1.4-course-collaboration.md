# v1.4 课程协作、反馈与通知

## 1. 使用入口

登录学生、教师或管理员账号后，从主导航进入“课程协作”。所有网络、文件和 AI 操作均在桌面后台线程执行，不阻塞 JavaFX Application Thread。

教师可以：

- 创建、更新、排序、停用或恢复课程、章节和知识点。
- 发布共享题目的不可变版本；更新题目会产生新版本，停用题目不删除历史数据。
- 从指定题目版本创建任务。发布时会冻结题目、数据集、评测规则、知识点和快照哈希。
- 查看提交，生成确定性反馈模板或可选网络 AI 草稿，人工确认后发布结构化反馈。
- 按学生查看知识点掌握度和稳定排序的下一步练习建议。
- 导入或导出格式版本为 1 的原生 JSON 课程题库包。

学生可以：

- 查看本人提交对应的教师反馈和薄弱知识点建议。
- 查看任务发布、临近截止、提交确认和新反馈四类站内通知。
- 在云端暂不可用时读取当前账号最近同步的反馈、建议和通知缓存。

## 2. 版本与历史规则

- 逻辑题目可以有多个发布版本；发布版本本身不可修改。
- 任务只能从启用课程中的启用题目版本创建。
- 已发布任务保存独立内容快照。课程、知识点或题目之后停用或更新，不改变历史任务和提交口径。
- 课程题库导入在单个数据库事务中完成；格式、内容或约束校验失败时不保留部分数据。
- 课程、章节、知识点和教师反馈更新使用版本号；过期版本返回 `CONTENT_VERSION_CONFLICT`。

## 3. 权限矩阵

| 操作 | 学生 | 教师 | 管理员 |
|---|---:|---:|---:|
| 查看本人反馈、掌握度和通知 | 是 | 本人通知 | 是 |
| 查看活动共享课程与题目 | 否 | 是 | 是 |
| 修改课程目录和发布题目 | 否 | 仅本人创建课程 | 是 |
| 从共享题目版本创建班级任务 | 否 | 仅任教班级 | 是 |
| 查看/发布提交反馈 | 仅本人读取 | 仅任教班级 | 是 |
| 查询学生掌握度 | 仅本人 | 仅任教班级 | 是 |

即使调用者知道其他班级的资源 ID，服务端仍会重新校验班级关系。学生离开班级后，旧通知不再返回关联资源内容。

## 4. AI 与隐私边界

- 服务端反馈草稿只包含确定性通过状态、错误码和内容快照哈希，不包含完整 SQL、学生身份、数据库结构或凭据。
- 只有用户已显式配置网络 AI 模型时，桌面端才会请求润色草稿；否则直接使用确定性模板。
- AI 草稿不能改变通过/未通过结论，不能给分，也不会自动发布。
- Provider 失败、超时或返回空内容时自动回退确定性模板。
- 本地缓存按账号隔离，只保存课程展示数据、反馈、掌握度和通知，不保存 Token、密码、API Key 或完整 SQL。

## 5. 数据演进

- 桌面 `app.db` schema 从 5 升至 6，新增 `teaching_content_cache`。
- 云端 schema 记录从 1 升至 2，新增课程目录、题目版本、任务快照、反馈审计、站内通知和幂等操作表。
- 所有新增表通过追加式、可重复初始化建立；旧任务不要求补造快照，只有 v1.4 从共享题目发布的新任务拥有内容快照。
