# v1.5.x UI、主题与设置权限说明

## v1.5.5 UI Foundation 2.0

v1.5.5 在既有浅色/深色主题和角色导航之上增加三层界面基础：

- AtlantaFX 2.1.0 提供标准 JavaFX 控件的现代基础皮肤；项目 CSS 仍负责 SQLTeacher 品牌、页面结构和状态语义。
- `css/foundation/tokens.css` 统一窗口、表面、输入区、边框、文字、强调色和状态色；`components/core.css` 与 `layouts/responsive.css` 分别承载组件和断点覆盖。
- 应用壳根据宽度进入 compact、medium、wide 三种布局。840～1039px 使用 72px 图标侧栏，1040～1359px 使用 196px 侧栏，1360px 及以上使用 232px 侧栏。

首页使用 `TilePane` 自动换列；SQL 练习页不再依赖整页长滚动，而是让编辑器和结果区共享可拖动工作区。全局焦点边框重新可见，键盘状态不会被 CSS 清除。

AtlantaFX 2.1.0 通过 Maven Central 获取，使用 MIT License，项目地址为 <https://github.com/mkpaz/atlantafx>。其 JAR 约 740 KiB，不包含第三方字体、浏览器运行时或本地服务，也不接触 SQL、凭据和教学数据。

## 应用壳与角色导航

v1.5 将 11 个同级横向入口改为左侧分组导航。访客、学生、教师和管理员仍使用 `DesktopCapability` 控制业务页面可见性，但入口按学习、教学/课程反馈、SQL 工具和系统组织。学生看到“学习反馈”和“我的班级”，教师看到“教学工作台”和管理入口。

设置中心属于公共页面，四类身份都拥有 `SETTINGS` 页面能力。页面内使用 `DesktopSettingPermission` 决定具体设置项：

| 权限 | 访客 | 学生 | 教师 | 管理员 |
|---|---:|---:|---:|---:|
| 外观与易用性 | 是 | 是 | 是 | 是 |
| SQL 安全与无限模式 | 是 | 是 | 是 | 是 |
| 本地数据库连接 | 是 | 是 | 是 | 是 |
| 教学默认值 | 否 | 否 | 是 | 是 |
| 本机数据备份恢复 | 否 | 否 | 否 | 是 |
| 云端运维 | 否 | 否 | 否 | 是 |

客户端的隐藏、只读或禁用状态只负责呈现。涉及云端和高影响数据的操作仍由应用服务或服务器再次鉴权。

## SQL 安全与无限模式

设置中心的“SQL 安全”标签提供当前设备级的无限模式，默认关闭。首次及每次重新启用前都会显示破坏性操作警告；确认后，通用 SQL 工作区与学生隔离练习将跳过 SQLTeacher 应用层的危险语句、多语句、只读和二次确认限制。标准模式拦截学生 SQL 时会同时提示此设置入口。

无限模式只影响用户手动提交给执行服务的 SQL，不会让 AI 自动执行 SQL，也不会绕过数据库账号权限、JDBC 驱动能力或操作系统保护。设置保存在 `app-data/sql-safety.properties`；对于不可恢复或共享数据库，应保持标准安全模式。

## 字体与图标

- 现代中文：`Microsoft YaHei UI` → `Microsoft YaHei` → `Segoe UI` 回退。
- 系统默认：`Segoe UI Variable` → `Segoe UI` → `Microsoft YaHei UI` 回退。
- 经典清晰：`Microsoft YaHei` → `SimHei` → `Segoe UI` 回退。
- SQL 编辑器继续优先使用 Cascadia Mono/Consolas 等宽字体。
- 主导航和首页使用项目内 JavaFX `SVGPath` 矢量图标，不再依赖 emoji；图标按钮必须提供可访问文本和提示。

本版本不随包分发第三方字体文件，避免额外字体许可和包体风险；所有字体均使用 Windows 回退栈。

## 主题与偏好

支持浅色、深色和跟随系统三种主题。跟随系统在应用启动时读取 Windows `AppsUseLightTheme`，读取失败时安全回退到深色；也可通过 `SQLTEACHER_SYSTEM_THEME=light|dark` 或 `-Dsqlteacher.system-theme=light|dark` 覆盖，便于测试与受管环境部署。

主题、字体、密度和减少动态效果使用当前 Windows 用户的 Java Preferences 保存。偏好不包含登录令牌、数据库密码、SQL、课程内容或学生数据。配置损坏时按字段回退默认值，不阻止应用启动。

## 核心工作流

- 学生练习页明确展示“选择题目 → 开始练习 → 运行检查 → 提交评测”，支持 `Ctrl+Enter`、`Ctrl+Shift+Enter` 和 `F1`，并阻止并行重复操作。
- 教学工作台将课程/题目/任务、反馈建议和通知拆为标签页；学生身份不可见教师专用标签与编辑区。
- 首页功能卡改为可聚焦按钮，键盘用户可以 Tab 定位并按 Enter/Space 打开。

## 已知限制

- 跟随系统主题在本版本中于启动时读取；应用运行期间更改 Windows 主题后，重新启动 SQLTeacher 即可同步。
- JavaFX 21 不提供网页 CSS 变量和完整的系统动态效果偏好接口，主题使用语义样式表覆盖实现。
- 标准系统对话框由 JavaFX/Windows 控制，部分细节可能与应用主题存在轻微差异，但高风险 SQL 自定义对话框会应用当前主题。
