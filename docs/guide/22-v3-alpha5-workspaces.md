# v3 Alpha.5 课程、练习与数据工作区

> 适用代码版本：`3.0.0-alpha.5`；该代码版本尚未发布

## 课程与知识

“课程与知识”把课程树、知识检索、安全 Markdown 阅读和 Obsidian 导入放在同一工作区。导入必须先提供用户选择的本地根目录并生成预览；预览列出新增、修订、跳过、Wiki 链接和缺失附件，确认后才写入。

Java 会规范化根目录，拒绝符号链接、目录越界、超过 2 MiB 的 Markdown 和超过 10,000 个文件的单批导入。预览令牌绑定文件指纹，有文件在确认前变化时，该文件不会导入。原始 HTML、Dataview JavaScript 和外部资源继续禁用。

## 练习与实验

SQL 练习遵循“选题 → 预览 → 确认 → 作答 → 反馈”。确认前不加载编辑器；运行和提交继续调用 Java 的练习会话与确定性评价服务。

编程实验支持 Java、Python、C 和 C++。界面提供 Monaco 高亮、补全、诊断、`Ctrl+Enter` 运行和取消；Java Runner 继续强制源码、输入、时间、内存、输出、工作区、文件和进程上限。关闭或取消请求时，现有 Runner 负责进程树清理。

## 数据、SQL 与 AI

“数据与 SQL”只接收非敏感连接摘要和结构 DTO，不接收密码或 JDBC 对象。SQL 操作分两步：

1. Java 分析语句并返回风险、原因、行数和超时上限；
2. 只有 Java 判定可执行后才进入执行。需确认语句使用 Java 签发、五分钟有效、绑定连接与 SQL 哈希的一次性令牌。

结果最多读取 500 行，每页最多传输 100 行，默认每页 50 行；后续页从 Java 内存中的十分钟限时缓存读取。底层执行服务仍负责二次风险分析、只读连接限制、超时、结果截断和学习事件审计。

知识 AI 助手使用现有 Java 检索、上下文策略、脱敏、字符预算、Provider 超时和审计服务。回答通过事件分段显示并附引用；无模型、无证据或 Provider 故障时返回确定性降级，不影响课程、练习或 SQL 核心路径。
