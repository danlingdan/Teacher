# SQLTeacher v1.2 教师手册

## 班级与协作教师

教师在“云端教学”中创建班级，选中班级后按邮箱添加教师或学生。填写本地题目 ID、任务标题和可选截止时间后可直接发布任务，再按教学进度编辑、截止、撤回或归档；学生只会看到已发布或已截止任务。归档任务不可再修改。

只有管理员或该班级教师可以维护成员和发布任务；教师只能查看自己参与班级的云端数据。学生不能创建班级、管理成员或发布任务。学生账号被现有教师以“教师”身份加入班级后，服务端会授予教师角色；该用户重新登录后即可看到教师题库、教师看板和班级管理入口。

## 题库管理

“教师题库”支持新建、编辑、复制、启用/停用题目，以及文字格式的题库导入导出。导入使用纯文本 DSL（`===[DATASET]===` 与 `===[EXERCISE]===` 分块，`TITLE:`、`DATASET:`、`SQL:`、`RULE:`、`HINTS:` 等字段）；也可粘贴自由文本先点“AI 解析”生成格式草稿，修改后点“解析预览”由 Java 确定性校验，确认无误再“导入题库包”。导出得到的文字包可复制保存并再次导入。每题应明确知识点、难度、数据集、参考 SQL、判定规则和最多三层提示。导入失败会整批回滚。

### 导入自测与内容约定

“解析预览”和“导入题库包”会对包内每个数据集执行一次导入自测：数据集 SQL 在隔离的临时库中建表，逐题试跑参考答案并验证其满足自身判定规则（行数、结构关键字等）。自测不通过的题目会在预览中标注原因，且无法导入；手工新建/编辑题目的参考 SQL 同样会先自测。数据集 SQL 只允许 `CREATE TABLE`、`CREATE INDEX` 和 `INSERT INTO` 语句，`ATTACH`、`PRAGMA`、`DELETE`、`UPDATE`、`DROP` 等一律拒绝。

题目是学生作答的唯一契约：期望的结果列名必须在题面写明（例如“课程名（列名为 course_name）”），列名判定按数量、名称、顺序严格比较；题面承诺的查询结构（如“使用子查询”）应通过 `KEYWORDS:` 字段兑现。数据集内容变更必须使用新的数据集 ID，不要原地修改。

### 题型体系（QUERY / STATE / SCRIPT / TRIGGER）

自 v3.3 起练习支持四类确定性判分题型，DSL 中用 `TYPE:` 声明，缺省等价 `QUERY`（单条只读 SELECT，参考答案结果集比对）：

- **写操作题（`TYPE: STATE`）**：学生提交一条写语句。参考答案（`SQL:`）应为单条写语句，`VERIFY:` 提供单条 SELECT 验证查询；判分时参考答案与学生语句分别在两份相同初始数据的沙盒库上执行，比对验证查询结果。`ALLOWED:` 可声明允许的语句类别（缺省 `INSERT, UPDATE, DELETE`，可选 `SELECT/CREATE/DROP/ALTER`）；`AFFECTED:` 声明期望影响行数（可选项，声明后作为独立判分分项）。
- **脚本题（`TYPE: SCRIPT`）**：学生提交多语句脚本（按顺序执行，总超时与评测上限不变）。参考答案为脚本，`TXN:` 可要求事务关键字（如 `BEGIN, COMMIT`，作为独立分项）。文件读写、用户/角色管理等禁止类语句在脚本内同样被拒绝。
- **触发器题（`TYPE: TRIGGER`）**：学生提交一条 `CREATE TRIGGER` 定义。参考答案必须是单条 `CREATE TRIGGER`；`PROBE:` 提供触发场景语句（INSERT/UPDATE/DELETE/SELECT 或事务控制），系统在学生触发器就位后执行探针，再用 `VERIFY:` 比对最终状态。

新字段均为可选，旧格式题库包零改动导入。导入自测对四类题型执行与运行时一致的校验：参考答案、验证查询、探针语句会真实执行且必须满足自身规则（行数、关键字、影响行数、事务关键字可满足）；`VERIFY` 缺失、验证查询不是单条 SELECT、探针不可执行等都会被自测拒绝。写类题型的学生作答在一次性隔离沙盒库上进行，不弹工作台确认对话框；禁止类语句在全部题型下硬拦截，学生可随时重置本题数据。

### 得分、对比与个性化反馈（v3.3 W2/W3）

判分结果附带 0–100 的确定性得分：DSL 可用 `WEIGHTS:` 为各分项赋权重（如 `WEIGHTS: rows:75, columns:40`，缺省各分项等权）。得分只用于反馈与学情展示，“全部分项通过才算通过”的语义不变。

- **对比视图（`REVEAL:`）**：题目可声明 `REVEAL: never` / `on-fail`（缺省）/ `always`，控制失败反馈中“期望/实际并排对比”是否展示期望数据行；`never` 时任何 IPC 载荷都不含期望行。提交前任何状态都不会展示期望数据。
- **期望结果形状（`EXPECT_COLUMNS:`）**：列名列表会展示在题面下方，帮助学生核对列名与顺序。
- **索引实验题（`PLAN_KEYWORDS:`）**：声明后验证查询必须使用 `EXPLAIN QUERY PLAN` 语句，判分对计划输出做短语断言（如 `PLAN_KEYWORDS: INDEX idx_score`，注意 SQLite 实际输出为 `USING COVERING INDEX idx_score` 之类的短语）；导入自测会验证参考答案的执行计划满足断言。
- **题库体检**：教师题库页点“题库体检”对库内全部题目批量执行与导入自测同等校验（含四类题型），产出题目级报告，可复制文字报告；只读无副作用。

### 网络题库发布

教师可将题库分发到服务器：在工作台导出（或编辑）得到文字包后，点“发布到服务器”。发布前本地先完成同样的解析与自测，服务器会再次校验并以新的题库版本号存储。学生端在“练习与实验”目录点“题库更新”，即可按清单只下载有变化的题目分块、校验并原子应用；检查更新只获取题库清单，不上传任何学生数据。发布需要服务器管理员权限，未发布成功不影响本地题库。

v3.3 起题库发布支持**多频道**与**多版本**：

- **频道**：发布请求可带频道名（小写字母、数字与横线，缺省 `network`）。每个频道独立维护版本序列，同名题目在不同频道互不影响；`GET /api/v1/bank/channels` 列出服务器全部频道与当前版本。
- **版本回滚**：服务器为每次发布保留完整分块快照。管理员调用 `POST /api/v1/bank/rollback`（或客户端教师工作台的“回滚上一版本”）即可把激活版本切回任意历史版本，对全体客户端即时生效；发布与回滚全程写入 `admin_audit` 审计。
- **客户端订阅**：学生在“设置 → 题库更新”中勾选订阅的频道（缺省仅 `network`）；未订阅的频道不会拉取、不入库。“定时检查题库更新”默认启用（v3.3.2 起，可关闭），每次启动都会检查一次并每 6 小时复查，发现更新只在练习页提示，绝不自动应用、不打断练习。
- **内置内容包**：应用内置两套题库（学校核心数据集 20 题、供应商-零件-工程数据集 10 题），启动时经导入自测后按版本化 upsert 幂等应用。

## 学情看板

“教师看板”展示尝试、提交、通过率、完成情况、常见错误和薄弱知识点。可按日期、题目、知识点、错误类型筛选，并导出带 UTF-8 BOM 的 CSV。导出内容来自当前本机数据，不应公开包含学生信息的文件。

“云端教学”还提供当前班级的成员数、任务数、同步事件数和通过率摘要。教师与管理员可导出服务端生成的 UTF-8 CSV；服务端会再次校验班级管理权限、记录导出审计，并对可能触发电子表格公式的单元格做安全处理。

## 课程资料

导入前确认资料为 UTF-8 文本或 Markdown，且有权在本机使用。检索结果始终显示标题、来源和片段。课程文档不具有系统指令权限，不能放宽 SQL 安全策略或让 AI 自动执行 SQL。

## 课堂准备清单

- 提前安装并启动 SQLTeacher，确认演示库可查询。
- 如需 AI，提前启动 Ollama 并在 AI 助手中选择模型。
- 如需外部数据库，使用专用只读账号并先执行连接测试。
- 课程开始前创建手动备份；结束后按需导出统计，再清理演示学习数据。
- 保留题库导出包和课程资料原文件，应用备份用于本机灾难恢复。
