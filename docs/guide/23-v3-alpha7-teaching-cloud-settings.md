# v3 Alpha.7 教学、云端、设置与迁移状态

> 适用代码版本：`3.0.0-alpha.7`；当前仍为本地开发版本，未发布。

## 教学空间

教师和管理员可进入“教学空间”查看现有题库、启停题目并查看本地练习学情。路由隐藏不是授权依据：Java IPC 会从安全会话重新计算角色，云端写操作还要经过服务器授权。

学生与访客直接调用教师接口会被 Java 拒绝。确定性评价、学习进度和发布版本冲突检查继续由现有 Java 服务负责。

## 班级与云端

- 未登录时显示登录表单，但本地课程、知识、练习、Runner 和 SQL 不受影响。
- 密码只作为一次 IPC 请求交给 Java 登录服务，不进入 Web Storage、日志或前端持久化状态；Java 调用后清零字符数组。
- 登录后先读取本地安全会话和同步队列，不自动访问网络；“刷新班级”和“立即同步”属于显式网络操作。
- 教师与管理员可创建班级，Java 和云端服务端都会检查角色。
- 网络失败进入可恢复降级状态，不清空本地学习事件或待同步队列。

## 设置与环境探测

常用设置直接显示语言、更新检查、动态效果、对比度、通知、计费网络和 SQL 开发者模式。高级区域按需展开，显示 Runner 能力、托管组件、连接状态和存储摘要。

SQL 开发者模式只减少常规确认；禁用语句、多语句、只读连接、高风险确认、执行上限和审计仍由 Java 强制。设置接口不返回密码、令牌、连接字符串或代理凭据。

工具链探测继续覆盖 `java.home`、`JAVA_HOME`、`JDK_HOME`、`PATH` 和已有文档列出的安装位置；缺失组件会显示原因码和来源说明。

“迁移状态”页面读取 Java 生成的功能清单，覆盖学习、知识、练习、数据、教学、云端和设置七个工作区。Alpha.7 不改变生产默认入口、不改变现有 schema 语义，并保留 JavaFX 回退入口。
