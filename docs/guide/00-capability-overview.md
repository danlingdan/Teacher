# SQLTeacher 能力总览

> 适用版本：`3.8.0`（最后核对 2026-09-21，随公开发布同步更新）
>
> 本页回答"产品现在有什么能力"。每项事实以所链接的权威文档为准，本页只做摘要与索引；
> 历史演进见 [发布说明](../releases/README.md) 与 [阶段实施记录](../history/stages/README.md)。

SQLTeacher 是面向计算机类课程的教学平台，**不止于 SQL**：SQL/数据库是第一门、也是打磨最深的学科；
同一套底座上还内置八门计算机学科课程、八种学习活动类型、四语言代码运行与确定式判分，以及账号、
班级、云端同步与教师学情闭环。桌面端离线可用，登录后与云端服务协同。

## 学生工作面

七个正式工作区：今天（学习摘要与下一步动作）、课程与知识（课程树、知识阅读与检索、知识助教）、
练习与实验（SQL 题、课程活动、代码运行、错题本、学习路径）、数据与 SQL（连接管理、SQL 工作台、
元数据/ER 简图/执行计划解读）、教学空间（教师端）、班级与云端（账号与同步）、设置。
细节权威：[用户手册](08-user-manual.md)。

## 学科与课程

- **SQL/数据库主线**：四类确定式判分题型（QUERY/STATE/SCRIPT/TRIGGER，v3.3 起）、两套内置题库、
  学习路径与知识点掌握度。权威：[教师手册·题型体系](09-teacher-manual.md)。
- **内置十二门课程**：八门学科课程（计算机系统、操作系统、计算机网络、程序设计语言与编译、离散数学
  与理论基础、软件工程、AI 与数据基础、计算机安全基础）与四门实践课程（数据管理——SQL 主线练习载体、
  数据结构与算法、编程语言基础、综合项目）。课程与活动定义随本地数据库种入，覆盖全部八种活动类型，
  配套可离线完成的确定性模拟与实验单元（指令周期、最短作业优先调度、分组交付、词法分析流水线、
  数学归纳法、混淆矩阵评价、CI 质量门禁、不可信输入防御链等）。权威：
  [离线系统模拟实验](16-offline-simulation-labs.md)、[专业基础离线实验](17-professional-foundation-labs.md)、
  [学习活动与兼容契约](19-beta-learning-contracts.md)。
- **官方知识包**：《数据库系统概念》与《托马斯微积分》两套课程知识树随安装包分发，支持云端/离线
  整包更新；教师可导入、修订、发布并维护检索索引。学生检索列表走 FTS5 全文检索；知识助教走混合
  检索（FTS + 本地向量，未安装本地向量模型时自动降级 FTS）。权威：
  [用户手册·课程知识与教师工作](08-user-manual.md)。

## 八种学习活动与证据

活动类型冻结为八种：SQL、测验（QUIZ）、追踪（TRACE）、模拟（SIMULATION）、代码（CODE）、
实验（LAB）、项目（PROJECT）、主动阅读（READING），统一走提交→评价→证据→诊断生命周期；
诊断证据按活动类型加权（阅读最低、项目最高，低权重证据不能靠重复刷阅读压过真实执行）；
全部评价由 Java 确定性代码完成。权威：[Beta 学习活动、证据与兼容契约](19-beta-learning-contracts.md)。

## 代码运行与判分

- 支持 Java、Python、C、C++ 四种语言的单文件程序运行：stdin 输入、墙钟与输出限额、可取消。
- **双轨设计**：本地 IDE 直跑是日常主路径（继承本机环境与权限，学生自负）；**提交判分**走
  WSL2 一次性隔离沙箱（无网络、一次性 tmpfs 根、cgroup 内存/CPU 限额、stderr 脱敏），
  环境不满足时 fail-closed 拒绝判分，绝不回退为无隔离执行。
- 编程题按测试用例（标准输入→期望输出，归一化后精确比对）判分，编译失败/运行错误/超时/内存超限/
  输出超限各有独立失败原因与教学反馈。判分入口是编程题（CODE 活动）的提交动作；"自由编程"标签页
  只做本地运行、不判分。权威：[本地学习 IDE 与代码 Runner 配置](15-local-ide-and-runner-setup.md)、
  [代码 Runner 威胁模型](../plans/2026-08-09-v2-alpha4-code-runner-threat-model.md)、
  [阶段门禁验收](../acceptance/2026-08-09-v2-alpha4-stage-gate.md)。

## SQL 执行与 AI 安全

所有 SQL 经 Java 单语句解析、风险分析、只读边界、高风险确认、超时、结果上限与审计；本地安全模式
默认教学模式且 fail-closed。多语句仅按题型白名单在一次性沙盒库执行；用户/角色管理与写文件类语句
在全部路径禁止。NL2SQL 只产出草稿、永不自动执行；模型永远不获得 JDBC `Connection`；AI 不参与判分，
不掌管掌握度等权威学习状态。权威：[SQL 与 AI 安全规范](05-sql-and-ai-safety.md)、
[用户手册·数据库、SQL 与 AI 安全](08-user-manual.md)。

## 教师端

题库 DSL 与导入自测、网络题库发布（多频道、多版本、回滚与审计）、班级与任务管理（8 位班级码、
教师升级码）、学情看板与 CSV 导出、班级学情总览、学生学情画像与学生提交内容查看（v3.7.0 起）、
干预队列。权威：[教师手册](09-teacher-manual.md)、[云端服务部署](12-cloud-service-deployment.md)。

## 账号与云端

离线学习无需登录；登录后同步班级、任务与学习事件。上传内容经白名单约束（不含结果集数据、AI 回答
全文与密码类信息），仅本班教师可见，教师查看明细记入审计。v3.8.0 账号体系闭环：邮箱验证码找回/换绑、
显示名修改、设备会话管理、未登录本机记录并入账号、教师升级码。云端服务提供认证、班级、题库频道、
课程/知识包分发、学习事件同步、更新清单、语义检索（Qdrant + fastembed，模型 bge-small-zh-v1.5，
已在生产运行）与 SMTP 邮件。
权威：[用户手册·云端账号与班级](08-user-manual.md)、[云端服务部署](12-cloud-service-deployment.md)、
[运维记录索引](../operations/README.md)。

## 项目学习与内容分发

项目制实践与成果档案（版本化提交、完整性自动检查；评审反馈经云端作业反馈链路给出，教师可 AI 起草）、
带许可合规的安全课程包
（服务端预检、SHA-256 校验、显式许可接受）、Cloud 2.0 同步边界（最小元数据白名单、拒绝源码与
敏感字段、离线 Outbox）。权威：[项目学习、课程包与 Cloud 2.0](18-project-course-package-cloud2.md)。

## 桌面形态与更新

Tauri/React 壳 + Java sidecar 单进程模型：Rust 只负责进程生命周期与孤儿兜底，业务与安全规则
全部在 Java。IPC 合同为 v1 additive。签名更新链：启动自动检查、断点续传、官方中继回落、
同版本重装入口（v3.5.4 起）。权威：[Tauri 桌面端架构](24-tauri-desktop-architecture.md)、
[LocalApp IPC v1 合同](21-local-app-ipc-v1.md)、[Windows 安装、升级与卸载](10-installation-and-upgrade.md)。

2. 本页不复制细节：每项能力只有一个权威文档，本页只写一句话摘要加链接。
3. 能力下线时从正文移除并在版本发布说明中说明，不留幽灵条目。
