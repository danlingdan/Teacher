# 项目学习、课程包与 Cloud 2.0

> 适用版本：`2.0.0-alpha.7` 及后续兼容版本

## 项目学习与成果档案

在课程地图进入“软件工程 → 项目制实践 → 版本化项目交付”。逐项确认里程碑，填写交付证据摘要和反思后提交。自动通过只表示材料完整，界面会持续显示“等待教师评审”。每次提交生成新的版本。

“教学内容 → 成果档案”仅查询当前身份的数据。私密导出需要当次确认，文件只包含版本、评价状态、原因码和 artifact SHA-256；不会包含源码，也不会公开分享。

## 安全课程包

教师导出课程时必须填写 SPDX 标识或明确许可说明。生成的格式 2 JSON 包包含原始课程 payload 和 SHA-256。

导入时应用先请求服务端预检，展示课程版本、许可、数量、哈希和冲突状态。只有明确接受许可后才提交同一哈希。格式未知、过大、篡改、预检后变化或同版本不同内容会被拒绝；重复操作号安全返回原结果。

## Cloud 2.0 同步边界

客户端先读取能力清单；缺少 `ARTIFACT_SYNC_V2` 时保持本地功能并停止新同步。同步范围限定为课程版本、作业快照、最小评价摘要、反馈和项目元数据。服务端拒绝源码、内容、仓库 URL、路径、令牌、密码和密钥字段。

本地 Outbox 在网络或服务失败时保留。服务端显式返回接受、重复或冲突；冲突不会静默覆盖。生产 API 地址仍为 `https://api.sqlteacher.tech`，本候选没有执行生产部署。
