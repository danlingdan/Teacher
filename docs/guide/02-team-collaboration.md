# 单人主线协作机制

SQLTeacher 采用单人串行开发和 `main` 直线历史。早期五人分工方案已归档，不再作为当前协作模型。

## 工作顺序

1. 从当前代码、测试、`pom.xml` 和 Git 状态确认基线。
2. 先做最窄的完整改动，再运行聚焦测试。
3. 跨模块、schema、安全或发布相关改动必须运行完整测试。
4. 公共行为变化同时更新现役指南、验收记录和发布说明。
5. 提交、推送、标签、Release 和生产部署分别取得明确授权。

## 责任边界

- Java 领域与应用层拥有确定性学习规则、安全策略和持久化语义。
- Tauri/React 是唯一桌面端，通过 LocalApp IPC 调用 Java 核心。
- AI 输出与导入内容均不可信；SQL 必须经过 Java 强制安全链路。
- 云端操作先只读检查，再备份、定义回滚并验证 HTTPS 健康状态。
- 发布使用 `main`，不引入 PR 流程，除非当前任务明确要求。

## 变更门槛

合并到本地工作成果前必须确认：范围内文件完整、测试与文档一致、无秘密或运行数据、无绕过 SQL 安全边界的路径。当前详细规则以根目录 [AGENTS.md](../../AGENTS.md) 为准。
