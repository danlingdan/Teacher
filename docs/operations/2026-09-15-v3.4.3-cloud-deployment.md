## 回滚方案

- 服务回滚：`ln -sfn /opt/sqlteacher/releases/3.4.2 /opt/sqlteacher/current.new && mv -T /opt/sqlteacher/current.new /opt/sqlteacher/current && systemctl restart sqlteacher-cloud`。
  v3.4.3 无云端 schema 变更，回滚到 3.4.2 后知识库端点回到 404（桌面端提示"云端暂未提供"），其余功能不受影响。
- 数据回滚：恢复升级前备份 `/opt/sqlteacher/backups/cloud-20260915T134902Z.db`（先做当前库副本）。
- 知识库回滚：删除 `/etc/sqlteacher/cloud.env` 中两个 `SQLTEACHER_KNOWLEDGE_BUNDLE_*` 变量并重启，端点回到 404。
