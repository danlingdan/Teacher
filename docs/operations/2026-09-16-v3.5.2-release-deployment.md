## 更新清单部署（ECS）

本次为内容文件替换，服务端 jar 与 `/etc/sqlteacher/cloud.env` 均未变更，未重启服务
（清单按请求实时读取）。

1. 下载 Release 资产 `update-manifest.json`，base64 解码校验：version=3.5.2，installer/portable
   URL 指向 `v3.5.2` tag；installer/portable SHA-256 与 Release `SHA256SUMS.txt` 一致。
2. paramiko SFTP 上传至 `/opt/sqlteacher/shared/.update-manifest.json.incoming-v3.5.2`，
   远端 `sha256sum` 与本地一致。
3. 回滚备份：`cp -p /opt/sqlteacher/shared/update-manifest.json
   /opt/sqlteacher/shared/update-manifest-3.5.1.json`（替换前线上值确认已解码为 3.5.1，
   备份 sha256 `e7c99730…`）。
4. 原子替换：`install -o root -g sqlteacher -m 0640 /opt/sqlteacher/shared/.update-manifest.json.incoming-v3.5.2
   /opt/sqlteacher/shared/update-manifest.json`，替换后远端哈希复核一致，属主权限
   `root:sqlteacher 640`。
5. 公网验证：`GET https://api.sqlteacher.tech/api/v1/app/update-manifest` 解码为 3.5.2，
   installer URL 与 Release 资产一致，签名信封完整（keyId `release-2026-01`），
   rollout 100% 未暂停。

## 回滚步骤

1. `cp -p /opt/sqlteacher/shared/update-manifest-3.5.1.json /opt/sqlteacher/shared/update-manifest.json`
2. 公网端点应解码回 3.5.1（该清单指向 v3.5.1 Release 资产，资产仍在，无需其他操作）。

## 已知限制

- **存量客户端无法应用内升级到 3.5.2**：3.5.1 及更早版本的下载白名单仍缺少
  `release-assets.githubusercontent.com`，应用内下载 3.5.2 会在重定向轮被自家校验拒绝
  （且其失败文案为被吞后的笼统提示）。存量用户需从 GitHub Release 页面手动下载安装；
  3.5.2 起客户端可恢复正常的应用内更新闭环——这正是本版本修复的问题。
- `V111AccountStoreTest.resetTokenIsInvalidatedAfterFiveFailedAttempts` 的偶发失败为既有
  测试缺陷（`Files.list` 顺序假设），与本次发布无关，留待后续版本修正。
