## 更新清单部署（ECS）

本次为内容文件替换，服务端 jar 与 `/etc/sqlteacher/cloud.env` 均未变更，未重启服务
（清单按请求实时读取）。

1. 下载 Release 资产 `update-manifest.json`，base64 解码校验：version=3.5.1，installer/portable
   URL 指向 `v3.5.1` tag；installer/portable SHA-256 与 Release `SHA256SUMS.txt` 一致，尺寸与
   Release 资产元数据一致。
2. paramiko SFTP 上传至 `/tmp/update-manifest-3.5.1.json`，远端 `sha256sum` 与本地一致
   （`e7c99730…`）。
3. 回滚备份：`cp -a /opt/sqlteacher/shared/update-manifest.json
   /opt/sqlteacher/shared/update-manifest-3.5.0.json`（替换前线上值确认已解码为 3.5.0）。
4. 原子替换：`install -o root -g sqlteacher -m 0640 /tmp/update-manifest-3.5.1.json
   /opt/sqlteacher/shared/update-manifest.json`，替换后远端哈希复核一致，属主权限
   `root:sqlteacher 640`。
5. 公网验证：`GET https://api.sqlteacher.tech/api/v1/app/update-manifest` 解码为 3.5.1，
   installer URL/尺寸/SHA-256 与 Release 资产一致，签名信封完整（keyId `release-2026-01`），
   rollout 100% 未暂停。

## 回滚步骤
