## 更新清单原子替换（ECS）

1. 下载 Release 资产 `update-manifest.json`，本地解码核对：`version=3.10.0`，
   `installerUrl/Size/Sha256` 与 Release 资产逐项一致（安装包 `0fd78ecb…`）。
2. paramiko 部署（凭据运行时读自 gitignored `.secrets/ecs.env`，本文不记录任何值）：
   SFTP 上传至 `/tmp/update-manifest.json.v3.10.0` → 服务器端 `sha256sum` 校验
   （`63f53004…ffa`，与本地一致）→ 保留上一版备份
   `/opt/sqlteacher/shared/update-manifest.json.3.9.0.bak` →
   `install -o root -g sqlteacher -m 0640 /tmp/... /opt/sqlteacher/shared/update-manifest.json`
   原子替换 → 终态哈希与权限（0640 root:sqlteacher）确认。清单按请求读取，无需重启服务。
3. 临时文件已清理。
