## 更新清单原子替换（ECS）

1. 下载 Release 资产 `update-manifest.json`，本地解码核对：`version=3.12.0`、channel `stable`，
   `installerSha256`/`portableSha256` 与 Release `SHA256SUMS.txt` 一致。
2. paramiko 部署（凭据运行时读自 gitignored `.env/aliyun-ecs.txt`，本文不记录任何值）：
   SFTP 上传至 `/tmp/update-manifest.json.v3.12.0` → 服务器端哈希一致 → 上一版清单备份为
   `/opt/sqlteacher/shared/update-manifest.json.3.11.0.bak` → `install -o root -g sqlteacher -m 0640`
   原子替换 → 终态哈希一致、权限 0640 root:sqlteacher 确认。清单按请求读取，无需重启服务。
