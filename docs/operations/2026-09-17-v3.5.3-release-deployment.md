## 更新清单部署（ECS）

本次为内容文件替换，服务端 jar 与 `/etc/sqlteacher/cloud.env` 均未变更，未重启服务
（清单按请求实时读取）。

1. 下载 Release 资产 `update-manifest.json`，base64 解码校验：version=3.5.3，installer
   URL 指向 `v3.5.3` tag；installer/portable SHA-256 与 Release `SHA256SUMS.txt` 一致。
2. paramiko SFTP 上传至 `/opt/sqlteacher/shared/.update-manifest.json.incoming-v3.5.3`，
   远端 `sha256sum` 与本地一致。
3. 回滚备份：`cp -p /opt/sqlteacher/shared/update-manifest.json
   /opt/sqlteacher/shared/update-manifest-3.5.2.json`（替换前线上值确认已解码为 3.5.2，
   备份 sha256 `1c8f1d59…`）。
4. 原子替换：`install -o root -g sqlteacher -m 0640 /opt/sqlteacher/shared/.update-manifest.json.incoming-v3.5.3
   /opt/sqlteacher/shared/update-manifest.json`，替换后远端哈希复核一致，属主权限
   `root:sqlteacher 640`。
5. 公网验证：`GET https://api.sqlteacher.tech/api/v1/app/update-manifest` 解码为 3.5.3，
   installer URL 与 Release 资产一致，签名信封完整（keyId `release-2026-01`）。

## 回滚步骤

1. `cp -p /opt/sqlteacher/shared/update-manifest-3.5.2.json /opt/sqlteacher/shared/update-manifest.json`
2. 公网端点应解码回 3.5.2（该清单指向 v3.5.2 Release 资产，资产仍在，无需其他操作）。
