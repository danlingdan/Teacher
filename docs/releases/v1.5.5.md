# SQLTeacher v1.5.5

v1.5.5 是桌面 UI Foundation 维护版本，不改变 SQL 安全、数据库、AI、课程协作或云端权限边界。

## 新增与改进

- 引入 AtlantaFX 2.1.0 作为标准 JavaFX 控件的现代基础皮肤。
- 新增语义设计令牌以及 foundation/components/layouts 分层样式资源。
- 新增 compact、medium、wide 三档窗口布局；紧凑模式使用图标侧栏并保留 Tooltip 和可访问文本。
- 主窗口最低宽度从 960px 调整为 840px。
- 首页任务卡使用自动换列布局。
- SQL 练习页改为可拖动的编辑器/结果工作区，主要动作和反馈不再被整页长滚动分隔。
- 恢复清晰的键盘焦点边框，统一按钮、表单、列表、表格、标签页和导航状态。

## 依赖与许可

- AtlantaFX 2.1.0，MIT License，约 740 KiB JAR；不包含第三方字体或浏览器运行时。
- 现有 JavaFX、SQLite、AI 和云端运行边界不变。

## 已知限制

- 其他复杂管理页面已获得新的控件和语义样式基线，但结构性响应式重排仍需后续逐页完成。
- 跟随系统主题仍在应用启动时读取，运行期间修改 Windows 主题后需要重启。
