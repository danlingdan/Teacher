# SQLTeacher v3.3.3

> 发布日期：2026-09-13（已公开，GitHub Release Latest 见 releases/README）
>
> v3.3.3 集中修复教师与学生在班级与云端、练习与实验两个工作区反馈的可用性问题（对应 GitHub issue #20–#26），并补齐 DDL 类考点的出题指引。

## 主要变化

### 练习与实验

- **搜索框中文输入修复（#25）**：练习目录的"搜索题目或知识点"输入框不再把每个按键同步写回 URL，中文输入法合成期间被打断导致的乱码消除；搜索词改为 300ms 防抖后生效，顺带把目录查询从每键一次降为一次停顿一次，且切换搜索词后自动回到第一页。难度/状态筛选变化同样重置分页。
- **查询题作答指引（#22）**：查询题运行与提交时若提交了非 SELECT 语句（如 `GRANT ...`），提示文案会明确给出 `SELECT '语句' AS answer` 的标准书写方式。`GRANT`/`REVOKE` 等用户与角色管理语句维持禁止执行的既有安全边界。

### 班级与云端

- **添加成员可选目标班级（#20）**："添加成员与创建任务"面板内新增"目标班级"下拉，并在按钮旁显示新成员将加入的班级；班级切换列表的班级名改为常显链接样式并带"当前班级"徽标，不再像纯文本。
- **班级页首屏自动拉取云端班级（#23）**：打开"班级与云端"后若本地没有班级数据，会自动刷新一次云端班级；"创建并发布任务"等入口不再因首屏列表为空而看似不存在。
- **班级成员名单（#26）**：教师可在班级卡片展开"成员名单"，查看每位成员的姓名、角色与邮箱。该能力依赖云端服务新增的 roster 接口；云端服务未更新时显示降级提示，不影响其他功能。
- **云端写操作失败原因透明化（#21）**：添加章节/知识点、创建班级/课程等云端写操作失败时，透传真实原因（云端不可达、登录过期等），不再统一显示"Local application operation failed"；打开课程若来自离线缓存，会显示警示条提示写操作可能失败。

### 出题与题库

- **DDL 考点指引（#24）**：出题表单的"参考 SQL"字段补充说明——查询题参考答案必须为单条只读 SELECT；`CREATE VIEW` 等视图、表定义类考点使用题库文本导入的 `TYPE: STATE` + `ALLOWED: CREATE`（或 `TYPE: SCRIPT`）承载（引擎自 v3.3 起即支持，本次补齐出题处的可发现性与教师手册说明）。

## 兼容性说明

- `cloud.class.roster` 为 v1 IPC 合约新增白名单方法与云端附加端点（`GET /api/v1/classes/{id}/roster`，仅班级教师与管理员可访问）；旧版云端服务不提供该端点时，桌面端成员名单显示降级提示，其他功能不受影响。
- 云端错误透传为附加行为，错误 `code`/`message`/`retryable` 随既有错误通道返回，前端按场景映射中文提示。
- 云端 roster 接口需云端服务随本仓库代码另行部署后生效；桌面端本次发布不包含云端部署。
