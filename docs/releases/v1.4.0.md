# SQLTeacher v1.4.0

SQLTeacher v1.4.0 是课程内容协作与个性化反馈版本。

## 新增功能

- 课程、章节与知识点目录，支持排序、乐观锁、停用和恢复。
- 云端共享题库与不可变发布版本，支持知识点筛选和原生 JSON 事务导入导出。
- 从题目版本创建任务内容快照，固定数据集、评测规则、知识点和 SHA-256 哈希。
- 教师结构化反馈、版本冲突保护、反馈审计和学生本人隔离读取。
- 基于确定性提交结果的知识点掌握度和可解释练习建议。
- 任务发布、临近截止、提交确认和新反馈四类幂等站内通知。
- “课程协作”桌面页面，全部网络、文件和 AI 操作在后台线程执行。
- 网络 AI 反馈草稿及确定性模板降级；草稿必须由教师确认后发布。
- 当前账号隔离的课程、反馈、掌握度和通知本地缓存。

## 数据升级

- 桌面 `app.db` schema：5 → 6，新增 `teaching_content_cache`。
- 云端 schema：1 → 2，新增课程目录、题目版本、任务快照、反馈、通知和幂等操作数据域。
- 课程题库 JSON 导入使用单事务，失败不保留部分内容；重复操作 ID 返回原导入结果。
- v1.3 旧任务继续兼容；v1.4 新建快照任务不受后续题库更新或停用影响。

## 安全与权限

- 学生只能读取自己的反馈、掌握度和通知；教师只能操作任教班级和本人创建的课程。
- 服务端对快照、反馈、掌握度和通知资源重新校验班级关系，不能通过其他班级 ID 绕过授权。
- AI 不参与判分，不接触 JDBC，不接收完整 SQL、学生身份、凭据或数据库结构。
- 本地缓存不保存 Token、密码、API Key 或完整 SQL；正式云端地址继续强制 HTTPS。

## 已知边界

- v1.4 不是正式在线考试或监考平台，提交结果不用于高风险官方考试。
- 站内通知不发送邮件、短信或操作系统推送。
- 网络 AI 由用户自行配置；未配置或不可用时使用确定性反馈模板。
- 安装器尚未代码签名，请从正式 GitHub Release 下载并校验 `SHA256SUMS.txt`。

## 发布验证

- 267 项自动化测试全部通过。
- Windows EXE、便携 ZIP、app-image 和 SHA-256 清单构建并独立复核通过。
- 生产云服务已切换到 v1.4.0，升级前备份完整性、服务健康、cloud schema 2 和真实 HTTPS 认证 API 验证通过。
