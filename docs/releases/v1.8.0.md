# SQLTeacher v1.8.0

v1.8.0 将原有本地文档检索升级为可组织、可发布、可追溯的课程知识中心，并把知识资料、练习和 v1.7 确定性学习诊断连接起来。

## 主要更新

- 新增 app schema 8：课程知识文章、不可变修订、知识点关联与身份所有者边界。
- 教师可一次选择多份 UTF-8 Markdown/TXT 资料，绑定课程、章节和知识点；新导入内容默认私有。
- 支持生成新修订、查看当前正文与历史版本数量，以及私有、发布、停用状态转换。修订已发布文章后会自动回到私有状态，避免未审核内容直接对学生可见。
- 学生只读取已发布条目，可按课程、章节和知识点限定 FTS5 检索，并从知识文章进入关联练习。
- v1.7 学习队列在没有直接练习但存在薄弱知识点时，可跳转到对应知识检索。
- AI 课程解释发送前展示字符数和来源；模型只能引用本次检索片段，未知引用或 Provider 故障会降级为可核验的本地检索摘要。

## 安全与隐私

- 私有知识按当前本地身份隔离，不因登录、建课或使用 AI 自动上传。
- 学生端不显示知识编排操作，也不能读取其他身份的私有条目。
- AI 上下文只允许学生问题和限长知识片段；既有 SQL 风险、确定性评测和掌握度规则不受模型输出影响。
- 课程正文不写入 AI 历史审计，审计仍只记录任务元数据。

## 兼容性与边界

- 支持从 schema 7 追加升级到 schema 8，原题库、练习、任务、反馈、诊断与旧知识文档保持不变。
- 本版本的课程知识发布与缓存为桌面本地优先实现；不新增云端课程知识 API，也不自动同步私有全文。
- 支持 `.txt`、`.md`、`.markdown`；PDF、Office、OCR、向量数据库和联网知识搜索不在本版本范围。
