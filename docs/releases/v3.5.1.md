## 主要变化

### 稳定性修复

- **更新下载重定向泄漏**：`SecureUpdateService` 跟随 302 重定向时，被跳过的 3xx 响应体现在用
  try-with-resources 立即关闭；此前一次下载最多泄漏 3 个流/连接。
- **AI 任务历史无痕丢失**：`FileAiTaskHistoryService` 遇到损坏的历史文件时，此前静默清空且下一次
  保存直接覆盖；现在记 warn 日志（只记异常类名，不落文件内容）并把损坏文件改名为 `.corrupt`
  隔离（与 `AtomicJsonFile` 既有模式一致），保留可人工恢复的数据。
- **云同步状态原子写**：`DefaultCloudLearningSyncService` 的状态文件写入改为临时文件 +
  `ATOMIC_MOVE` 原子替换（不支持时降级常规替换），进程崩溃不再可能留下截断的半写文件。
- **静默吞异常补日志**：云会话刷新遇到非 401/403 的瞬时错误时补 info 日志（此前"莫名掉登录"
  无迹可查）；`AtomicJsonFile` 损坏文件隔离失败补 debug 日志。
- **UI 监听与定时器清理**：更新下载进度事件在组件卸载时退订（此前下载中途关闭页面会残留监听）；
  Toaster 的 toast 自动关闭定时器在卸载时统一清理，消除卸载后 setState 隐患。

### 性能优化

- **SQL 风险分析热路径**：文件读取函数正则按方言族一次性编译缓存，触发器体检测、注释剥离、
  管理语句匹配等 9 处每次分析都重新编译的正则提升为静态常量；`SqlStructureMatcher` 关键字匹配
  增加 Pattern 缓存。风险分析语义完全不变（判定结果与既有全部安全测试一致）。
- **重复对象创建**：练习文本草稿解析与题库章节 JSON 编码改为共享静态 `ObjectMapper`，
  不再每次调用新建。
- **云端同步/管理查询**：同步下载页导入由每条记录开一条连接改为单连接复用预编译语句
  （`insert or ignore` 逐条计数语义不变）；管理端用户列表的角色查询由每用户一条 SQL 合并为
  一次分组预加载。
- **UI 渲染热点**：SQL 结果表（最多 500 行）与 Schema 样例表格 memo 化，编辑器输入等父级状态
  变化不再触发全量重渲染；知识库搜索高亮的正则按查询词缓存；教学工作台练习过滤增加 `useMemo`。

### 清理

- 删除全仓库零引用的死导出 `LiveRegion` 组件及其 `.sr-only` CSS；`TEACHING_NOTE_MARKER`、
  `defineSqlTeacherEditorTheme` 收窄为模块私有。
- 三处重复的"复制到剪贴板 + toast"流程收敛为 `shared/clipboard.ts`；两处重复的 datetime-local
  格式化收敛为 `shared/datetime.ts`；消除 2 处 TypeScript 非空断言。

### 打包修复

- **知识库 zip 只带一个版本**：`package-v3.ps1` 向 Tauri 暂存目录复制前先清理旧版本产物
  （版本号在文件名里，`Copy-Item -Force` 无法覆盖旧 zip，导致 v3.4.4 起的安装包同时携带
  1.0.0 与 1.0.1 两个知识库 zip、白白多出约 21 MB），并在暂存后断言"恰好一个 zip"，异常直接
  终止打包。全新安装的首启导入不再先完整导入 1.0.0 再立即重导 1.0.1。

## 兼容性说明

- **桌面数据库 / IPC / 题库 DSL**：无任何变更；契约版本不变，无新端点。
- **SQL 安全**：无边界变化。风险分析与结构匹配仅将重复编译的正则提升为静态常量，分析结果
  语义不变；多语句阻断、高风险确认、禁用类清单全部由既有测试守护。
- **行为差异**：损坏的 AI 任务历史文件会隔离为 `*.corrupt` 并记日志（此前静默清空）；云同步
  状态目录在写入瞬间可能出现同名 `.tmp` 中间文件（写入后原子替换消失）。
- **云端**：无 schema 变更、无新端点；管理端用户列表接口返回内容不变（角色集合语义一致）。
- **更新通道**：本版本经签名 update-manifest 正常下发，公网端点应从 3.5.0 切换到 3.5.1。

## 已知限制与后续积压

- CloudPage / SettingsPage 等千行级页面组件的 memo 化拆分属于分阶段重构，本版只做了结果表等
  最热点的定向优化，整体拆分留待后续版本。
- `maskQuotedText` 在同一分析内的多次重算因属行为敏感的安全代码，本版保持保守未合并为单遍扫描。
- `MysqlReadOnlyIntegrationVerifier` 的控制台输出为本地一次性 CLI 验证器的既定输出方式，保持原样。
