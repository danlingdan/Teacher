> 发布日期：2026-09-16（已公开，GitHub Release Latest 见 releases/README）
>
> v3.4.4 是"体验补齐"版本，交付 [v3.4.4 计划](../plans/2026-09-15-v3.4.4-plan.md) 的 KUI/CTB/AIS 三组任务，并吸收三轮用户预览反馈（计划第 8–10 节）。亮点：知识助教独立子窗口与知识侧栏单一折叠树、数据库连接入口顶栏化并支持自动列出数据库、本地/网络 AI 模型设置在设置页回归、LaTeX 与加粗渲染容错、官方知识库更新入口对全角色开放。SQL 安全边界未改动。

## 主要变化

### 知识页与知识助教（KUI-1…4 + 预览反馈）

- **阅读区占满主列**：知识助教不再内联排在正文之下；「知识助教」按钮打开**独立子窗口**（Tauri WebviewWindow，440×720），自动携带当前文档上下文（课程/章节/标题），支持连续追问、生成取消（桥端不支持中断时自然完成）、清空对话；子窗口与主窗口主题观感一致（外观应用逻辑抽为 `useAppearanceEffects` 共用）。
- **侧栏单一导航树**：课程 → 章节 → 文档双层折叠（默认展开、当前文档高亮），移除与课程树重复的平铺文档列表与分页器；按「第 N 部分、第 N 章」数字自然排序。
- **检索体验**：结果关键词高亮（分片渲染，不使用 `dangerouslySetInnerHTML`）、结果计数与「清除」、每条标注所属课程/章节（overview 既有字段映射，不加 IPC）、无结果给换词引导。
- **文档阅读头部**：标题 + 课程/章节/版本与「标记为已读」「知识助教」同行；阅读卡占满工作区高度，不再有大片空白。
- **渲染容错**：Obsidian `\(…\)`/`\[…\]` 数学定界符自动转 `$`/`$$`（围栏与行内代码先摘出再还原，不误伤代码）；「**加粗 **」闭合前多余空格自动折叠。
- **图片加载排队**：官方文档插图改为小并发队列（同时 2 个）经桥读取——修复一篇文章多图并发触发桥端 `BUSY` 拒绝导致的整页"图片不可用"；失败占位显示桥端错误码（如 `KNOWLEDGE_ASSET_NOT_FOUND`）。

### 数据库连接顶栏化与表结构独立（CTB-1…3 + 预览反馈）

- **顶栏连接入口**：通知按钮旁新增连接 chip——常态显示当前连接名称与方言（只读连接带标签），无连接时显示醒目"连接数据库"引导。点开清单：点行即设为当前连接，行内编辑/复制/删除（builtIn 隐藏复制与删除，删除需确认），底部「新建连接」打开对话框表单（v3.4.3 傻瓜化表单整体迁移：常用类型一键、端口自动填、文件型单字段、高级选项折叠）。清单行显示连接目标详情（文件名或主机:端口/库），内置「应用数据库」「SQLite 演示数据库」与自建连接一眼可辨。
- **数据页侧栏纯表结构**：移除页内连接表单，侧栏只留当前连接指示、管理按钮（唤起顶栏同一面板）与表结构树；`?connection=` 深链保留。
- **当前连接单轨化**：连接列表提升为共享查询，页内视图只认后端 `selected`；顶栏切换、深链统一经 `data.connection.select` 写全局选中。
- **列出数据库**：新增 IPC `data.connection.databases`——按方言执行目录查询（MySQL 族 `SHOW DATABASES`、PostgreSQL 族 `pg_database`、SQL Server `sys.databases`、Oracle/达梦 `all_users`、Db2 `syscat.schemata`，过滤系统库），表单内显式下拉选择（原生 datalist 会按输入前缀过滤成空弹层，已弃用）；失败/文件型返回空列表加指引文案，不阻塞手输。空密码自动复用本进程已验证的会话凭据。

### 本地/网络 AI 模型设置回归（AIS-1…2）

- v3.0 重写时未迁移的"本地 Ollama / 网络 AI"配置能力在设置页回归：新增「AI 模型」面板——显示当前生效通道，网络供应商（OpenAI 兼容）的新建/编辑/删除、启用（切网络 AI）/停用（回本地 Ollama）、「测试连接」（实时探测并列出可用模型）。
- 后端复用既有 `AiProviderProfileService`（多 Profile 持久化 + API Key DPAPI 加密）与 `HttpAiProviderProbeService`；新增 IPC `ai.provider.list/save/activate/deactivate/remove/test`（additive）。**凭据只写不读**：列表与测试响应不回传任何密钥材料（含 DPAPI 引用名），保存/测试后凭据数组即清零，并有测试锁定。
- 端点校验沿用既有规则：仅 HTTPS（本机 http://localhost 亦可），拒绝携带用户信息/查询串的 URL。网络 AI 失败自动回落本地 Ollama，不影响本地学习主流程。

### 官方知识库更新入口全角色开放（预览反馈）

- 侧栏底部新增「知识库更新」（默认折叠，所有角色可见）：已安装版本、「检查云端更新」（有新版时「下载并安装」）、「手动导入…」本地 zip。教师管理折叠区不再重复放置官方知识库面板；人工 Obsidian 导入、单篇修订/删除/可见性等教学管理操作仍限教师/管理员（`KnowledgeApiSectionTest` 已按新行为反转断言）。
- 构建脚本修复后的首个 bundle 产物为 **1.0.1**（title 恢复为「数据库系统概念」，章节=第 N 部分，117 张附件齐全）；v3.4.3 分发的 1.0.0 因构建脚本变量名大小写冲突导致 manifest 标题被污染（f7c5e40 已修脚本，本轮重建产物）。

## 兼容性说明

- **桌面数据库**：无 schema 变更（仍是 Migration 24）。
- **云端**：无 schema 变更；云端知识库已同步更新为 **1.0.1**（修正版，见 [云端更新记录](../operations/2026-09-16-v3.4.4-knowledge-bundle-1.0.1-cloud-update.md)），v3.4.3 客户端「检查更新」即会提示 1.0.0 → 1.0.1。
- **IPC**：契约版本不变（3.0-v1），additive 新增 7 个方法：`data.connection.databases` 与 `ai.provider.list/save/activate/deactivate/remove/test`，契约三处（`LocalAppContract`/`manifest.json`/`lib.rs`）同步登记并有契约一致性测试守护。
- **行为变化**：知识库 bundle 的检查/云端下载/手动导入不再要求教师角色（全角色可用）；数据页内切换连接现在会写全局选中连接（原先只改页面本地视图）。
- **随包知识库**：建议随 v3.4.4 安装包分发 1.0.1 bundle（替换 1.0.0，修正 manifest 标题）。

## 已知限制与后续积压

- 知识助教为单轮检索问答的会话式封装，多轮上下文拼接与流式输出、阅读 TOC/选中文本提问、本地 Ollama 模型选择下拉仍在积压（见计划第 6 节）。
- 助教"取消"依赖通用取消通道：桥端若不支持中断当前方法，请求会自然完成后静默丢弃。
- `ai.provider.*` 的角色可见性为全角色；后续如需按身份限制供应商数量或端点白名单，另行评估。
