# SQLTeacher v3.4.0

> 发布日期：2026-09-15（已公开，GitHub Release Latest 见 releases/README）
>
> v3.4.0 是"质量版本"：不含用户可见新功能，集中修复 11 项正确性/健壮性缺陷（含一项云端生产事故跟进）、完成大规模可维护性重构、清理老版本兼容妥协并补齐测试与文档规范。SQL 安全边界未放宽。完整任务清单见[整体优化计划](../plans/2026-09-14-v3.4.0-optimization-plan.md)，门禁与复审证据见[质量门禁记录](../acceptance/2026-09-14-v3.4.0-quality-gate.md)。

## 主要变化

### 稳定性与进程管理

- **sidecar 孤儿进程兜底**：桌面应用崩溃或被强杀时，Java 核心进程此前可能残留并持有数据库句柄；现在通过 Windows Job Object（kill-on-close）由操作系统连带回收整个 sidecar 进程树，退出事件也会显式关停。
- **sidecar 崩溃日志落盘**：Java 侧 stderr 此前被直接丢弃，崩溃无从诊断；现在滚动写入 `%LOCALAPPDATA%\SQLTeacher\logs\sidecar.log`（超 1MB 轮换为 `sidecar.old.log`）。
- **长操作不再误报超时**：IPC 此前对所有方法一刀切 30 秒超时，备份恢复、知识导入、索引重建、云端同步、更新下载等长操作会被误判为 SIDECAR_TIMEOUT（Java 侧其实仍在执行）；现在按方法配置超时预算（下载/组件安装 30 分钟、备份/导入/沙箱等 10 分钟、AI 草稿 3 分钟、云同步 5 分钟）。

### 升级与数据

- **最低支持升级起点上抬（行为变更）**：仅保证带 `schema_version` 表的 v3.x 数据库升级；v1.x/v2.x 无版本表的老数据库启动时将被明确拒绝并保留原文件（此前是静默收编）。自动更新自 v3.3.2 起已覆盖全部在线用户，此变更影响面趋近于零。
- **迁移 23**：`learning_events` 补 `owner` 列（含回填与 `learning_events_owner_occurred` 索引）并归一时间戳；迁移中途发现的脏行改为跳过并计数上报，不再阻断升级。
- **NSIS 安装器清理**：移除针对 v1.0–v2.3 WiX 与 3.0 Alpha/Beta 的旧版卸载钩子及 app-data 搬迁逻辑（Tauri 内置的 WiX 迁移不变）。

### SQL 工作台

- **"执行计划"按方言门禁**：`EXPLAIN QUERY PLAN` 仅对 SQLite 连接可用（其余方言此前点击必然报错），非 SQLite 连接禁用按钮并给出提示；执行前先经统一风险分析入口（`sql.analyze`），被阻断时如实反馈"SQL 未执行"。
- **连接查询错误可见**：连接列表加载失败此前无任何界面反馈；现在与 schema 错误一样呈现错误态。

### AI 与知识

- **NL2SQL 表结构内省失败可诊断**：内省异常此前被静默吞掉并回退到内置示例表结构（模型基于错误 schema 生成 SQL 且无法排查）；现在记录警告日志，且给模型的 schema 上下文明确标注回退来源。
- **AI Provider 探针报错分流**：不再把一切异常都报成"无法连接 Provider"；超时、JSON 解析失败、网络异常分别给出对应文案。
- **知识页已读标记失败反馈**：markRead 失败此前静默；现在呈现错误提示。
- **界面译文冲突修复**：中英对照表中"复制"“待处理”等重复键的冲突译文已去重，并加测试期完整性检查防回归。

### 云端（服务端）

- **题库迁移事故跟进修复**：修复 2026-09-12 生产事故暴露的迁移顺序缺陷（91 个 block 滞留）——改为"停放→建表→幂等回灌→最后盖戳"的崩溃安全顺序，中途失败可幂等重跑。
- **迁移机制统一**：云端手写 DDL 与"错误消息字符串匹配加列"替换为版本化 `CloudSchemaMigrator`（8 个迁移），消除双轨。
- **统计/导出不再静默失真**：班级学习概览与 CSV 导出对无法解析的记录此前静默跳行；现在计数并记录日志。
- **邮件链接环境隔离**：账户邮件链接 base URL 可注入（`SQLTEACHER_PUBLIC_BASE_URL`），测试/演练环境不再可能发出指向生产域名的链接。
- **更新清单 `rollout` 字段收紧为必填**（运维约束）：清单每次在线拉取、无缓存兼容负担。

### 内部质量（用户不可见，为后续功能版本铺路）

- 上帝类拆分：`SqlTeacherCloudServer` 2907→1401 行、`DefaultLocalAppApi` 2213→135 行（11 个 Section+注册表分派）、`CloudApiClient` 拆 8 个窄端口、`PlatformPages`/`EditorPage`/`CloudPage` 前端拆分、装配类拆 15 个 `@Configuration`。
- 基础设施收敛：HTTP 客户端统一走 `HttpClients` 工厂（含 HTTP/1.1 钉扎）、题库乐观锁 SQL 抽 `ExerciseStatements`、runner 进程管理抽 `ProcessRunner`、日期格式化收敛 `formatInstant`、JDBC 驱动降 runtime scope。
- 前端工程化：eslint flat config + prettier + editorconfig + typecheck、tsconfig `noUncheckedIndexedAccess`、暗色主题 CSS token 化。
- 测试体系：安全覆盖缺口补齐（EXPLAIN 风险用例、执行层 FORBIDDEN/多语句拒绝、练习提交门禁、沙箱脚本不变量）、Clock 注入消除墙钟忙等、bridge Section 专属测试 53 项、push/PR fast CI workflow。

## 兼容性说明

- **数据库**：桌面 schema 升至 23（`learning_events` owner 列+索引+时间戳归一），升级自动执行；无 `schema_version` 表的 v1.x/v2.x 老库将被拒绝启动并保留原文件，需先升级到 v3.x 再升本版。
- **IPC**：契约版本不变（3.0-v1）；超时预算按方法细化属桌面壳内部行为。
- **云端**：`CloudSchemaMigrator` 接管云端 schema 迁移（含缺口自愈）；服务端需与桌面版独立部署，接口对旧客户端保持兼容。
- **打包**：NSIS 不再自动卸载 v1.x–v3.0 beta 旧安装；从这些版本升级的用户可能需手动卸载一次。
