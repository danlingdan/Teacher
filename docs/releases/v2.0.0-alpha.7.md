# SQLTeacher v2.0.0-alpha.7（候选说明）

这是 v2.0 的最后一个 Alpha 候选，补齐教师安全课程包、项目制学习、本人成果档案、Cloud 2.0 能力协商和多设备元数据同步。本文件不表示已经创建标签或 GitHub Release。

## 主要变化

- 新增 `PROJECT` 活动、里程碑、量规、版本化提交和教师评审边界；
- 课程地图扩展为 11 门课程、35 个活动；
- 新增当前身份隔离的成果档案与显式私密导出；
- 课程包升级为带许可、版本和 SHA-256 的格式 2 预检导入；
- Cloud API 宣告 2.0 能力，新增最小摘要同步、操作幂等和显式版本冲突；
- 本地 schema 升至 16，Cloud schema 升至 6。

## 安全与兼容性

- 自动项目门禁不形成最终能力结论；教师评审仍必需；
- 源码、仓库地址、路径和凭据不进入成果档案或 Cloud 2.0 摘要；
- 课程包必须由教师操作并在预检后确认许可，篡改和冲突均拒绝；
- 原有 SQL、活动、课程 API 和事件同步保持兼容。

设计见 [alpha.7 RFC](../plans/2026-08-09-v2-alpha7-project-cloud-rfc.md)，使用方法见 [项目学习、课程包与 Cloud 2.0](../guide/18-project-course-package-cloud2.md)，验证见 [alpha.7 门禁](../acceptance/2026-08-09-v2-alpha7-stage-gate.md)。
