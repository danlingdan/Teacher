# SQLTeacher v2.0.1

2.0.1 是教学文案整顿版本。它将首页、课程、实验和教师工作台中偏向内部实现的描述，改写为学生和教师可以直接执行的任务语言。

## 主要变化

- 学生页面更清楚地说明当前任务、操作步骤、检查结果和下一步；
- 教师页面使用课程目标、学生提交、学习记录和反馈等教学语言；
- 隐藏与普通用户无关的服务分层、评价器、活动定义和内部状态术语；
- 保留安全警告的准确含义，也保留专业课程本身需要教授的术语；
- 中英文界面同步调整，并增加主教学流程文案回归检查。

## 兼容性

- 不改变数据库 schema、Cloud API、课程活动类型、评测规则或本地代码运行责任；
- 可以从 v2.0.0 直接升级，现有课程、学习记录和设置保持不变；
- 本版本只更新桌面程序，不需要部署新的云端服务。

实施范围见 [v2.0.1 教学文案整顿计划](../plans/2026-08-09-v2.0.1-teaching-copy-plan.md)。
