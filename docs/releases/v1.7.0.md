# SQLTeacher v1.7.0

v1.7.0 将已有题库、练习评测、云端任务、教师反馈和学情分析连接为可解释的学习诊断闭环。诊断结论由固定版本的 Java 规则计算，不依赖 AI，也不会因为 SQL 无限模式而改变。

## 新增功能

- 知识点掌握快照：按当前身份读取最近 30 天、每个知识点最近 20 次有效提交，输出 `UNKNOWN`、`NEEDS_PRACTICE`、`DEVELOPING`、`MASTERED` 四档状态。
- 可解释原因码：明确区分数据不足、连续失败、提示依赖、形成中和稳定掌握，并保留限长证据引用。
- 首页学习队列：合并本机未完成练习、薄弱知识点、未完成班级任务和未读反馈，稳定去重后最多显示 7 项。
- 继续学习：本机建议可直达对应题目，云端任务可携带班级上下文进入隔离练习流程，反馈入口进入既有学习反馈工作区。
- 教师干预队列：仅通过当前账号有权访问的班级 API 汇总逾期、连续失败和待跟进提交，可标记已查看、已解决或忽略。
- 脱敏导出：知识点诊断和教师干预数据采用字段白名单导出，转义电子表格公式前缀。
- 迁移与恢复：`app.db` schema 升至版本 7；派生快照与处理状态独立保存，学习数据清理时同步清除，可由原始事实重算。
- 身份隔离：新练习会话记录当前本地所有者，访客和不同账号不会共享未完成练习建议。

## 安全与降级

- AI 不参与掌握度、原因码、队列排序或教师干预对象选择。
- 网络不可用时首页保留本机诊断，云端队列失败不会混入部分数据或阻塞练习。
- 教师干预只消费现有班级授权 API；桌面端不会绕过服务端查询其他班级。
- 处理状态不会修改原始提交、评测、任务或反馈事实；新证据会产生新的稳定周期。
- CSV 不包含 API Key、完整 Prompt、连接凭据、完整 SQL 或数据库样本行。

## 使用入口

- 学生/访客：首页的“下一步学习”。
- 教师：学情看板中的“教师干预队列”标签。
- 正式安装包和便携版统一位于 Release 附件；请配合 `SHA256SUMS.txt` 校验。

## 兼容性

- 支持从 v1.6.1 的应用数据库追加升级，不修改或删除原始练习、任务与反馈记录。
- 云端服务和 AI Provider 均为可选增强；本机确定性诊断可离线使用。
