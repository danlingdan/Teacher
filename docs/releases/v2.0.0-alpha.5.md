# SQLTeacher v2.0.0-alpha.5（候选说明）

这是 v2.0 的第五个 Alpha 里程碑候选。它为计算机系统、操作系统和计算机网络加入完全离线、可验证的模拟实验。本文件描述当前源码候选，不表示已经创建 Git 标签或 GitHub Release。

## 主要变化

- 新增计算机系统、操作系统和计算机网络三门课程；
- 新增指令周期、最短作业优先调度和分组交付三个模拟实验；
- 通用实验工作区支持状态、动作、观察、历史、检查点、撤销与重置；
- 动作序列由确定性评价器重放，输出逐项结果、稳定原因码和证据；
- 模拟完全离线运行，不需要 AI、Cloud、本地编译器或数据库服务器。

## 兼容性与边界

- 本地 schema 从 13 升级到 14，只追加内置课程内容；
- 原有 SQL、测验、跟踪、代码活动和学习记录继续保留；
- 本地代码运行权限、安全评价、SQL 风险确认、AI 信任边界与 Cloud 权限没有变化；
- 本阶段不把 UI 的推荐动作作为权威判断，最终结果始终由应用层重新评价 artifact。

使用方法见 [离线系统模拟实验指南](../guide/16-offline-simulation-labs.md)，设计见 [alpha.5 RFC](../plans/2026-08-09-v2-alpha5-systems-simulation-rfc.md)，验证状态见 [alpha.5 门禁](../acceptance/2026-08-09-v2-alpha5-stage-gate.md)。
