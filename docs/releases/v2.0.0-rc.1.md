# SQLTeacher v2.0.0-rc.1（候选说明）

`2.0.0-rc.1` 是 v2.0 的第一个发布候选。它沿用 `beta.1` 冻结的活动类型、课程格式、schema 17、Cloud 2.0 主契约、UI 架构和 Runner 边界，不增加新的产品功能。

## 候选范围

- 将源码与 Windows 包版本切换到 `2.0.0-rc.1`。
- 验证 RC 更新清单只进入 RC 安装通道；稳定安装继续拒绝所有预发布通道。
- 重新执行完整测试、迁移与性能夹具、Windows 打包、校验和、SBOM、敏感内容扫描和 app-image 启动冒烟。
- RC 期间只接受阻断、兼容、安全、内容事实、许可、错误文案和发布配置修正。

## 兼容与安全

- 本地数据库保持 schema 17，不新增迁移；1.x 与 Alpha/Beta 事实数据沿既有追加迁移路径保留。
- Cloud API、课程包、SQL 安全链、AI 非权威边界和独立 Runner 契约均保持不变。
- 本地 IDE 中由学生主动发起的本机联网运行不等同于受控评价；正式评价仍使用独立 Runner。

## 发布状态

本文件描述本地 RC 候选，不表示已经提交、打标签、创建 GitHub Release 或部署。Windows 多设备/多缩放人工走查和 Cloud 预生产验证必须在公开发布或 GA 前完成。
