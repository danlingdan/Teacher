# SQLTeacher v3.12.0

> v3.12.0 是依赖全面升级版本：**无任何业务行为与公共契约变化**，升级动因是 2026-10-28 基础设施
> 盘点（[升级计划](../plans/2026-10-28-v3.12.0-dependency-upgrade-plan.md)）——Java/Frontend/Rust
> 三栈全部升到各自当前最新稳定版，桌面运行时从 Node 24 切换到 Node 26 LTS。本版无 schema 变更，
> 本地 IPC 契约无变化。
>
> 测试执行：本地全量（CI 凭据跳过，LEG-15 回执绑定 tag 父提交；mvn 896 / npm 223 / cargo 5 /
> 验证应用 5 项 PASS，打包工件校验与冒烟通过）。

## 主要变化

### Java 栈（Spring 7 + JUnit 6 时代）

- Spring Context **6.2 → 7.0.10**、JUnit **5.13 → 6.1.3**：两大框架大版本一次切换，
  889→**896** 项测试全量通过（测试计数变化来自 JUnit 6 将条件禁用测试计入 skipped 统计）。
- 数据库驱动大版本跟进：**MySQL Connector/J 9.4 → 26.10**（MySQL 改日历版本线）、
  **MariaDB 3.5 → 4.0**、**DuckDB 1.5 → 2.0**；14 方言连接与执行回归由集成测试覆盖。
- 其余全部升至最新稳定：sqlite-jdbc 3.53.4、Jackson 2.22.4、slf4j 2.0.20、logback 1.6.6、
  Lucene 10.5.2、jsoup 1.23.2、PDFBox 3.0.8、PostgreSQL 42.7.14、Oracle 23.26.3、H2 2.5.252，
  以及 compiler/surefire/jar/exec/cyclonedx 五个 Maven 插件例行升级。
- 保持不动：mssql-jdbc 13.4（14.x 仍 preview）、达梦 8.1.5.45、DB2 jcc 12.1.4、angus-mail 2.0.5
  （均已最新或最新为特殊构建）。

### 前端栈（Node 26 + Vite 8 + Vitest 5 + mermaid 12）

- **构建/测试工具链大版本**：Vite 7→8（rolldown 内核，构建显著提速）、Vitest 4→5、
  @vitejs/plugin-react 4→6；**Node 24 → 26 LTS**（本地 fnm 与 CI 同步切换）。
- **mermaid 11 → 12.2.0**：顺带消除 v3.11.0 遗留的 5 项 katex 低危审计公告，前端生产依赖审计清零。
- monaco-editor 0.57、React 19.3.1、react-router 7.18.5、tauri api/cli 2.12.4、通知插件 2.8.0
  （npm 与 Rust crate 两端同步，解除 v3.10 起的精确钉版）。
- 性能基准迁移到 vitest 5 新 API（test 上下文 bench fixture），`npm run test:performance` 入口不变。
- **TypeScript 保持 5.9.3**：尝试过 TS 7.0.2（tsc 与构建可通过），但 typescript-eslint 尚只支持
  `<6.1`，lint 门禁被生态卡住，待其支持后再升。
- **WebdriverIO 保持 9.32**：@wdio/tauri-service 1.5.1 尚只 peer webdriverio ^9，待其跟进后再升。

### Rust / 打包

- tauri 2.12.5 与全部插件随 `cargo update` 刷新至兼容线内最新；通知 Rust crate 2.8.0。
- windows-sys 0.60.2 将 `CreateJobObjectW` 移入 `Win32_Security` feature 门控，sidecar 进程树
  兜底代码相应补充该 feature（行为不变）。

## 升级与兼容

- 桌面端可经应用内更新直接升级；本地学习数据 schema 无新增迁移；云端服务端零变更。
- 安全边界不变：SQL 安全路径、风险分析、确认门禁、AI 不参与权威学习状态等全部机制未动。
- 已知留痕：npm audit 剩余 0 项（mermaid 12 升级后 katex 链路低危清零）；wdio 10 与 TS 7
  为生态卡点，分别待 @wdio/tauri-service 与 typescript-eslint 跟进。
