# SQLTeacher v1.8.6

v1.8.6 完成 v1.8.5 云端课程知识能力的生产闭环，重点补齐 Embedding、事务 Outbox、Qdrant 混合检索、授权复核和运维恢复能力。

## 主要变化

- Cloud schema 4 增加知识索引 Outbox 与嵌入画像；课程知识事实、切片和待索引任务在同一个 SQLite 事务中提交。
- 后台索引任务按批次生成 passage embedding 并幂等写入 Qdrant，失败时退避重试，不回滚已经发布的课程事实。
- 云端搜索使用 query embedding，并通过 RRF 合并 SQLite 关键词与 Qdrant 向量候选；Embedding 或 Qdrant 不可用时自动降级到关键词检索。
- Qdrant 查询强制附加课程和可见性 Payload filter，返回结果再由 Cloud SQLite 根据当前修订、所有者和发布状态复核。
- 新增管理员索引状态与重建接口；`/health` 增加 `knowledgeIndex` 和 `knowledgeIndexBacklog`。
- 生产 Embedding 使用 FastEmbed `0.8.0`、`BAAI/bge-small-zh-v1.5` 和 512 维归一化向量，仅监听 loopback。
- 运维检查覆盖 Embedding 模型、Cloud 索引积压、Qdrant 集合、快照年龄与恢复门禁。
- 修复从旧便携目录迁移 `app-data` 时，活动日志与同名旧日志冲突导致首次启动失败的问题；迁移会保留目标目录中已创建的文件。

## 安全与降级

- 桌面客户端不持有 Qdrant API key，也不直接连接 Qdrant 或 Embedding 服务。
- 课程知识正文、查询文本和向量不会写入请求日志；生产凭据不进入安装包或仓库。
- SQLite 仍是文章、修订、所有者和发布状态的事实来源；Qdrant 是可以从 Outbox 重建的派生索引。
- 学生只能检索已发布内容，PRIVATE 内容即使成为向量候选也会在返回前被事实库授权复核阻断。

- 隔离端到端验证覆盖发布、Outbox、Embedding、Qdrant upsert、非关键词语义命中以及 PUBLISHED/PRIVATE 权限边界。
- 生产 Qdrant 512 维快照恢复到临时集合成功，Payload Index 完整；Cloud 总运维检查通过。
- 正式服务继续使用 `https://api.sqlteacher.tech`，Qdrant、Embedding 和 Cloud 后端端口只监听 loopback。
