# SQLTeacher v2.0.0-alpha.6（候选说明）

这是 v2.0 的第六个 Alpha 里程碑候选。它为软件工程、程序设计语言与编译、离散数学、AI 与数据基础、计算机安全基础各增加一个可离线完成、可确定性评价的课程单元。本文件描述当前源码候选，不表示已经创建 Git 标签或 GitHub Release。

## 主要变化

- 新增持续集成质量门禁、词法分析、数学归纳法、分类结果评价和不可信输入防御链五个实验；
- 课程地图扩展到 11 门课程、34 个活动；
- 每个新单元具有课程专用检查点、稳定原因码和学习事件证据；
- 模拟工作区进一步通用化，可供后续课程复用。

## 安全与兼容性

- schema 从 14 升级到 15，只追加内置课程内容；
- 新实验均为纯数据离线模拟，不执行真实 Git、CI、编译器、模型、Shell 或网络操作；
- 安全课程不包含攻击载荷或公网目标，AI 课程不把模型输出作为权威结果；
- 原有 SQL、测验、跟踪、代码、系统模拟与学习记录继续保留。

设计见 [alpha.6 RFC](../plans/2026-08-09-v2-alpha6-professional-foundations-rfc.md)，使用方法见 [专业基础离线实验指南](../guide/17-professional-foundation-labs.md)，验证见 [alpha.6 门禁](../acceptance/2026-08-09-v2-alpha6-stage-gate.md)。
