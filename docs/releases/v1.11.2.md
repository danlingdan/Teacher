# SQLTeacher v1.11.2

v1.11.2 是界面语言修复版本：默认界面语言固定为简体中文（不再跟随操作系统语言），并在设置页提供可持久化的界面语言切换。

## 主要变化

- **默认简体中文**：界面语言不再跟随系统 Locale，避免在英文 Windows 上自动显示英文界面而无法改回。
- **界面语言切换**：「设置 → 更新与支持 → 网络、外观与通用设置」新增「界面语言」选择（简体中文 / English），保存后原子写入通用设置，重启应用后完整生效。
- 语言偏好随通用设置导入导出白名单保存；`zh`/`en` 之外的非法值回退简体中文。

## 兼容性

- 支持从 v1.10.1、v1.11.0、v1.11.1 原位升级，保留 `app-data` 用户数据。
- Cloud API 版本保持 `1.11`，最低兼容客户端为 1.9.0；本版本为纯桌面客户端改动，生产 Cloud 无需升级。
- 需要 Windows x64；正式安装包和便携 ZIP 均自带 Java 21 运行时。
