# SQLTeacher v2.0.0-alpha.2

这是 v2.0 的第二个预发布里程碑，面向桌面主路径和交互验证，不替代最新稳定版 `v1.11.5`。

## 主要变化

- 新应用壳按学习、课程、实验、教学和系统组织功能，并显示当前页面上下文；
- 首页升级为任务中心，保留本地诊断、学习队列、任务和反馈入口；
- 课程地图读取真实的本地发布课程、章节、活动和知识点；
- 课程活动可进入通用实验工作区，SQL 作为首个真实 Runner 继续使用原安全执行链；
- 路由、身份能力、数字快捷键和 `Ctrl+K` 命令入口共享同一能力感知模型；
- 页面切换使用无空白帧的淡入淡出与轻微位移动画，短任务不再闪现全屏 Loading；
- 亮暗主题和 840×600 响应式路径完成窗口走查。

## 兼容与限制

- schema 仍为 alpha.1 引入的版本 11，本版本不增加迁移；
- 既有 SQL 编辑、风险确认、执行、结果和设置页面继续复用，数据格式与 Cloud API 不变；
- 开启“减少动态效果”后，页面与 Loading 过渡会即时完成；
- 非 SQL 活动没有占位 Runner；后续 Alpha 提供真实评价器和运行器后再开放；
- 这是预发布版本，不会替换稳定版 Latest，也不会自动进入稳定更新通道。
