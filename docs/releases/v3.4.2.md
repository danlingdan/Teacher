# SQLTeacher v3.4.2

> 发布日期：2026-09-15（已公开，GitHub Release Latest 见 releases/README）
>
> v3.4.2 是"易用性 + 数据完整性 + 软件合规"合并版本：一并交付 [v3.4.1 设置易用性与数据完整性计划](../plans/2026-09-15-v3.4.1-plan.md)（未单独发布）与 [v3.4.2 软件合规声明与关于信息计划](../plans/2026-09-15-v3.4.2-plan.md)。亮点：班级码自助加入、演示库三大完整性教学可用、设置页"关于"面板与完整隐私说明、随安装器分发的法律文件与许可协议页、可选问题反馈通道。SQL 安全边界未放宽。
>
> 测试执行：本地全量（CI 凭据跳过）。

## 主要变化

### 云端协作：班级码（原 v3.4.1 CLS）

- **学生凭班级码自助加入班级**：每个班级自动生成 8 位班级码（字符集去除 0/O/1/I 等易混字符），学生在「可见班级」输入班级码即可以学生身份入班，无需教师逐个按邮箱登记；服务端对加入尝试限流，码无效或云端版本过旧时统一给可读提示。
- **教师端班级码管理**：班级「成员名单」中可查看、一键复制、重置班级码；重置后旧码立即失效，已加入成员不受影响。
- 云端 schema 升至 **Migration 9**（`classrooms.join_code` 列 + 唯一索引，存量班级自动回填）；契约全部 additive，先部署云端、再发桌面版，旧客户端不受影响。

### 易用性修复（原 v3.4.1 SET/SQL/KNW）

- **设置页全区块可折叠**：「题库更新」与「外观与使用体验」改为与其他区块一致的折叠面板（外观默认展开），并修复题库卡片小字标签被圆角裁切的布局缺陷。
- **数据 SQL 页表结构浏览重构**：表默认收起、顶部按表名/列名过滤、显示"共 N 张表"计数，面板分区固定，表多时侧栏不再被撑爆；补空态与加载态。
- **知识页课程树收敛**：课程树只显示章节与知识文档数，不再平铺点不动的"活动"条目（活动入口归还教学/练习页）；检索结果不再出现无法打开的禁用条目——映射不到课程文章的命中在后端过滤并计数打日志。

### 演示库与练习数据集完整性（原 v3.4.1 DB，含行为变更）

- **demo.db 补全三大完整性**：SPJ 补 3 条外键、SC 补 2 条外键、Course.Cpno 自引用先修课外键，`SC.Grade` 加 0–100 CHECK 约束；演示库现在可直接用于讲解实体、参照与用户自定义完整性。demo.db 每次启动全量重建，升级无需迁移。
- **外键运行期强制（行为变更）**：演示库连接开启 `PRAGMA foreign_keys`——违规写入现在会真实报 `FOREIGN KEY constraint failed`，此前是静默成功。app.db 本版不开启（见积压）。
- **spj-demo 练习数据集对齐**（VERSION 1→2，自动重应用）：补与 demo.db 相同口径的外键；练习沙箱与评测库连接同步开启外键强制。

### 软件合规与关于信息（v3.4.2 LEG-1…7）

- **设置页新增「关于」面板**：产品名称与版本号、制作人员名单、版权与权属（"软件著作权归河南科技大学所有"，软著申请中，登记号待登记）、Apache-2.0 许可信息；「隐私与数据」按钮在面板内展示隐私说明全文；含「检查更新」与「问题反馈」入口。
- **隐私说明全文触达**：帮助"隐私"主题从一句话升级为 `legal/PRIVACY.md` 全文（读取失败 fail-closed 回退短句）；PRIVACY.md 升版 v1.11——修正过期面板名引用，补充更新检查（无请求体 GET + 签名清单验签）、灰度分桶（本地哈希不上送）、网络 AI（仅发往用户自行配置的 endpoint，Key 走 DPAPI 本地保护，发送前可预览）、云协作与题库分发的数据去向事实。
- **第三方许可复核至 3.4.2**：对照 Java 依赖树与 npm/Cargo 实际版本逐条核对，修正 ojdbc11 与 Db2 JCC 许可证标识，新增桌面 UI 运行时组件段（React、TanStack Query、Monaco、Tauri 等），移除已不存在的 WiX 条目。
- **安装目录携带法律文件**：安装器现在把 `legal\`（LICENSE.txt、THIRD-PARTY-LICENSES.txt、PRIVACY.md）随 resources 落地到安装目录，与便携包内容一致；单一事实源保持 `src/main/resources/legal/`，构建期复制。
- **NSIS 安装器许可协议页与版权元数据**：正常安装新增一页可滚动的 Apache-2.0 许可协议（passive/静默安装自动跳过）；安装器 BrandingText 与文件属性 LegalCopyright 写入 "Copyright 2026 河南科技大学"；根 LICENSE 补 Apache-2.0 标准附录署名行。打包合同校验新增对应断言。

### 问题反馈通道（v3.4.2 LEG-10）

- **设置页可选问题反馈**：类型/严重度/摘要/详细描述/复现步骤/期望与实际/联系方式（可选）表单；四个诊断勾选（环境、近期错误、网络摘要、更新状态）**默认全关**，提交前强制「预览诊断字段」，预览与提交共用同一构造路径（所见即所发），诊断内容逐项过敏感信息脱敏。
- 提交成功返回 `reportId` 与 `queryToken`（**仅显示一次**，用于查询进度/撤回/导出）；同面板提供查询进度与撤回入口。未登录云端时走匿名通道；服务端端点与 365 天保留期为 v1.10 既有能力，无服务端改动。
- 本版不含截图附件（IPC 请求上限约束，见积压）。

### 遗留功能接线（v3.4.2 LEG-11…14）

- **AI 起草课堂反馈**：课堂反馈表单新增「AI 起草」——AI 产出草稿填入可编辑评语框，教师修改后仍经既有保存链路提交；AI 失败时提示并保持手写路径可用。
- **编辑已发布作业**：教师作业卡片新增「编辑」入口，复用创建表单回填；不可编辑作业按后端语义给出可读提示。
- **单课程 JSON 导入**：教师课程管理区在「导入课程包」旁新增「导入课程 JSON」（单文件导入），成功刷新课程列表，失败区分格式错误/版本不兼容。
- **教师题库回滚**：设置页「题库更新」面板新增「回滚上一版本」——破坏性操作，经确认对话框（写明目标版本与学生侧影响）后执行；无历史版本时禁用并说明。

### 发布工作流提效（v3.4.2 LEG-15）

- 新增本地验证凭据机制：本地全量 `mvn test` + `npm test` 通过后生成 `verification-receipt.json`（绑定发布提交），release workflow 在凭据有效且零失败时跳过 CI 重复测试（`npm ci`、`npm audit`、打包、SBOM、签名与合同校验始终执行）；凭据缺失、SHA 不符或记录失败一律回退全量测试。凭据随 Release 资产上传供审计。

## 兼容性说明

- **云端**：schema 升至 Migration 9（幂等、可回填），**先部署云端再升级桌面**；旧桌面客户端不受影响，新桌面对旧服务端给统一可读提示。
- **桌面数据库**：app 库 schema 不变（23）；demo.db 启动全量重建自动获得新结构；spj-demo 练习数据集 VERSION 2 自动重应用。
- **行为变更**：演示库与练习沙箱的外键强制开启——此前静默成功的违规写入现在报错（教学预期行为）。
- **IPC**：契约版本不变（3.0-v1），additive 新增 8 个方法（`cloud.class.join`、`cloud.class.join-code`、`cloud.class.join-code.rotate`、`support.report.preview/submit/status/withdraw/export`），共 144 个。
- **安装器**：正常安装流程新增许可协议页一步（静默/passive 不受影响）；安装目录新增 `legal\`。
