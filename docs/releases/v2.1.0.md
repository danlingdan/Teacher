# SQLTeacher v2.1.0

2.1.0 增加目标驱动的数据库学习入口，把课程活动、需求建模、公开数据预览和 SQL 助手组织成一条本地学习路径。

## 主要变化

- 从“数据库学习”选择目标，并进入课程地图中的真实活动；
- 使用学生选课、电商订单和图书借阅示例练习需求拆解与表设计；
- 在 AI 助手中选择教学引导或直接草稿，两种方式均经过相同 SQL 安全检查；
- 从公开 HTTP(S) 地址读取有界文本预览，生成单条、有限行数的 `INSERT` 草稿；
- DDL 和数据草稿只会送入实验工作区，不会在来源页面自动执行。
- 默认启用开发者 SQL 模式：普通插入和建表减少重复确认，高危修改保留最终确认；
- 新建数据库连接默认可写，网络 AI 上下文确认调整为每个应用会话一次；
- 本地代码继续作为普通 IDE 运行，直接使用本机文件、工具链与外网，安全评价作为独立课程检查。

## 安全与兼容性

- 不改变数据库 schema 或 Cloud API，不需要服务端部署；
- 继续拒绝本机、私网、凭据 URL、过大响应和不支持的网页内容；
- 多语句、`DROP DATABASE`、`GRANT`、`REVOKE`、只读连接和 AI 自动执行仍不可绕过；
- 可从 v2.0.1 直接升级，现有课程、学习记录和设置不变。

实施边界见 [2.1 目标驱动数据库学习计划](../plans/2026-08-09-v2.1-goal-driven-database-learning-plan.md)。
