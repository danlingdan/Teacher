# SQLTeacher v1.6.1

v1.6.1 是网络 AI 调用链路的兼容性与错误提示热修复版本。

## 修复

- OpenAI-compatible Provider 可直接填写根地址或 `/v1` 地址，生成请求会自动使用对应的 `/chat/completions`。
- 继续兼容已经填写完整 `/chat/completions` 的地址，并可从 `/models` 地址推导生成地址。
- AI 请求失败时展示服务层返回的脱敏错误说明，不再把所有错误统一标记为“服务离线”。
- 移除失败时自动填入模拟 SQL 的行为，避免用户误把演示内容当成模型真实输出。
- 用户切回本地 Ollama 后，重启应用仍保持本地模式，不会重新激活网络 Provider。
- HTTP 4xx 配置错误不再进行无意义重试；超时、网络异常和服务端错误仍保留一次有界重试。
- Provider 地址禁止内嵌用户名、密码、查询参数或片段，避免敏感配置写入 Profile 元数据。
- 云端 API 的异常处理改用受控结构化日志，不再向标准错误直接打印异常堆栈。

## 验证

- DeepSeek 根地址模型发现和真实结构化生成调用通过。
- Maven 依赖分析通过，未发现未声明或已使用但缺失的依赖。
- 完整 Maven 回归 300 项，失败 0、错误 0；2 项实时测试按默认配置跳过。
- 本地 Ollama `qwen3.5:0.8b` 与 DeepSeek 根地址实时测试均已独立显式执行并通过。
