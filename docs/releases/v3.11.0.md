## 主要变化

### 数据建模：自然语言生成 E-R 图

- 侧边导航新增**「数据建模」**工作区：输入业务需求（≤2000 字符）一键生成陈氏记号 E-R 图，
  画布支持缩放、平移与拖拽微调，「适应视图」一键回正；**导出 PNG / 导出 SVG** 保存为课件素材。
- **记号全集**：实体/弱实体（双线矩形）、属性椭圆（主码下划线、复合子属性、多值双椭圆、
  派生虚线椭圆）、联系菱形（连线标注 1/n/m、全参与双线）、依赖联系（双菱形）、2–4 元联系、
  联系属性、概括/特化（ISA 三角形）；布局为确定性自动排布（实体—联系分层 + 属性环绕）。
- **AI 起草、Java 校验**：模型输出视为不可信输入——规模上限（实体 ≤16、每实体属性 ≤12、
  联系 ≤24、层级 ≤8 等）、基数白名单（1/n/m）、引用完整性、弱实体/依赖联系配对、ISA 树形约束
  等全部由 Java 聚合校验；不合规时自动带错误清单重试一次，仍失败则给出中文原因列表，可重新生成。
- **引擎话术如实**：页面按 `ai.engine.status` 实际通道显示「本地 AI / 网络 AI」；使用网络供应商时
  明确提示需求会上传至所选服务商，不宣称"不上传云端"。需求文本不写入日志与学习事件。
- 引擎未就绪时与数据页 NL2SQL 一致：就地显示引导并可一键打开顶栏「AI 引擎」面板；
  生成失败不阻塞其他功能。E-R 生成不会执行任何 SQL。

## 升级与兼容

- 桌面端可经应用内更新直接升级；本地学习数据 schema 无新增迁移；云端服务端零变更。
- 本地 IPC 契约按 **additive-within-v1** 新增一个方法：`ai.modeling.er.generate`；旧调用行为不变，
  无破坏性变更。
- 前端新增渲染依赖：`@xyflow/react`、`elkjs`、`html-to-image`（均为 MIT，画布渲染与图片导出）。
- 安全边界不变：E-R 建模全程无 SQL 执行、不接触数据库凭据；模型输出先经 Java 校验才渲染；
  AI 不参与判分，不掌管任何权威学习状态。
- 本版为 v3.5.0「不做 ER 图编辑/建模工具」裁定的定向推翻（AI 生成 + 查看微调，仍不做手工
  编辑器），决策记录见[计划文档](../plans/2026-10-27-v3.11.0-er-modeling-plan.md)；数据页由
  外键驱动的只读关系简图保留，与本功能互补。使用说明见
  [数据建模指南](../guide/25-er-modeling.md)。
