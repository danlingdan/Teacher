# SQLTeacher v3.7.0

> 发布日期：2026-09-20（已公开，GitHub Release Latest 见 releases/README）
>
> v3.7.0 是**教师端学情反馈版本**：教师能看到的学生信息从"作业提交的布尔结果"升级为
> "学习过程记录"——学生执行了什么 SQL、哪题错在哪、AI 生成与提问、知识检索与阅读、
> 掌握度变化、每日活跃，经学生端登录后自动同步上报云端，教师在班级与云端页按班级
> 总览、按学生逐条查看。同时把同步控制权交给学生（上传可暂停、自动同步默认开启可关闭），
> 服务端补齐上传限流、容量上限与默认保留期。SQL 安全边界、AI 不碰 JDBC、离线优先
> 等原则不变；上传内容经白名单约束（不含结果集数据、AI 回答全文）。
>
> 测试执行：本地全量（CI 凭据跳过，LEG-15 回执绑定 tag 提交）。

## 主要变化

### 教师端学情反馈（本版核心）

- **班级学情总览**：「班级与云端」班级页新增折叠卡——学生数、已同步学习记录数、近 7 日
  活跃人数、记录类型分布（SQL 执行/练习/AI/检索/阅读等）与近 14 日活动趋势条形图。
- **学情画像**：成员名单中每个学生新增「学情画像」入口——按类型过滤、分页加载的活动
  时间线（SQL 执行与被拦截语句的文本摘要、练习得分与错误码、AI 生成草稿、助教提问摘要、
  知识检索、阅读进度、掌握度变化），并展示该学生的知识点掌握度（后端早已支持教师查
  指定学生，本版接通 UI）。学生未同步的本地练习不会出现；教师每次查看明细都写入云端
  导出审计。
- **任务学情呈现学生提交内容**：任务学情新增「学生提交」区，可展开每个学生最新一次
  提交的 SQL 文本（超长截断至 4KB）与得分；随提交上云、离线队列补投不丢失。此前提交
  只存结果哈希，教师批阅看不到学生写了什么。
- **干预证据增强**：干预队列候选证据追加班级近 7 日活跃事实；旧版云端自动降级省略，
  干预状态机不变。

### 学生端记录范围与同步控制

- **学习事件证据丰富化**：SQL 执行事件携带截断 SQL 文本（4KB）、方言、耗时与行数；
  练习事件携带得分、错误码与提交 SQL；AI 生成草稿携带 SQL 文本，并以完整 SQL 的
  SHA-256 哈希（`sqlHash`）串联"AI 生成 → 是否执行 → 执行结果"。
- **新学习事件**：知识点掌握度实质变化（级别变化或百分比变化 ≥10 才记录）、每日活跃
  （应用开启时长心跳，约每 30 分钟一条，无键鼠/屏幕监控）、知识阅读进度（跨 25/50/75/100%
  阈值）、AI 助教提问（问题文本截断 500 字符，不上传回答全文）。
- **同步偏好**：「班级与云端」同步卡与设置页「云端同步」面板提供同一份配置——
  「上传学习记录到云端」（关闭后手动/登录/自动均不上传，本地记录与作业离线队列不受影响）
  与「登录期间自动同步」（**默认开启**，约每 5 分钟节流；关闭即回到手动同步）。
  上传内容白名单可见于隐私声明与用户手册。

### 云端服务端（需先于客户端部署）

- **教师读学生事件明细端点** `GET /api/v1/classes/{id}/events`：按班级教师权限 + 本班
  学生成员校验，游标分页、类型/时间过滤，每次读取写 `export_audit`；学生本人查询语义不变。
- **班级学情总览端点** `GET /api/v1/classes/{id}/analytics/overview`：经典汇总之外新增
  近 7 日活跃、事件类型分布与 14 日趋势；独立端点保证旧桌面客户端解析不受影响。
- **提交载荷**：`assignment_submissions` 新增 `submission_payload_json`（云端迁移 v10），
  单条 ≤16KB 校验。
- **防护与保留**：事件上传限流每账号 1 次/分钟（429 + Retry-After）；每用户同步事件
  软上限 100,000 条（超限 400 `SYNC_EVENT_CAPACITY_EXCEEDED`）；每日自动清理超过保留期
  的同步记录，默认 180 天（环境变量 `SQLTEACHER_CLOUD_SYNC_RETENTION_DAYS` 可调，0 关闭）。

### 其他

- **SQL 执行历史按账号隔离**：`sql_history` 新增 owner 列（本地迁移 27）；新记录按登录
  账号隔离，历史遗留记录保持全员可见，修复本机多账号执行历史串号。
- **账号导出补全**：账号数据导出新增本人已同步学习记录（此前仅含问题反馈）。
- 离线提交队列携带载荷（本地迁移 28）；新 IPC 方法已同步四处契约
  （Java 契约/桥/manifest/Rust 允许清单）。

## 升级与兼容

- **云端必须先于客户端部署**：总览/明细/提交载荷为新服务端能力；旧客户端对新云端完全
  兼容，新客户端遇旧云端时相关功能降级提示。
- 云端 SQLite 迁移 v9 → v10（加列，幂等）；桌面 SQLite 迁移 26 → 28（加列，升级前自动备份）。
- 行为变化：登录账号后学习记录默认自动同步（可在设置关闭）——隐私声明与用户手册已同步
  更新；SQL 作业提交从"不含任何 SQL"放开为"仅白名单化的截断 SQL 文本"（计划已批准）。
