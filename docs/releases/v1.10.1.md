# SQLTeacher v1.10.1

v1.10.1 是账号登录兼容性补丁版本，修复管理员预置账号可能因历史密码长度策略而无法登录的问题。

## 主要变化

- 登录校验现在允许验证既有的管理员预置账号，不再用公开注册的最小密码长度提前拒绝登录。
- 公开注册和修改后的新密码仍要求 12 至 128 位，不降低普通账号的新密码策略。
- 登录页明确区分“输入现有登录密码”和“注册至少 12 位”的要求。
- 补充回归测试，确保短密码仍无法通过公开注册，但已预置账号可以进入实际身份校验流程。

## 兼容性

- 支持从 v1.9.0、v1.10.0 正式安装版原位升级，保留 `app-data` 用户数据。
- 云端 API 版本保持 `1.10`，现有 v1.9.0 及以上客户端协议兼容性不变。
- 需要 Windows x64；正式安装包和便携 ZIP 均自带 Java 21 运行时。
