# SQLTeacher v2.2.0 发布说明

> 完成日期：2026-08-09
>
> 状态：正式版

## 本版完成内容

- 数据库连接由 SQLite/MySQL/MariaDB 扩展为 SQLite、DuckDB、H2、MySQL、MariaDB、
  PostgreSQL、SQL Server、Oracle、Db2、达梦、TiDB、OceanBase 与 GaussDB/openGauss 预设；
- 新增通用 JDBC 入口，可配置本地驱动 JAR、驱动类、JDBC URL 与用户名，密码继续只保存在会话内；
- SQLite schema 18 无损迁移旧连接配置，并保存文件库、服务器和通用 JDBC 三类目标；
- DuckDB 与 H2 可直接使用本地文件，无需额外数据库服务器；
- 本地 IDE Runner 优先复用 Windows 原生 Python，并兼容 MSVC、PATH 中的 GCC/Clang，
  以及 `D:\DevelopmentEnvironment\cygwin\bin` 中的 Cygwin GCC/G++；
- 设置新增“开发环境”页，集中显示 Java、Python、C、C++ 的真实可用状态；
- 开发环境页可在逐项确认来源、许可证、管理员权限和重启影响后，自动下载安装
  Temurin JDK 21、Python 3.13、Ollama、MSVC Build Tools 与 WSL Ubuntu；支持取消、失败重试和安装后复检；
- AI 继续复用已有的自定义 Ollama 地址和 OpenAI-compatible 提供者配置，无需增加厂商专用分支。

## 支持边界

- SQLite 仍是确定性练习评测基线；外部数据库用于探索、项目和连接实践；
- Oracle、Db2、达梦与兼容协议预设先保证驱动、连接和标准 JDBC 元数据兼容，
  不宣称覆盖所有厂商方言和认证方式；
- 通用 JDBC 由用户提供驱动，其兼容性取决于驱动实现；
- 自动安装依赖 Windows Package Manager 或系统自带的 WSL 命令；应用不会静默提权、自动重启或卸载用户已有组件；
- Ollama 模型仍由用户在 AI 助手中选择和下载，本版只自动安装 Ollama 软件。
