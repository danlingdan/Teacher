# SQLTeacher v1.11.4

v1.11.4 完成 v1.11 计划的最终收尾：原生通知真实触发、按流量计费网络策略接入自动更新检查，并完成全量回归。

## 主要变化

- **原生通知触发**：发现新版本时发送系统通知（仅显式启用后；正文白名单短语）。
- **按流量计费网络策略**：设置页新增「当前网络为按流量计费」开关；开启后自动更新检查暂停（手动检查仍可用，用户主动操作不受影响），策略真正接入自动更新流程。
- **功能接线核查**：所有 v1.11 新增功能类均确认有真实生产调用方（此前原生通知与资源策略仅有实现无触发点）。

## 兼容性

- 支持从 v1.10.1、v1.11.0~v1.11.3 原位升级，保留 `app-data` 用户数据。
- Cloud API 版本保持 `1.11`，最低兼容客户端为 1.9.0；本版本为纯桌面客户端改动，生产 Cloud 无需升级。
- 需要 Windows x64；正式安装包和便携 ZIP 均自带 Java 21 运行时。
