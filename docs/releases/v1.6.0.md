# SQLTeacher v1.6.0

v1.6.0 将本地 Ollama 与 OpenAI-compatible 网络模型整合为统一、可控的 AI 教学工作区。AI 继续只生成待审查草稿，不自动执行 SQL、不自动判分，也不会继承 SQL 无限模式。

## 新增与改进

- 支持多个网络 Provider Profile；非敏感配置与凭据分离，API Key 使用 Windows CurrentUser DPAPI 加密保存。
- Ollama 与网络 Provider 支持连接测试、模型发现、超时、响应限长和脱敏错误映射。
- NL2SQL、SQL 错误解释与教师反馈草稿统一经过任务编排，集中处理取消、一次有界重试、输出限制、结构校验、降级与审计。
- 网络调用前展示上下文类别、来源、字符数和删减记录；默认隐藏邮箱、常见凭据并限制上下文预算。
- 支持对上一版 SQL 草稿提出单轮修订，每一轮都会重新生成完整草稿并重新执行 Java SQL 风险审查。
- 增加简洁、引导式、分步解释三种教师反馈表达模板；AI 不得修改确定性评测结论。
- 保存最近 AI 任务的脱敏元数据；只有用户主动收藏时才保存限长草稿正文。
- 提供设备级输入、输出、超时和每日调用边界；真实 Provider 冒烟测试默认禁用，避免普通构建产生网络调用或费用。
- 切换本地 Ollama 模型时自动用 `keep_alive: 0` 卸载上一模型，及时释放内存。

## 安全边界

- AI Provider 不接触 JDBC `Connection`，任何生成内容都不能自动执行。
- AI SQL 草稿始终经过结构解析、方言检查和本地 SQL 风险分析；无限模式不会放宽这些规则。
- 公开网络 Provider 必须使用 HTTPS，HTTP 仅允许回环地址；连接探测不跟随重定向。
- 密钥、完整 Prompt 和默认完整响应不进入日志、历史、导出、安装包或版本库。
- 教师反馈仍需人工确认后才能发布。
