# SQLTeacher v3.1.0

> 发布日期:未发布(本地候选;记录已合并入 `main` 的变更,版本号随发布流程落盘)
>
> 教学内容增强:题库包迁移至文字 DSL 并新增 AI 辅助解析;内置示例库替换为教材经典数据集。

## 主要变化

- **SQL 执行历史**:数据与 SQL 工作台新增"执行历史"折叠区,自动记录本机最近 200 条执行(语句、连接、成败、行数、耗时),点击任意条目把语句填回编辑器,支持一键清空;历史仅保存在本机应用数据库,不进入云端也不参与学情统计。
- **查询结果导出 CSV**:SQL 结果面板新增"导出 CSV",通过系统保存对话框选择位置后由 Java 写入文件(带 BOM,Excel 直接打开);结果缓存 10 分钟,过期后重新执行即可。
- **连接配置复制**:管理连接新增"复制"按钮,基于当前连接的配置快速创建同类型的另一个连接,ID 与显示名称自动重新生成。
- **题库包改为文字 DSL**:教师题库导入导出从 JSON 迁移到纯文本 DSL(`===[DATASET]===` 与 `===[EXERCISE]===` 分块,`TITLE:`、`DATASET:`、`SQL:`、`RULE:`、`HINTS:` 等字段)。编码与校验全部由 Java 确定性完成:未知字段、重复 ID、不支持的格式版本、超过三层的提示都会在解析时拒绝,导入失败整批回滚。
- **导入前解析预览**:粘贴题库包后先"解析预览"查看将导入的数据集与题目清单,由 Java 校验通过后才能"导入题库包";文本一旦修改,预览即失效,避免导入内容与所见不一致。
- **AI 辅助解析草稿**:教师可粘贴自由文本,点击"AI 解析"由本地 Ollama 模型生成文字 DSL 草稿。AI 输出仅作为草稿:必须通过 Java 确定性校验与教师预览确认后才会入库,不能执行 SQL 或绕过判定规则;模型不可用或输出不合法时给出明确错误,不影响本地核心功能。
- **内置示例库升级为教材数据集**:示例库(demo.db)从旧的单表 `student` 替换为两组教材经典数据集——学生-选课(Student/Course/SC)与供应商-零件-工程项目(S/P/J/SPJ),共 7 表 63 行,覆盖多表连接、复合主键与字母编码等教学场景;NL2SQL 与学情演示获得更真实的上下文。
- **修复教材数据集下的表结构读取**:教材表的 `TEXT`/复合主键会在 SQLite 中生成 `sqlite_autoindex_*` 内部索引,表结构面板此前会因尝试读取这些内部对象而整体失败;现已过滤全部 SQLite 保留对象,结构面板对任意主键形式的库均可用(打包验证中发现并修复)。
- **新建数据库连接更省心**:数据库类型下拉改为中文名称并自动填充默认端口(如 MySQL 3306、达梦 5236);SQLite/DuckDB/H2 支持"浏览…"选择数据库文件,文件不存在时测试结果会提示将创建新的空库,避免路径笔误产生"连接成功"的空库;连接 ID 与显示名称留空自动生成(ID 移入"高级"),新用户只需填地址和凭据。
- **保存前强制真实连接测试**:连接保存改为"测试并保存",先用真实连接验证再落盘,连不上的配置不会被保存;编辑服务器连接时密码留空会自动复用本次会话中已验证的凭据。
- **界面细节打磨**:全部长页面与滚动区域改用细滚动条(浅色/深色主题各自适配),降低 Windows 默认粗滚动条带来的厚重感;连接表单中文件路径输入与"浏览…"按钮同行铺满、必填缺口以警示条提示下一步动作、低频的"连接 ID"字段收入弱化的"高级"折叠区;结构树补齐末行分隔与表名悬停反馈。
- **发布验证同步适配**:发布性能验证应用的数据填充与查询改用新的 `Student` 表。

## 兼容性说明

- v3.0 及更早版本导出的 JSON 题库包无法直接导入,需按[教师手册](../guide/09-teacher-manual.md)中的文字 DSL 格式重新整理;已保存在题库中的题目不受影响,可直接导出为新的文字包。
- 示例库在每次启动时重建为标准教材数据,对示例库的手工修改不再跨启动保留;正式题库(app 数据库)不受影响。
- 云端课程包功能仍使用原有 JSON 格式,与本变更无关。

## 验证

两项变更分别通过各自 PR 的 CI Maven 门禁与本地复验:全量 Maven 测试除本机 WSL 沙箱的 7 项预存环境失败外全部通过,前端 vitest 23 项全部通过;合并后在 `main` 上复跑题库 DSL、AI 起草与数据库初始化聚焦测试全部通过。正式发布前将按发布流程重跑完整门禁。
