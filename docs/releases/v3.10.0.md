## 主要变化

### 顶栏「AI 引擎」独立入口

- 顶栏新增**独立「AI 引擎」按钮**（数据库连接按钮左侧），弹层内集中：当前引擎状态行
  （本地 Ollama · 选定模型 / 网络 AI · 供应商 / 未就绪）、本地已安装 Ollama 模型下拉选择
  （切换时自动卸载上一个模型）、网络 AI 供应商管理（增删改、启用/停用、连通性测试）。
  设置页原「AI 模型」面板移除，顶栏是唯一入口；任意页面可达。
- **引擎未就绪有引导**：数据页自然语言生成 SQL 与练习页 AI 讲解在引擎未配置/不可用时，
  就地显示"AI 引擎未就绪"与一键打开引导；不会执行任何语句，手写 SQL 与本地学习主流程不受影响。
- 修正两处与实际行为不符的描述：NL2SQL **没有**"未配置 AI 时本地确定性生成兜底"（无模型时返回
  引导而非草稿）；网络 AI 失败**不会自动回落本地**（显式停用网络供应商才回到本地 Ollama）。

### 网络 AI 傻瓜化：19 家厂商预设 + 发现模型

- 新建/编辑网络供应商表单内置**「服务商预设」**：覆盖 DeepSeek、智谱 GLM、Kimi、通义千问
  （阿里云百炼）、豆包（火山方舟）、腾讯混元、百度千帆、讯飞星火、MiniMax、阶跃星辰，OpenAI、
  Anthropic Claude（官方兼容层）、Google Gemini、xAI Grok、Mistral，以及 OpenRouter、Groq、
  硅基流动、LM Studio（本机）等聚合与本地入口。选择后自动填入端点与默认模型，只需粘贴 API Key；
  表单同步显示各厂商的密钥申请入口与特殊说明（如方舟推理接入点、星火新模型鉴权格式）。
- **「发现模型」**：填好端点与密钥后一键拉取该供应商真实可用模型列表，模型名改为发现式下拉选择；
  编辑已保存的供应商时可借用其已存密钥（DPAPI 解密、一次性使用后清零），无需重新粘贴。
  「测试连接」的结果模型与发现结果共用同一列表；端点与模型始终可手动修改（自定义 OpenAI 兼容）。
- 预设端点与默认模型按 2026-10 各厂商官方文档核实；厂商配置随时可能调整，可自由编辑。

### 数据库连接弹层增强

- 弹层底部新增**「测试当前连接」**一键校验，成功/失败反馈明确。
- 服务器型连接（MySQL、PostgreSQL 等）行内新增**「重新输入密码」**快捷恢复：应用重启后无需编辑
  整份连接配置，就地输入密码重验即恢复，验证结果在本进程内有效。密码仍只暂存在本进程内存，
  不落盘、不回显。

## 升级与兼容

- 桌面端可经应用内更新直接升级；本地学习数据 schema 无新增迁移；云端服务端零变更。
- 本地 IPC 契约按 **additive-within-v1** 新增四个方法：`ai.engine.status`、`ai.model.list`、
  `ai.model.select`、`ai.provider.models`；`data.connection.test` 新增可选 `connectionId` 参数
  （按 id 直取已存连接配置）。旧调用行为不变，无破坏性变更。
- 安全边界不变：模型永不执行 SQL、永不获得 JDBC `Connection`；AI 生成的 SQL 仍走 Java 风险分析、
  预览与确认门禁；AI 供应商 API Key 仍 Windows DPAPI 加密、只写不回显，测试/发现请求中的密钥
  一次性使用后清零；AI 不参与判分，不掌管掌握度等权威学习状态。
- 新增/更新能力见[能力总览](../guide/00-capability-overview.md)与
  [用户手册](../guide/08-user-manual.md)；本地 IPC 契约明细见
  [本地应用 IPC 契约](../guide/21-local-app-ipc-v1.md)。
