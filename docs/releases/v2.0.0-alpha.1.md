# SQLTeacher v2.0.0-alpha.1

这是 v2.0 的首个预发布里程碑，面向开发验证，不替代最新稳定版 `v1.11.5`。

## 主要变化

- 建立通用学习活动、类型化规格/产物、确定性评价结果和跨活动证据合同；
- 建立课程、章节、学习成果、知识点与关系图谱骨架；
- 将现有 SQL 题目作为首个 `SQL` 活动适配器接入，保留原练习界面和安全评测行为；
- 本地 schema 升级到 11，旧 SQL 题目和会话自动映射到通用活动投影；
- 学习事件增加活动类型、评价器版本、证据版本和原因码，仍不记录无限长结果或凭据；
- Windows 打包支持 SemVer 预发布名与数值 MSI 版本的单调映射，预发布 Release 不会成为 Latest。

## 兼容与限制

- v1.11.5 的 SQL 题目、会话、尝试、事件和诊断事实保留；迁移前仍使用现有自动备份恢复流程；
- alpha.1 只注册 SQL 评价器。其他活动类型是冻结合同，必须在后续 Alpha 提供真实评价器后才能运行；
- UI 2.0、非 SQL 纵向闭环和独立代码 Runner 分别属于后续 Alpha，不在本版本提供占位入口；
- 本版本没有改变生产 Cloud API 合同，也没有放宽 SQL、AI、权限或隐私边界。

实现决策见 [alpha.1 RFC](../plans/2026-08-09-v2-alpha1-activity-kernel-rfc.md)，验证结果见
[alpha.1 门禁](../acceptance/2026-08-09-v2-alpha1-stage-gate.md)。
