## 主要变化

### SQL 反馈深化（SFE-1…3）——懂错在哪

- **结果集行列级对比 + 差异摘要**：失败对比表（W2.4 既有）顶部新增 Java 计算的摘要行——两边行数、是否差一列、
  首个差异单元格位置（"第 N 行第 M 列"）、行多重集合差异（仅期望有 / 你多出的行数）；结果超过 200 行只对比
  前 200 行并在摘要注明。`ResultComparison` additive 扩展 `summary` 载荷。
- **错误教学解读**：执行/评测/沙盒失败时，常见 SQLite 错误（外键、唯一、非空、CHECK、语法 near 词、
  表/列/函数不存在、无法识别符号、语句不完整、聚合误用）由 Java 纯映射表（`SqlErrorTeachingAdvisor`）
  追加"教学解读"块，指出违反的约束类型并给常见原因（如"先插父表再插子表"），未命中原样透传不臆造。
  工作台错误反馈区与练习分项反馈均独立渲染解读。
- **执行计划教学解读**：`EXPLAIN QUERY PLAN` 原文表格下方逐条给出白话结论与优化提示（SCAN → 全表扫描、
  `SEARCH … USING INDEX` → 索引命中、主键定位、TEMP B-TREE 排序/分组/去重、子查询物化），仅 SQLite 连接
  （沿用既有判定）；普通执行的展示不受影响。

### Schema 助学（SCH-1…3）——让 Schema 成为教具

- **外键元数据（SCH-1）**：`JdbcDatabaseMetadataService` 读取 `getImportedKeys`，按约束聚合为
  `DatabaseForeignKey`（列与引用列按位对齐，支持自引用与复合外键）；单表读取失败降级空列表
  （沿用 CXN-2 索引降级模式）。`data.schema` additive 扩展 `foreignKeys`，侧栏每张表新增"外键"分区。
- **表结构可交互（SCH-2）**：侧栏表名/列名可点击，按 `表名` / `表.列` 插入 SQL 编辑器光标处
  （走 Monaco `executeEdits`，撤销栈保留）；每张表新增"样例数据"动作——前端只传表名，SQL 一律由 Java
  侧构造为带 5 行上限的只读 SELECT（标识符按方言加引号 + 白名单字符双保险，经既有风险分析/执行路径，
  不写执行历史），在侧栏内以只读表格展示。
- **外键关系简图（SCH-3）**：表结构区头部"关系图"入口，基于外键元数据生成只读 Mermaid `erDiagram`
  （复用严格模式渲染，箭头从子表指向被引用的父表）；连接没有外键时明确提示，不做编辑/建模能力。

### 工作台效率（WBE-1…2）

- **SQL 格式化（WBE-1）**：编辑器工具栏"格式化"按钮——关键字大写归一、子句换行缩进、SELECT 列表逗号分列；
  纯本地文本重排（不经网络、不改 token 顺序、字符串/注释原样保留），经 Monaco `executeEdits` 整体替换，
  Ctrl+Z 一步恢复。
- **教学语句模板（WBE-2）**：工具栏"模板"下拉内置三表 JOIN、分组统计、子查询、INSERT…SELECT、条件更新
  五个教学常用骨架（命名与演示库 Student/Course/SC 对齐），点击插入光标处。

### 课程化练习路径（EPATH-1…3）——知道下一步练什么

- **路径数据模型（EPATH-1）**：题库 DSL 新增 `===[PATH]===` 块（章节序｜章节名｜知识点标签｜题目 ID），
  随题库版本分发（沿用 bank_version 单调版本 + 清单分块通道，不新增服务端端点）；服务端发布/清单/回滚、
  客户端流式同步与本地 `exercise_paths` 表（Migration 25）全链路支持。旧客户端清单无 PATH 引用、
  行为不变；旧格式包解析结果不变。
- **练习页路径视图（EPATH-2）**：练习页新增可折叠"学习路径"入口，按章节分组展示（`practice.paths`
  新 IPC 返回路径 + 当前学习者的完成态/掌握态），点击题目进入既有练习流；无路径数据时整体隐藏，
  推荐与错题本入口不变。内置题库随包分发两条演示路径（SQL 查询 5 章、SPJ 3 章）。
- **章节↔知识文章联动（EPATH-3）**：章节知识点标签与课程知识文章的章节名/知识点按名称精确映射，
  命中时章节行显示"相关阅读"深链直达知识页（`/knowledge?article=`）；无映射不显示。

## 兼容性说明

- **桌面数据库**：Migration 24 → 25（新增 `exercise_paths` 表），additive、幂等，旧库自动迁移。
- **云端**：无 schema 变更、无新端点；题库清单 additive 新增 `paths` 引用数组，旧客户端忽略。
- **IPC**：契约版本不变（3.0-v1），additive 新增 2 个方法：`data.table.sample` 与 `practice.paths`，
  契约三处（`LocalAppContract`/`manifest.json`/`lib.rs`）同步登记并有契约一致性测试守护。
- **题库 DSL**：格式版本仍为 1；`===[PATH]===` 为新块类型，旧客户端不会从清单收到 PATH 块引用。
- **行为变化**：无安全边界变化。样例数据预览与关系图均为只读，语句由 Java 构造并走既有只读执行路径；
  判分仍由确定性评估给出，差异对比只是展示层增强。

## 已知限制与后续积压

- 样例数据预览的取行子句按方言族选择（TOP / FETCH FIRST / LIMIT）；未列名的冷门方言按 LIMIT 处理，
  个别方言如不支持会报错并附教学解读。
- 学习路径的状态徽标来自本机进度与掌握快照，多账号场景按当前登录者计算（与练习进度页一致）。
- 计划"明确不做"清单锁定不变：AI 判分/语义比对、存储过程教学与第二评测引擎、事务故障注入判分、
  课堂投影/实时协同视图、ER 图编辑建模均不入本版（见计划第 6 节积压）。
