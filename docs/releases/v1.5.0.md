# SQLTeacher v1.5.0

v1.5.0 是桌面 UI 与易用性专项版本，不改变 SQL 安全、任务快照、反馈审计和云端权限边界。

## 新增与改进

- 将 11 个同级横向入口重构为角色化分组侧栏，低分辨率下不再依赖导航横向滚动。
- 新增浅色、深色和跟随 Windows 系统主题，可即时应用并持久化。
- 新增现代中文、系统默认、经典清晰三种界面字体方案，以及舒适/紧凑界面密度。
- 使用统一 JavaFX 矢量图标替换主导航和首页 emoji/临时色块。
- 设置中心向访客、学生、教师和管理员开放；备份恢复和运维能力使用设置项级权限限制。
- 首页卡片支持键盘焦点与 Enter/Space 操作。
- 学生练习页明确运行与提交层级，增加运行、提交和提示快捷键及重复操作保护。
- 教师课程、题目、任务、反馈和通知重构为标签式教学工作台，减少长页面滚动和上下文丢失。
- 统一焦点环、主题状态、字体回退和显示缩放要求。

## 安全与隐私

- UI 隐藏或禁用不作为安全边界；敏感设置继续由应用服务或云端鉴权。
- 主题、字体和密度偏好仅包含非敏感枚举值，保存在当前 Windows 用户配置中。
- 未放宽 SQL 风险检测、多语句阻止、AI 草案预览或云端 HTTPS 限制。

## 已知限制

- 跟随系统主题在应用启动时读取；运行期间切换 Windows 主题后需重启应用。
- 安装器尚未代码签名，请从正式 GitHub Release 下载并核对 `SHA256SUMS.txt`。
