# SQLTeacher v2.0.0-beta.1（候选说明）

`2.0.0-beta.1` 是一次性完成全部 Beta 收敛门禁的功能冻结候选。它不创建新的产品方向，而是把 Alpha 已建立的课程、活动、Runner、项目、课程包、Cloud 2.0 和 UI 入口补齐为稳定契约。

## 主要变化

- LAB 与 READING 成为真实可运行活动，八种活动类型全部接入评价、持久化、诊断和 JavaFX 工作区。
- 增加综合项目路径，内置课程达到 12 条；课程来源、许可、作者和跨课程关系进入 schema 17。
- 诊断按活动类型使用版本化证据权重，阅读完成本身不再可能被解释为掌握。
- 预发布签名清单支持 alpha/beta/rc，同时稳定安装继续拒绝预发布通道。
- 公开名称保留 SQLTeacher，数据目录、安装升级身份、Java package 和 Cloud 兼容入口不变。

## 兼容性

- 本地 schema 从 16 追加迁移到 17，不删除 Alpha 或 1.x 事实数据。
- Cloud API 仍使用 2.0 能力协商，本版本不新增 Cloud 主端点或生产数据库迁移。
- Beta 起活动类型、课程格式、本地数据库体系和顶层 UI 架构冻结；后续 RC 只处理发布阻断、兼容、安全、内容事实和可访问性缺陷。

## 安全说明

SQL 安全链、AI 非权威边界、课程包不可信输入策略和双 Runner 边界没有放宽。本地 IDE 运行仍由学生主动发起并允许真实本机环境与联网；安全评价继续在独立受控 Runner 中执行。
