# SQLTeacher v2.0.0-alpha.4

这是 v2.0 的第四个预发布里程碑，SQLTeacher 从通用学习平台原型推进为本地优先的计算机专业学习 IDE。本版本以 GitHub prerelease 发布，不替代当前稳定版本。

## 主要变化

- 新增 Java、Python、C、C++ 代码活动和“编程语言基础”课程路径；
- 通用实验工作区增加代码编辑器、标准输入、控制台、本地运行、取消和打开终端；
- 本地运行直接使用学生的 JDK、WSL Python、MSVC、文件和网络权限，非 SQL 代码风险由学生负责；
- 增加可选“安全评价”，在 WSL2 隔离环境中运行课程固定测试并保存确定性证据；
- 安全评价区分编译、运行、时间、内存、工作区、进程、输出和取消原因；
- 首页、侧栏、README 和 Windows 包元数据统一为“计算机专业学习 IDE”。

## 环境与兼容性

- 本地 schema 从 12 升级到 13，追加编程课程和四种 CODE 活动，不删除既有 SQL/QUIZ/TRACE 数据；
- Java 本地运行需要 JDK 21，Python 本地运行需要 WSL Ubuntu，C/C++ 本地运行需要 MSVC；
- 安全评价是可选 WSL2 能力，缺少 Ubuntu、systemd、隔离原语或工具链时拒绝执行并显示稳定原因；
- SQL 风险确认、AI 信任边界、教师权限、Cloud API 和学生隐私规则保持不变。
