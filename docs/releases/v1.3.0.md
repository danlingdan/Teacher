# SQLTeacher v1.3.0

SQLTeacher v1.3.0 是教学任务闭环与运维自动化版本。

## 主要变化

- 教师可保存、复制、编辑和发布带版本号的任务，旧版本更新会明确冲突。
- 学生从云端任务进入本地隔离练习，确定性评测摘要以幂等操作 ID 提交。
- 断网提交按账号持久化到本地队列，重启后可重试，不保存 SQL、令牌或连接秘密。
- 教师可查看任务完成率、通过率、尝试次数和常见错误，并导出同口径 CSV。
- 管理员可查看健康摘要、禁用/恢复账号、撤销会话并查询脱敏审计。
- 云端数据清理具备最短保留期、影响预览、备份门禁、事务归档和恢复能力。
- 证书续期、每日备份、恢复和运维健康检查已形成可重复脚本与定时任务。

## 数据升级

- 桌面 `app.db` schema：4 → 5，新增账号隔离的任务提交队列。
- 云端数据库启动时幂等补齐任务 v2、提交、管理员审计和保留作业表。
- 旧任务保持已发布状态，版本从 1 开始。

## 安全边界

- AI 输出仍不会直接执行，任务成绩仅来自 Java 侧确定性评测。
- 服务端最终校验成员关系、任务状态和截止时间。
- 审计和队列不保存密码、令牌、API Key、连接秘密或完整 SQL。
- 正式云端地址只允许 HTTPS；HTTP 仅允许回环开发地址。
