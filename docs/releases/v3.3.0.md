# SQLTeacher v3.3.0

> 发布日期：未发布（本地候选，版本号已定）
>
> 全面提升 SQL 教学能力：练习新增写操作、脚本与触发器三类可判分题型，判分附带确定性得分与期望/实际对比，错题本与推荐构成个性化闭环，题库分发升级为多频道多版本生态；同步完成 UI 质量与平台遗留清偿。

## 主要变化

### 练习题型体系（W1）

- **四类确定性判分题型**：在原查询题（单条 SELECT）之外新增——
  - **写操作题（STATE）**：学生提交单条 `INSERT`/`UPDATE`/`DELETE` 等写语句（教师可按题声明允许的语句类别，缺省 INSERT/UPDATE/DELETE，可扩展 CREATE/DROP/ALTER/SELECT）。
  - **脚本题（SCRIPT）**：学生提交多语句脚本按顺序执行（上限 100 条、总超时 10 秒不变），可要求使用事务关键字（`BEGIN`/`COMMIT` 等）作为独立判分分项。
  - **触发器题（TRIGGER）**：学生提交一条 `CREATE TRIGGER` 定义，系统自动执行教师提供的触发场景语句，再以验证查询比对最终数据状态。
- **写类题型的判分方式**：参考答案与学生提交在两份相同初始数据的一次性沙盒库上分别执行（触发器题先执行探针语句），再以教师声明的单条 SELECT 验证查询比对终态；影响行数可声明为独立分项。执行失败、验证查询失败、破坏表结构都会得到明确的中文归因反馈。
- **题库 DSL 扩展（全部可选，旧包零改动导入）**：`TYPE:`、`VERIFY:`、`ALLOWED:`、`AFFECTED:`、`TXN:`、`PROBE:`；导入自测对四类题型执行与运行时完全一致的校验（参考答案、验证查询、探针真实执行且满足自身规则）。
- **沙盒安全边界**：写类题目的作答在一次性隔离库上进行，不弹工作台确认对话框；FORBIDDEN 类语句（PRAGMA、ATTACH、文件读写、用户/角色管理、多语句欺骗）在全部题型下硬拦截。查询题行为与 v3.2 完全一致，学生可随时一键重置本题数据。
- **工作台同步增强**：`CREATE TRIGGER` 的语句体不再被误判为多语句——工作台现在可以执行触发器定义（仍走高风险确认制）。

### 判分与个性化闭环（W2）

- **分项权重与展示得分**：题目可用 `WEIGHTS:` 为各判分分项赋权重，反馈给出 0–100 的确定性得分；"全部分项通过才算通过"的语义不变，得分仅用于反馈与学情展示。目录与作答界面显示最佳得分与未通过分项。
- **期望/实际对比视图**：评测失败时反馈区提供期望与实际结果的并排表格，单元格级差异由 Java 确定性计算并标红；教师按题用 `REVEAL:`（`never`/`on-fail`（缺省）/`always`）控制是否展示期望数据行，`never` 时任何载荷都不含期望数据。提交前任何状态都不会泄露期望数据。
- **错题本**：练习页新增"错题本"标签，聚合做错且尚未通过的题目（尝试次数、最佳得分、最近反馈），一键重练开新会话；数据全部来自本机确定性统计。
- **AI 讲解草稿**：失败反馈区可按需请求 AI 讲解——只读展示、标注"仅供参考，不影响判分"，不写入任何学习状态、不影响推荐与掌握度；提示词明确禁止泄露参考答案与期望数据。
- **推荐下一题**：目录上方按本机作答历史给出确定性推荐（知识点正确率 × 难度层级的固定规则，无随机、无 AI），附推荐理由（如"正确率 33%，建议先巩固基础题"）。

### 查询教学与性能深化（W3）

- **执行计划**：`EXPLAIN`/`EXPLAIN QUERY PLAN` 在 SQLite 方言下按只读放行（LOW，行数与超时上限不变）；SQL 工作台新增"执行计划"按钮，对当前语句自动包裹执行并以表格呈现。
- **期望结果形状**：题目可用 `EXPECT_COLUMNS:` 声明期望列，题面下方直接展示，帮助学生核对列名与顺序。
- **索引实验题**：题目可用 `PLAN_KEYWORDS:` 对 `EXPLAIN QUERY PLAN` 输出做短语断言（如要求出现 `INDEX idx_score`）；验证查询限定为 EXPLAIN 语句，导入自测会验证参考答案的执行计划确实满足断言。
- **教师题库体检**：教师题库页新增"题库体检"，对库内全部题目（含四类题型）批量执行与导入自测同等校验，产出题目级报告并可复制文字报告；只读、无副作用。

### 题库分发与内容生态（W4）

- **内置第二题库**：新增"供应商-零件-工程"（S/P/J/SPJ）题库包，10 道题覆盖基础查询、条件筛选、去重、分组聚合、连接、子查询（NOT EXISTS）与综合聚合，全部通过导入自测与真实评测验证；随应用启动幂等应用。
- **多题库频道**：服务端题库接口支持频道维度（如 `network`、`spj`），每个频道独立维护版本序列；`GET /api/v1/bank/channels` 列出可用频道。客户端在"设置 → 题库更新"中订阅频道，未订阅的频道不拉取、不入库。
- **题库多版本与回滚**：服务器为每次发布保留完整分块快照，管理员可将激活版本回滚到任意历史版本，对全体客户端即时生效；发布与回滚全程写入 `admin_audit`。
- **定时检查（opt-in）**：设置页可开启题库定时检查（默认关闭），开启后每 6 小时后台检查订阅频道，发现更新仅在练习页提示，绝不自动应用、不打断练习；离线或失败静默降级。
- **目录分页**：`practice.catalog` 支持服务端分页与过滤（每页上限 500，默认 50），前端按页拉取，题库规模增长不再拖慢目录加载。

### UI 与平台质量（W5/W6）

- **教师学情结构化呈现**：班级学情与云端学情报告从 JSON dump 改为结构化指标卡与知识点/常见错误分表，指标中文化、比率百分比化。
- **Monaco 补全隔离**：练习编辑器与 SQL 工作台的补全 provider 按模型 URI 过滤，互相不再污染；符号槽位改为副作用刷新，消除渲染期模块变量写入。
- **CSV 导出加固**：以 `=`、`+`、`-`、`@`、制表符开头的单元格自动前缀中和，防止在电子表格中作为公式执行；导出路径强制 `.csv` 扩展名并校验父目录存在。
- **SQL 审计事件闭环**：高风险确认的签发、消费、取消/过期三处现在都会记录学习事件（`SQL_CONFIRMATION_ISSUED`/`SQL_CONFIRMED`/`SQL_CONFIRMATION_CANCELLED`），随既有云同步通道上报。
- **学习队列批量接口**：新增按班级一次取回本人全部任务通过状态的只读端点，消除学习队列刷新的逐任务 N+1；旧服务端自动回退逐任务查询，部署顺序无关。
- **服务端清理任务**：新增管理员清理接口（先 dry-run 报告数量，再执行），覆盖过期/吊销令牌与 `retention-backups/` 旧备份文件；保留期可用 `SQLTEACHER_CLOUD_TOKEN_RETENTION_DAYS`、`SQLTEACHER_CLOUD_BACKUP_RETENTION_DAYS` 覆盖，全程审计。
- **组件安装异步化**：组件安装立即返回"安装中"，进度经事件流上报，终态由状态轮询获得；子进程以管道重定向启动，不再弹出控制台窗口。
- **DPAPI 与退出排空**：DPAPI 密文仅在解密确定性失败时清除，瞬时读取故障不再误删；桌面退出时等待 Java 侧排空的上限从 500ms 提升到 5 秒，降低关闭时数据未落盘的概率。

## 兼容性说明

- 题库 DSL 新字段全部可选：旧格式题库包零改动导入；旧版客户端/服务端不读取新字段。
- 客户端按服务端 capabilities 自动降级：旧服务端（无批量端点/频道接口）保持逐任务查询与默认频道，部署顺序无关。
- 本地数据库自动迁移（schema v21–v22：题目类型配置与尝试得分列），升级前后无需手工操作。
- 存储 `CREATE TRIGGER` 的行为变化：此前触发器定义会被多语句检查拒绝，现在作为单条 DDL 按高风险确认制放行。
- 存储过程教学仍不支持（SQLite 引擎限制），列入后续候选。
