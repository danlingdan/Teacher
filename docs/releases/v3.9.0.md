## 主要变化

### 云端任务直达（INT-1 首条切片）

- **通知直达对象**：顶栏通知里的"新任务 / 新反馈"点击后直接定位到对应班级的任务或该任务的
  反馈视图，不再一律落到「班级与云端」总页让用户自己找班级找任务。目标不存在、无权限或
  加载失败时显示可恢复的明确状态，不泄露其他班级内容。
- **登录回跳保留目标**：未登录状态打开任务/反馈深链时，登录后回到原目标（含云端对象参数），
  不再丢失查询参数；仅允许站内安全路径，伪造目标回落「班级与云端」。
- **账号与班级上下文隔离**：班级任务与提交反馈缓存按"账号 + 班级"分键，切换账号不再看到
  前一账号的任务列表；切换班级立即清理反馈选区与未保存标记，前一班级的迟到响应一律丢弃，
  避免私有反馈瞬时串显。
- **任务列表状态真实化**：班级任务加载失败明确报错并可重试，不再把失败伪装成"当前班级还
  没有任务"的空列表；加载中与真正的空班级状态分开呈现。

### 用户反馈修复（2026-10-01）

- **查看学情崩溃修复**：教师点「查看学情」整页报"Cannot convert undefined or null to object"
  ——学情面板读取了后端从未返回的 `overview` 字段（v3.3 起存在，无测试覆盖所以一直未被发现）。
  现按班级/任务学情报告的真实字段呈现概览指标（任务：学员总数/已提交/已通过/尝试总数/完成率/
  通过率；班级：学员总数/活跃学员/同步事件/成功事件）与常见错误、学生提交明细。
- **找回密码发码失败兜底**：发送验证码请求失败时（典型：触发每小时 3 封的发送上限，或代理/
  断网），找回页新增"已收到验证码？直接输入验证码 →"入口，先收到邮件的用户仍可进入输码步骤
  完成重置；验证码正确性仍由服务端校验，入口不改变安全语义。

## 升级与兼容

- 桌面端 3.8.0 及以后可经应用内更新直接升级；本地学习数据 schema 无新增迁移。
- 云端服务端零变更：无新端点、无迁移，本版只需轮换桌面端更新清单。
- 安全边界不变：URL 参数只负责定位，Java 桥接与云端服务照常执行角色与数据边界检查；
  SQL/AI 安全策略、判分与学习权威状态零改动。
