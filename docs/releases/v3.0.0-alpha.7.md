# SQLTeacher v3.0.0-alpha.7

> 发布日期：2026-08-11
>
> 发布类型：v3.0 最后一个 Alpha 预发布，不进入 stable 更新通道

## 本次预览内容

- 完成“今天、课程与知识、练习与实验、数据/SQL/AI、教学空间、班级与云端、设置与环境”七个 React/Tauri 工作区的 Alpha 功能对齐。
- 新增课程、知识条目与 Obsidian Vault 安全增量导入；外部资源、原始 HTML 和 Dataview 仍按安全策略降级。
- 新增练习 Runner、Monaco 编辑体验、确定性评价与进度反馈，并保留 Java 对资源限制和学习状态的权威控制。
- 接入数据连接、SQL 安全模式和 AI 辅助流程；风险分析、确认、超时、结果限制、审计与确定性降级仍由 Java 强制执行。
- 新增教师题库与学情、真实会话角色、账号登录/退出、班级创建、显式云同步及环境探测。
- 完善版本化 IPC 合同、跨语言清单一致性、错误恢复、离线启动、打包态 E2E 与迁移状态页。

## 安全与兼容边界

- WebView 和模型不会获得 JDBC 连接、Spring Bean、任意命令或任意文件访问能力。
- Java 和云端服务分别执行本地与服务端角色校验；前端角色守卫不是授权边界。
- 密码、令牌和连接信息不会写入 Web Storage、日志或普通 IPC 响应。
- 本版本不改变 SQLite schema 语义，不迁移或删除用户数据。
- Windows x64 安装包和便携包包含 Java 25 运行时；JavaFX 入口继续保留为稳定回退，生产默认入口仍未切换到 v3。

## 已知限制

- 这是最终 Alpha，而非稳定版；干净 Windows 10/11 安装、覆盖升级、卸载和失败回退矩阵将在 Beta 门禁继续验证。
- Vite 仍提示 Monaco 与 Mermaid 大分块，首屏拆包与两小时稳态测试留待 Beta 性能收敛。
- 当前 AI 流式展示基于现有 Java 提供者能力，尚不是所有提供者的原生逐块传输。
- NSIS 继续使用 WebView2 在线下载引导模式，离线安装器与固定运行时模式仍待验证。

完整证据见 [Alpha.3 至 Alpha.5 阶段门禁](../acceptance/2026-08-11-v3-alpha3-alpha5-stage-gate.md)和
