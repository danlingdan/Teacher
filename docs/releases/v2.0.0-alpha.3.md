# SQLTeacher v2.0.0-alpha.3

这是 v2.0 的第三个预发布里程碑，首次提供 SQL 之外的完整学习活动闭环，不替代最新稳定版
`v1.11.5`。

## 主要变化

- 新增“数据结构与算法 / 二叉树遍历”内置课程单元；
- 新增前序遍历概念测验和可交互二叉树步骤跟踪；
- 测验与跟踪由 Java 确定性评价器检查，不依赖 AI、网络或代码执行；
- QUIZ、TRACE 与既有 SQL 证据可按知识点合并诊断，并生成可直达活动的巩固建议；
- 教师和管理员可复核本机非 SQL 评价证据并发布反馈，学生重新打开活动即可查看；
- 通用实验工作区修复异步目录加载覆盖目标活动的问题。

## 数据与兼容性

- 本地 schema 从 11 升级到 12，追加内置课程数据和 `activity_feedback`；
- 旧 SQL 课程、练习、会话、风险确认和评价路径保持不变；
- 本版本不执行任意代码；Java/Python/C/C++ Runner 属于后续 alpha.4；
- Cloud API 没有变化，通用活动云同步仍属于后续阶段。

实现决策见 [alpha.3 RFC](../plans/2026-08-09-v2-alpha3-binary-tree-learning-loop-rfc.md)，
验证结果见 [alpha.3 门禁](../acceptance/2026-08-09-v2-alpha3-stage-gate.md)。
