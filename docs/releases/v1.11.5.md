# SQLTeacher v1.11.5

v1.11.5 是界面本地化完整性修复：英文资源包中 109 个动态拼接片段键此前仍是中文值，英文界面会显示中文碎片（如"共"、"已显示前"、"将发送"），本版本全部补齐翻译。

## 主要变化

- 修复英文包 109 个键的中文残留值（动态拼接片段，如 `共`、`已显示前`、`将发送`、`· 截止：` 等）。
- 新增回归门禁：`AppI18nTest` 增加"英文包任何值不得包含中文字符"断言，防止再次出现中英混杂。

## 兼容性

- 支持从 v1.10.1、v1.11.0~v1.11.4 原位升级，保留 `app-data` 用户数据。
- Cloud API 版本保持 `1.11`，最低兼容客户端为 1.9.0；本版本为纯桌面客户端改动，生产 Cloud 无需升级。
- 需要 Windows x64；正式安装包和便携 ZIP 均自带 Java 21 运行时。
