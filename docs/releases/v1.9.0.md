# SQLTeacher v1.9.0

v1.9.0 将课程知识、确定性学习诊断和云端协作收敛为可验证的教学编排闭环。

## 主要更新

- 教师可维护带版本、先修关系、完成条件和资源关联的课程目标。
- 学生端按任务、反馈、先修缺口和练习证据生成稳定、限长且可解释的学习计划。
- 计划动作支持开始、完成、忽略、失效、重算以及离线 Outbox 同步。
- 辅导会话绑定课程目标与检索快照，只保留最小引用和枚举反馈，并支持无依据降级。
- 教师可按课程目标查看班级摘要，经过影响预览、短期确认令牌和版本复核后发布干预。
- 本地数据库升级到 app schema 10，云端数据库升级到 Cloud schema 5。
- 云端新增目标、计划状态、干预审计和规划健康接口，继续保持 loopback 服务与 HTTPS 反向代理边界。

## 兼容与安全

- Java 21 LTS 编译目标保持不变。
- AI 不决定掌握度、计划优先级、正式任务或教师干预对象。
- Qdrant、Embedding、联网搜索或 AI 不可用时，本地练习、诊断与确定性计划仍可运行。
- 课程目标和计划缓存均按账号、课程与版本隔离；服务端迁移保持幂等并拒绝未知未来 schema。

## 发布验证

- Maven：362 项测试通过，0 失败、0 错误；2 项在线 AI 冒烟测试按环境设计跳过。
- Windows：EXE、Windows x64 ZIP、app-image 和双条目 `SHA256SUMS.txt` 生成并验证。
- 固定旅程：30 条学习计划旅程通过。
- 容量夹具：10,000 条个人事实重算及 500 名学生目标汇总通过。

## 本次裁剪

学习日历、个人目标、课程包 v4、教师 AI 备课/题目草稿和独立容量页面保留为后续增强；它们不影响 v1.9.0 的课程目标、学习计划、辅导与教师干预核心闭环。
