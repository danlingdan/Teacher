# SQLTeacher v2.0.0

SQLTeacher 2.0 将原有 SQL 学习应用扩展为本地优先、可验证的计算机专业学习 IDE。SQL 仍是完整课程实践能力，但不再是产品唯一中心；Java、Python、C/C++、系统模拟、项目学习、课程知识和教学协作共享统一学习闭环。

## 主要变化

- 建立 SQL、QUIZ、TRACE、SIMULATION、CODE、LAB、PROJECT、READING 八种类型化活动及确定性评价契约。
- 提供 12 条计算机专业课程路径、课程来源与许可记录、跨课程关系、项目作品和可重算学习诊断。
- JavaFX UI 2.0 使用任务中心、课程地图、通用实验工作区、响应式布局、动画和可访问性设置。
- 本地学习 IDE 支持 Java、Python、C/C++ 和 SQL；学生主动运行可使用本机工具链与网络，正式评价仍由独立受控 Runner 执行。
- 课程包作为不可信输入进行预检；Cloud 2.0 提供能力协商、项目元数据与最小摘要同步、幂等和显式冲突。
- 诊断按活动类型使用版本化证据权重，AI 只提供解释或草稿，不决定掌握、评分、队列或执行动作。

## 升级与兼容

- 本地数据库追加迁移到 schema 17，不删除 1.x、Alpha、Beta 或 RC 的事实数据。
- 公开名称、Java package、数据目录和生产 API 地址保持兼容；最低更新支持版本为 1.9.0。
- Windows 安装版与便携版均为 x64，要求 Java 21 构建环境；安装包自带运行时，不要求用户单独安装 JDK。

## 安全与隐私

- 模型不能执行 SQL、访问 JDBC 连接或直接改变权威学习状态。
- SQL 继续经过结构化解析、风险分析、预览、必要确认、限制执行和审计记录。
- 本地学生代码的运行风险由学生自行承担；课程正式安全评价使用独立 Runner 的时间、内存、输出、文件、子进程和凭据继承限制。
- 更新包只接受内置公钥签名、固定 HTTPS 来源、大小与 SHA-256 校验；稳定安装只接收 stable 清单。
