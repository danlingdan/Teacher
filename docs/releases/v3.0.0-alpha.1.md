# SQLTeacher v3.0.0-alpha.1

> 发布日期：2026-08-11
>
> 发布类型：3.0 UI 迁移技术预览，不进入 stable 更新通道

## 本次预览内容

- 桌面运行时升级到 Java 25，并保留 Java 确定性学习与 SQL 安全边界。
- 新增 Tauri 2 + React 桌面壳；Java 核心通过版本化本地 Sidecar 合同提供真实首页、知识样本和编辑器能力。
- Sidecar 支持方法白名单、请求 ID、结构化错误、事件、取消、超时、载荷限制和窗口关闭后的进程回收。
- 知识渲染样本覆盖 frontmatter、Callout、KaTeX、Wiki 链接、Mermaid 与 Dataview 安全降级。
- Monaco 使用本地资源，首批支持 SQL 与 Java 高亮。
- 提供 NSIS 安装包和包含 jlink Java 25 运行时的 Windows x64 便携包。

## 安全与兼容边界

- WebView 和 Rust 不获得 JDBC、Spring Bean、任意命令或任意文件访问能力。
- SQL 执行没有迁入 Web/Rust，仍由 Java 服务执行风险分析、确认、超时、结果限制和审计。
- 外部 Markdown 资源、原始 HTML 与 Dataview 执行默认禁用。
- 这是开发者预览版；正式默认入口仍是 v2.3.0 JavaFX。

## 已知限制

- 尚未完成干净 Windows 10/11 虚拟机上的安装、覆盖升级、卸载和失败回退矩阵。
- 当前 NSIS 使用 WebView2 在线下载引导模式，离线安装器与固定运行时模式仍待验证。
- 完整的 2.3/3.0 同机十轮性能矩阵及两小时稳态测试仍待完成。
- Java 与 npm 分别提供 CycloneDX SBOM；Cargo 依赖仍以锁文件记录，合并 SBOM 留待后续 Alpha 门禁。
