# SQLTeacher v1.10.0

v1.10.0 是通用桌面软件能力版本。本次不扩展 SQL 教学专业功能，重点补齐可信更新、问题反馈、诊断恢复、设置治理和正式软件发布透明度。

## 主要变化

- 新增“设置 → 更新与支持”，提供稳定版检查、签名清单验证、受控下载、大小与 SHA-256 复核、跳过版本和安装器交接。
- 新增访客/登录用户问题反馈、最小诊断预览、本地诊断 ZIP、回执编号、匿名查询凭据、幂等、限流与服务端保留边界。
- 新增单实例激活、窗口位置恢复、异常启动识别、统一有界后台线程池、任务/通知快照、存储分类和白名单清理。
- 新增通用设置原子存储、损坏隔离、非敏感导入导出、代理策略、高对比度与减少动态效果基础。
- 新增账号改密并撤销全部会话、离线帮助、隐私说明、第三方许可证和 CycloneDX SBOM。
- Cloud API 增加 `1.10` 能力协商、反馈接口和只读更新清单端点；请求正文统一限制为 64 KiB。

## 安全与隐私

- 更新清单使用 Ed25519 签名，客户端仅信任内置公钥和固定 HTTPS 域名；私钥不进入仓库、安装包或云服务器。
- 诊断默认不包含数据库、SQL、Prompt、密码、Token、AI Key 或任意附件；发送前必须由用户预览并确认。
- 更新和反馈失败不阻断离线 SQL 教学功能；异常栈不会原样显示到界面。

## 兼容性

- 支持从 v1.9.0 正式安装版原位升级，保留 `app-data` 用户数据。
- 需要 Windows x64 和 Java 21 打包运行时；便携 ZIP 可继续手动替换程序目录。
- Cloud 最低兼容客户端为 1.9.0。

## 后续增强

断点续传、截图附件、完整英文界面、原生通知、邮件密码重置、账号注销、分阶段发布和安装修复入口保留给 v1.10.x；这些增强不削弱 v1.10.0 的更新信任、反馈隐私和恢复门禁。
