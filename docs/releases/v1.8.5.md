# SQLTeacher v1.8.5

v1.8.5 将 v1.8.0 的课程知识中心升级为本地优先、可降级、可评测的混合 RAG 基础设施。

## 主要变化

- app schema 9 保存细粒度片段、索引任务、嵌入配置、阅读进度、联网来源缓存元数据和检索反馈；已有 schema 8 数据自动进入待索引队列。
- 使用 Ollama `/api/embed` 生成本地嵌入，使用嵌入式 Lucene HNSW 保存向量；模型不可用、索引为空或查询失败时确定性回退到 SQLite FTS5。
- 关键词与语义候选通过 RRF 融合；课程、章节、知识点、所有者和发布状态在返回结果前再次过滤。
- 知识中心显示索引模式与队列状态，支持显式重建、标记已读、PDF/DOCX 导入和带来源的联网搜索。
- Brave Search 默认关闭且需要用户配置密钥；每次联网查询都需要确认。网页抓取限制协议、重定向、响应大小和内容类型，并阻断本机、私网及保留地址。
- Cloud schema 4 增加共享知识文章、不可变修订、片段、同步游标、事务 Outbox 与嵌入画像；云 API 强制课程所有者写入和发布可见性读取边界。
- 服务端 Qdrant 支持 payload 课程/可见性过滤、批量 upsert、查询、重建和快照；云端使用 RRF 融合关键词与语义候选，返回前再以事实库复核授权。桌面端不会直接连接 Qdrant，未配置或故障时云端关键词检索仍可用。
- 提供首批 40 问 JSONL 黄金集和 Recall@K、MRR、拒答精度、引用覆盖率、P95 延迟的确定性计算器。

## 配置

- 本地嵌入模型：系统属性 `sqlteacher.knowledge.embedding-model`，默认 `embeddinggemma`。
- Brave Search：环境变量 `SQLTEACHER_BRAVE_API_KEY` 或系统属性 `sqlteacher.knowledge.brave-api-key`。未配置时功能保持关闭。
- Qdrant 仅由服务端运维配置，API key 不进入桌面配置、日志或知识内容。
- 生产 Embedding Provider 为 FastEmbed `BAAI/bge-small-zh-v1.5`（512 维），模型离线加载且服务只监听 loopback。

## 安全与降级

- AI 仍只能解释用户确认发送的检索片段；引用缺失时拒绝展示无依据答案。
- 联网内容不会自动写入课程知识库，也不能覆盖 SQL 风险规则、确定性评测或掌握度事实。
- 向量索引是可删除、可重建的派生数据；SQLite 文章、修订和发布状态仍是事实来源。
