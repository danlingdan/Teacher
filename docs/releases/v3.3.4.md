# SQLTeacher v3.3.4

> 发布日期：2026-09-14（已公开，GitHub Release Latest 见 releases/README）
>
> v3.3.4 交付 2026-09-14 全界面 UI 审计（教师、学生、管理员、未登录四种身份逐页核查）的全部修复：六个界面缺陷、八项体验改进，以及教师班级面板重构与命令面板实体搜索两项结构升级。完整清单见[审计报告与修复计划](../plans/2026-09-14-ui-audit-findings-and-fix-plan.md)。

## 主要变化

### 界面缺陷修复

- **深色主题下代码编辑器配色**：练习作答、自由编程与 SQL 工作台的编辑器此前在深色模式下仍为白色高亮，与界面严重割裂；现在注册了与界面配色一致的 `sqlteacher-dark` 主题并跟随"主题"设置（含高对比度变体）实时切换。
- **备份时间显示 1970 年**：设置 → 备份与本地数据的备份时间此前显示为 1970 年（Java 秒级时间戳被前端按毫秒解析）且为英文格式；现在统一按中文格式显示真实时间。登录会话"时间未知"与学情"生成时间"一并修正。
- **课程与知识页空态引导**：学生账号没有知识文档时，页面此前只有一句"选择一篇知识文档"；现在明确提示文档来源与课程树的定位，文档列表为空时也给出说明，不再像功能损坏。
- **"完整学情分析"空面板**：教学空间展开该面板后此前完全空白；现在有加载态与空态文案。
- **快捷键帮助与实际不符**：帮助里的快捷键列表此前过期；现在与实际一致（Ctrl+K 搜索、Ctrl+1~7 切换工作区、Ctrl+, 设置、编辑器内 Ctrl+Enter / Ctrl+Shift+Enter / F1）。
- **错题本布局**：错题本此前复用了双列布局，整个内容被压进侧栏宽度的窄列、步进器文字断行；现在改为单列全宽布局。

### 练习与实验

- **作答时可见题目要求与数据结构**：作答视图此前只有题目标题和编辑器，学生需要回到预览记忆要求；现在编辑器上方直接显示题目描述与期望列，表结构收进可折叠的"数据表结构"面板并逐表分行展示。
- **界面枚举中文化**：预览卡、错题本、课程活动预览此前直接显示 `BEGINNER`、`QUERY`、`SIMULATION` 等原始枚举；现在统一显示"入门/进阶/高级""查询题""模拟实验"等中文标签，运行反馈徽标兜底文案改为"待运行"。
- **错题本与课程活动的标签修复**同上，由本次枚举映射统一覆盖。

### 班级与云端

- **教师班级面板重构**："添加成员"与"新建任务"拆分为两个独立折叠面板（各自带"待提交/草稿未保存"状态提示），截止时间新增"今天 18:00 / 明天 18:00 / 7 天后 18:00"快捷项与一键清除；"提交状态/起止时间"筛选与"查看学情/导出学情"合并为紧贴任务列表的常显工具栏，不再与创建表单混在一起。
- **学生加入班级指引**：无班级时的空态文案补充了加入流程（教师在班级中通过邮箱添加成员，学生点击"立即同步"）。

### 全局

- **命令面板实体搜索（Ctrl+K）**：搜索与跳转此前只能搜 6 个页面名；现在输入至少 2 个字符即可同时搜索题目、知识文档、班级与数据库连接，结果按"页面 → 题目 → 知识文档 → 班级 → 连接"分组展示，支持方向键循环选择、Enter 打开，并直接深链到对应题目预览、知识文档、班级视图或已选连接。某类搜索失败时静默隐藏该分组，不影响其他结果。
- **今天页行动引导**：学习队列为空时，"下一步学习"与队列卡片提供"去练习一题"入口。
- **教学空间口径说明**：题库与学情统计下方注明数据为本机作答记录，班级维度学情请前往"班级与云端"，避免误读为全班数据。
- **题库表格可用性**：教学空间题库"状态"列改为"已启用/已停用"状态标签 + 停用/启用切换按钮，不再只显示动作按钮；点击题目标题会展开编辑器并平滑滚动到位；题库与学情列表每页从 8 条提升到 50 条（96 道题由 12 页缩至 2 页）。
- **登录页布局**："← 继续离线学习"从表单上方移至底部"离线学习无需登录"行内。
- **设置保存按钮命名**：设置页顶部按钮更名"保存偏好设置"，与题库区的"保存题库设置"明确区分。
- **练习目录可访问性**：目录按钮补充无障碍名称（题目、类型、难度、状态），读屏不再朗读整行拼接文本。

### 网络与部署

- **桌面启动器强制 IPv4 栈**：sidecar 启动参数加入 `-Djava.net.preferIPv4Stack=true`，缓解 IPv6 路由不完整的网络环境下云端登录与同步全部超时的问题。

## 兼容性说明

- 本次无 IPC 契约变更、无数据库结构变更；命令面板与深链均复用既有 IPC 方法。
- `/knowledge?article=`、`/data?connection=`、`/cloud?class=`、`/practice?exercise=` 为前端路由参数，仅影响桌面端页内跳转。
- 快捷键帮助文案修正随本次安装包生效；sidecar 启动参数变更对云端服务无影响。
