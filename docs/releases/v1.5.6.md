# SQLTeacher v1.5.6

v1.5.6 是桌面显示、AI 工作流、练习易用性与 SQL 执行策略维护版本。它重点修复浅色模式对比度和禁用状态可读性，并统一本地 AI 与网络 AI 的入口。

## 新增与改进

- 重构浅色主题语义颜色和页面覆盖规则，修复列表、表格、表单、空态、禁用按钮及教学页面文字对比度问题。
- 本地 Ollama 与网络 AI 统一到 AI 助手页面；云端教学页不再承担 AI Provider 配置。
- AI SQL 草稿支持 `SELECT`、`INSERT`、`UPDATE`、`DELETE`，Prompt 独立存放并继续经过本地解析、方言和风险审查。
- 学生练习页增加数据集字段摘要、加大的 SQL 编辑区与三级提示。
- 教师任务截止时间改为日期时间选择控件，反馈目标改为可选择的班级、任务和学生，不再要求手填 UUID。
- 设置新增“SQL 安全”页和本机无限模式。无限模式默认关闭，启用前会明确警告破坏性操作风险。
- 标准模式下，学生运行禁用 SQL 时会提示无限模式入口；启用后，通用 SQL 和隔离练习会跳过应用层禁止、只读及二次确认限制。

## 安全边界

- AI 仍只能生成待审查草稿，不能自动执行 SQL。
- 无限模式仅绕过 SQLTeacher 应用层检查，不能绕过数据库账号权限、JDBC 驱动能力或操作系统保护。
- 无限模式选择保存在当前设备的 `app-data/sql-safety.properties`，不进入安装包或版本库。
- 正式客户端继续使用 `https://api.sqlteacher.tech`，非回环 HTTP 地址仍会被拒绝。

## 已知限制

- JavaFX 界面视觉验收由发布负责人在安装包上完成，本次自动门禁不启动桌面 UI。
- JDBC 驱动是否接受多语句仍由对应数据库与驱动配置决定。
