# SQLTeacher v3.4.3

> 发布日期：2026-09-15（本地打包验证版本）
>
> v3.4.3 是"知识与数据体验"版本，交付 [v3.4.3 知识检索重做、连接傻瓜化与官方知识库分发计划](../plans/2026-09-15-v3.4.3-plan.md)。亮点：课程知识页按知识库状态三态重做并与课程活动从数据层彻底切开、数据库连接傻瓜化（常用类型一键选 + 端口自动填 + 高级项折叠）、表结构两级折叠并新增索引展示、官方《数据库系统概念》知识库随安装包分发并支持云端/离线更新（含插图渲染）。SQL 安全边界未改动。
>
> 测试执行：本地全量 `mvn test` + `npm test`。

## 主要变化

### 检索课程知识重做（KSR-1、KSR-2）

- **知识页与课程活动彻底切开**：新增 `knowledge.overview` 端点作为知识页唯一数据源（文章列表、文章数、官方知识库状态、索引状态），课程树改由文章自身的 `courseTitle/sectionTitle` 归组。知识页不再消费 `course.workspace`（其 courses 混有课程活动），从数据层杜绝"知识/活动"混淆。课程活动入口保持不动（仍在「练习与实验」）。
- **按知识库状态三态渲染**：
  - **空库**（无文章且无官方知识库）：隐藏检索框与知识助教，改为引导卡——教师可「检查官方知识库」下载或「导入知识库文件…」，学生提示联系教师；不再对着空索引显示"无匹配结果"。
  - **索引未就绪**（有文章且待索引任务 > 0）：顶部显示索引进度与降级说明（全文检索已可用，语义检索待本地向量模型就绪），检索框保持可用。
  - **正常**：维持既有检索/课程树/知识助教体验。

### 数据库连接傻瓜化与表结构折叠（CXN-1…3）

- **连接表单单页智能默认**：数据库类型改为「常用类型」（MySQL / SQLite / PostgreSQL）一键 chip + 「更多类型」下拉收纳其余 11 种方言与通用 JDBC；选中类型后只渲染该类型必要字段，服务器型自动填默认端口，文件型只留「数据库文件」并新增「新建空库…」快捷；通用 JDBC/驱动 JAR/连接 ID/只读/启用等低频项收进「高级选项」折叠；复制/设为当前/删除收进「更多操作」折叠。「测试通过才能保存」的安全闸与凭据内存暂存机制不变。
- **表结构两级折叠 + 索引展示**：侧栏表结构外包一层可折叠「表结构（共 N 张表）」整体块，每张表展开后分区显示「列」（名称/类型/PK/NOT NULL）与「索引」（名称/列清单/唯一性），无索引显示「无」。后端元数据服务新增 `DatabaseMetaData.getIndexInfo` 读取（过滤统计型与 SQLite 内部 autoindex），单表索引读取失败降级为空列表、不影响整棵结构树。

### 官方课程知识库分发（OKB-1…7）

- **随安装包分发**：官方《数据库系统概念》知识库（8 篇章节 Markdown + 117 张插图，约 21 MiB）由 `packaging/build-knowledge-bundle.ps1` 打成 bundle zip，随 NSIS 安装器与便携包落地到 `knowledge\` 资源目录；首次启动后台自动导入（source=builtin），不阻塞界面，已安装更新版本时不回退。
- **云端与离线双更新渠道**：云端新增无认证端点 `GET /api/v1/app/knowledge-bundle-manifest` 与 `GET /api/v1/app/knowledge-bundle`（env 配置，缺省明确 404）；桌面「官方知识库」面板可「检查更新」，云端版本更新时「下载并安装」（下载流式落盘 + sha256 与大小双校验后导入，source=cloud），也可「导入知识库文件…」离线导入本地 zip（source=manual）。
- **插图渲染**：bundle 文档中的 Obsidian `![[图片]]` 引用在构建期改写为标准 Markdown 图片，导入时图片落 `app-data\knowledge-assets\<bundleId>\`；阅读时经 `knowledge.article.asset` 端点按文章所属 bundle 作用域安全读取（路径规范化防目录穿越、仅图片类型），以 data URL 渲染，缺失/失败显示占位不破图。
- **整包替换、用户文档零触碰**：官方文档以 `bundle_id/bundle_doc_id` 标记（app 库 Migration 24），更新按文档 id 整包替换并置为 PUBLISHED；用户自己导入的文档（bundle 标记为 NULL）永不被覆盖。导入采用"校验全部通过后再写入、旧文档显式删除后重导"的 owner 无关策略，失败不落半状态。

## 兼容性说明

- **桌面数据库**：app 库 schema 升至 **Migration 24**（新增 `knowledge_bundle_state` 表，`course_knowledge_articles` 加 `bundle_id`/`bundle_doc_id` 两列，均 additive、可回滚、拒绝未来版本）；demo.db 不变。
- **云端**：无 schema 变更；知识库端点为静态文件下发，需配置 `SQLTEACHER_KNOWLEDGE_BUNDLE_MANIFEST` 与 `SQLTEACHER_KNOWLEDGE_BUNDLE_FILE` 两个环境变量后才对外提供（未配置时返回明确 404，不影响其它端点）。云端部署属生产操作，另行授权执行。
- **IPC**：契约版本不变（3.0-v1），additive 新增 5 个方法（`knowledge.overview`、`knowledge.article.asset`、`knowledge.bundle.import`、`knowledge.bundle.check`、`knowledge.bundle.download`），共 **149** 个。
- **安装器**：安装目录新增 `knowledge\`（官方知识库 zip）；其余流程与 v3.4.2 一致。
- **内容授权**：随包与云端分发的教材衍生内容已由用户确认获得授权（见计划第 7 节确认记录）。

## 已知限制与后续积压

- 云端知识库端点的生产部署与公网冒烟在发布后另行授权执行，本版本地验证不含公网下载。
- bundle 更新为整包替换（非增量），包体约 21 MiB；多官方知识库、增量更新、bundle 内容 Ed25519 签名、云端 Qdrant 侧共享检索列入后续版本。
