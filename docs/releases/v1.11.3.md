# SQLTeacher v1.11.3

v1.11.3 完整落地 v1.11 计划的全部缺口：完整英文界面、全部桌面功能接线、原生通知、安装修复、镜像开关与分阶段发布工具。

## 主要变化

- **完整英文界面**：全部 18 个 FXML 与 19 个控制器的硬编码文案迁移至 ResourceBundle；中英文键集完全一致（键完整性门禁），简体中文界面残留归零。
- **设置页新功能**（更新与支持 → 问题反馈/账号安全）：
  - 反馈截图附件：选择单张 PNG/JPEG，发送前清除 EXIF/GPS 元数据并预览。
  - 反馈撤回与本人反馈元数据导出。
  - 发送密码重置邮件（防枚举）、活跃会话列表与按设备撤销、云端数据导出、账号注销（7 天冷静期可取消）。
- **Windows 原生通知**：默认关闭，显式启用后发送白名单短语系统通知；失败静默降级应用内通知。
- **安装修复入口**：检测正式程序文件缺失/篡改并给出修复指引（不下载任意文件、不改用户数据）。
- **受控镜像开关**：官方源不可达时可启用白名单镜像下载（默认关闭）。
- **分阶段发布工具**：`UpdateManifestTool set-rollout/pause` 可调整发布百分比或紧急暂停并重新签名；Release 清单默认全量（100%）。

## 兼容性

- 支持从 v1.10.1、v1.11.0~v1.11.2 原位升级，保留 `app-data` 用户数据。
- Cloud API 版本保持 `1.11`，最低兼容客户端为 1.9.0；本版本为纯桌面客户端改动，生产 Cloud 无需升级。
- 需要 Windows x64；正式安装包和便携 ZIP 均自带 Java 21 运行时。
