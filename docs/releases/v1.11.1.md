# SQLTeacher v1.11.1

v1.11.1 是设置页加载修复补丁版本，修复 v1.11.0 在 FXML 本地化迁移后「设置」页无法打开的问题。

## 主要变化

- 修复：`SettingsController.load()` 创建 `FXMLLoader` 时未注入 ResourceBundle，而 `general-software.fxml` 已使用 `%key` 本地化文案，导致 JavaFX 加载时抛错、设置页无法打开。
- 修复范围：为全部 `FXMLLoader`（`SettingsController`、`MainWindowController` 11 处、`SqlRiskConfirmDialogUtil`）统一注入 `AppI18n.bundle()`，消除同类隐患。
- 新增回归门禁 `FxmlBundleInjectionTest`：静态扫描源码，任何加载含 `%key` 的 FXML 的 `FXMLLoader` 若未注入 bundle 则测试失败，防止再次回归。

## 兼容性

- 支持从 v1.10.1、v1.11.0 正式安装版原位升级，保留 `app-data` 用户数据。
- Cloud API 版本保持 `1.11`，最低兼容客户端为 1.9.0。
- 生产 Cloud 已同步升级至 1.11.1（备份、原子切换、健康与能力验证通过）。
- 需要 Windows x64；正式安装包和便携 ZIP 均自带 Java 21 运行时。
