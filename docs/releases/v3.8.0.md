## 主要变化

### 账号闭环（本版核心）

- **真实邮件通道**：云端新增 SMTP 发信（`org.eclipse.angus:angus-mail`，支持 587/STARTTLS
  与 465/隐式 SSL,环境变量 `SQLTEACHER_CLOUD_SMTP_*` 配置），未配置时自动降级原有文件
  outbox；发送异步化,失败不影响接口防枚举语义,日志只记失败类别与收件人域。生产已配置
  阿里云邮件推送并经真实收信验证。
- **验证码化密码找回**：找回密码改为两步——输注册邮箱 → 收 **6 位数字验证码**（15 分钟有效、
  5 次尝试上限、新码自动作废旧码）→ 输码并设置新密码,成功后所有会话退出。重置**不再要求
  邮箱已验证**（持箱收码即凭证,消除"注册未验证邮箱无法找回"死角）；任何失败统一文案,
  不泄露账号是否存在。
- **邮箱绑定/换绑**：「班级与云端 → 账号安全与数据治理 → 邮箱验证」向新邮箱发码,验证后
  替换账号邮箱并标记已验证;目标邮箱已被其他账号占用时明确拒绝且原绑定不变。这是找回
  密码可用的前置,也是换绑入口。
- **显示名称自助修改**：账号安全区新增显示名编辑,保存后本地身份立即刷新（会话自动重签）,
  班级花名册与学情画像同步呈现。
- **设备会话标识**：登录/注册/刷新上报设备名（取主机名,服务端净化截断 64 字符,缺省回落
  "桌面设备"）,「登录会话」列表据此区分多设备。
- **本地记录并入账号**：检测到未登录期间产生的学习事件与 SQL 历史时,同步偏好卡出示一次性
  提示,确认"并入我的账号"后才归属并参与云端同步;不并入则永留本机,legacy NULL 行不受影响。

### 教师升级码（决策点 1,方案 B）

- 管理员经 REST 端点签发**一次性 8 位教师升级码**（明文仅签发响应出现一次,库中仅存
  SHA-256 哈希;默认 30 天有效、可撤销,签发/撤销/兑换全部落 `admin_audit`,云端迁移 v11）。
- 教师在「账号安全与数据治理 → 教师身份」输码兑换,会话即时重签,教师功能**无需重新登录**
  即可用;兑换限流 5 次/账号/时,错误统一文案且失败不消耗码,已是教师的账号拒绝兑换。
- 签发操作文档见云端部署指南（guide/12）,教师侧说明见教师手册（guide/09）。

### 界面一致性（UIX）

- **确认对话框统一**：新增 `ConfirmDialog` 组件（危险操作红色确认、回显操作对象）,替换
  全部 5 处原生 `window.confirm`（知识文档删除、AI 供应商删除、重置班级码、AI 起草覆盖、
  重复导入确认）,Esc/点外关闭与焦点管理沿用无障碍 Dialog。
- **真实图标系统**：引入 `lucide-react`,侧边栏导航、设置面板与通知铃的 Unicode 字符全部
  替换为统一规格（18px、1.75 描边）的中性线性图标。
- **交互原语收口**：Button 忙碌态保留原文案 + 内联 spinner（不再整体替换为"处理中…",宽度
  不跳动、下载进度直接可见）;加载占位合并为 `shared/ui` 单一 `Loading` 实现;空状态统一
  `EmptyState`（新增 compact 变体）;错误兜底卡内联样式归位;新增 radius/spacing 设计 token
  并在设计系统样式 adoption。

### 云端服务端（已先行部署）

- 云端 schema 迁移 v10/v11 随本版部署生产（3.4.3 → 3.8.0 服务端跨度一次补齐）,含 v3.7.0
  的教师明细/班级总览/提交载荷/上传限流/180 天保留等服务端能力与本次账号闭环端点。
- 新端点：`PATCH /api/v1/account/profile`、`POST /api/v1/account/role-codes/redeem`、
  管理端 `POST/GET /api/v1/admin/role-codes`、`POST /api/v1/admin/role-codes/{hash}/revoke`;
  既有 auth/account 响应 additive 演进,旧客户端兼容。

## 升级与兼容

- 桌面端 3.7.0 及以后可经应用内更新直接升级;学习数据本地 schema 无新增迁移。
- 生产云端已先行部署并验证（迁移、新端点、SMTP 真实发信）;SMTP 凭据仅经服务器环境变量
  注入,未配置的部署自动降级文件 outbox（功能不报错,但公网用户收不到验证码邮件）。
- 安全边界不变：PBKDF2 凭据存储、不透明令牌、限流与审计全量沿用;验证码哈希存储、限时限次、
  统一错误文案;AI 与 SQL 执行安全策略零改动。
