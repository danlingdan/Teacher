# SQLTeacher v3.0.0

> 发布日期:2026-09-05
>
> 全新 Tauri/React 桌面端,替代自 v1.0 以来的 JavaFX 界面。本版本为正式版(GA)。

## 主要变化

- **全新桌面体验**:Tauri 2 + React 19 成为唯一桌面端,七个学习与教学工作区通过受限、版本化 IPC 使用 Java 确定性核心;启动不再出现额外控制台窗口,支持单实例激活与窗口状态恢复。
- **完整的 2.3 能力对齐**:课程隔离、两阶段练习、Monaco 多语言高亮/补全、本地题库与知识管理全部回归;云端课程协作、任务提交闭环、教师反馈、掌握度、教学通知、成果档案与课程包均已接入。
- **练习更省心**:作答按题自动保存草稿、随链接恢复;运行结果直接以表格展示;重置等破坏性操作需要确认。
- **教师工作流更顺**:班级任务一步"创建并发布",状态变更需要确认;所有操作成败均有即时提示,不再静默失败。
- **界面语言**:中英文界面、浅色/深色/跟随系统主题、字体、密度、高对比度、减少动态效果、`Ctrl+K` 快速导航与数字快捷键全部保留;界面文案全面精简为简洁的产品语言。
- **独立账号页**:登录、注册、密码重置统一入口,同时保留无需账号的离线学习路径;Windows 原生通知只发送固定白名单短语,不含学生信息、SQL 或附件内容。
- **稳定性与性能**:修复学习事件时间戳、SQLite 并发写、更新下载重定向、Sidecar 崩溃恢复等问题;云同步改为增量上传;首页学习诊断约 20ms,IPC 往返 p95 约 0.5ms。
- **安全边界不变**:SQL 风险分析、确认、超时、结果限制和审计仍由 Java 强制执行,AI 不能直接执行 SQL;数据库连接、备份恢复、组件安装、账号安全均接入真实 Java 服务,不使用 mock。
- **安装与升级更可靠**:3.0 安装到 `%ProgramFiles%\SQLTeacher`,与用户数据目录分离;从 v1.0–v2.3 的 WiX 版本或 3.0 Alpha/Beta 升级时自动卸载旧程序并保留用户数据,不再安装 JavaFX。

## 下载与校验

从本 Release 下载 `SQLTeacher-3.0.0.exe`(推荐)或 `SQLTeacher-3.0.0-windows-x64.zip` 便携版,
并使用 Release 资产中的 `SHA256SUMS.txt` 校验文件完整性。程序自带 Java 25 运行时,安装器需要管理员权限。

## 升级说明

- 从 v1.0 至 v2.3 升级:安装器会先卸载旧 WiX 程序(含 JavaFX runtime 与旧快捷方式),保留原用户数据;
  旧版卸载失败或被取消时,3.0 安装会停止以保护数据。
- 从 3.0 Alpha/Beta 升级:安装器会先移除旧的当前用户安装,再进行机器级安装。
- 应用内更新:已安装 3.0 正式版后,设置 → 更新会通过签名更新清单检查新版本。
