# SQLTeacher v3.0.0

> 状态：正式版本地候选，尚未提交、推送、打标签或创建 GitHub Release。

## 主要变化

- Tauri 2 + React 19 成为唯一桌面端，JavaFX、FXML、旧控制器/资源和旧打包链已从现役代码移除。
- Windows 主程序使用 GUI 子系统，Java sidecar 以 `CREATE_NO_WINDOW` 启动，日常启动不再出现额外控制台窗口。
- 七个学习与教学工作区通过受限、版本化 IPC 使用 Java 确定性核心；正式导航中没有迁移状态、设计系统或其他测试页面。
- 对齐 2.3 的课程隔离、活动预览确认、两阶段练习、Monaco 多语言高亮/补全、本地题库与知识管理流程；云端课程协作、任务提交闭环、反馈/掌握度/教学通知、成果档案和课程包已接入 3.0 IPC 与工作台。正式发布前仍需使用真实教师、学生账号完成生产云端贯通验收。
- 恢复中英文界面、浅色/深色/跟随系统、字体、密度、高对比度、减少动态效果、`Ctrl+K` 快速导航和数字快捷键。
- 重整桌面视觉层级与设置中心：导航、卡片和表单采用更清晰的工作台布局；启动和进入设置不再自动执行 Cloud、工具链或磁盘探测，环境与存储信息改为按需加载。
- 新增独立账号页，统一登录、注册和密码重置入口，同时保留无需账号的离线学习路径；桌面 E2E 会截图巡检全部学生工作区及受角色保护的教学空间。
- 支持单实例激活、窗口状态恢复和 Windows 原生通知；原生通知只允许固定白名单短语，不发送学生信息、SQL、Prompt 或附件内容。
- SQL 风险分析、确认、超时、结果限制和审计仍由 Java 强制执行，AI 不能直接执行 SQL。
- 数据库连接、备份恢复、组件安装与取消、账号安全、数据导出/注销、知识导入修订和练习提示/重置均接入真实 Java 服务，不使用生产 mock。
- Windows 交付统一为 NSIS 安装包和便携 ZIP，随附 SHA-256 校验和及 Java/UI CycloneDX SBOM。
- 修复跨安装器升级：3.0 使用与历史 WiX 包一致的发布者身份，安装前卸载旧 WiX 或 3.0 Alpha/Beta 当前用户 NSIS 程序、JavaFX runtime 和旧快捷方式；程序改装到 `%ProgramFiles%\SQLTeacher`，不再与 `%LOCALAPPDATA%\SQLTeacher` 用户数据目录重叠。
- 练习作答按题自动保存草稿并随链接恢复，重置与破坏性切换需确认，运行结果直接以表格展示；发布任务可一步"创建并发布"，状态变更需确认。
- 全局操作反馈（toast）、路由级错误兜底与 Sidecar 崩溃后自动恢复，操作成败均有即时提示，不再出现静默失败。
- 修复学习事件时间戳格式、SQLite 并发写、更新下载重定向、IPC 错误码吞没等问题；云同步改为增量上传，知识检索与首页诊断热路径显著提速（首页摘要 54ms → 21ms）。

## 安装与升级

正式发布后，从 GitHub Release 下载 `SQLTeacher-3.0.0.exe` 或
`SQLTeacher-3.0.0-windows-x64.zip`，并使用同一 Release 的 `SHA256SUMS.txt` 校验。
程序自带 Java 25 runtime；安装器需要管理员权限。从 v1.0 至 v2.3 的 WiX 版本升级时会先卸载旧程序，
继续兼容并保留原用户数据，且不会启动或安装 JavaFX。旧版卸载失败或被取消时，3.0 安装会停止。

当前本地候选的正式 JAR 和便携 ZIP 已逐项扫描，未包含 JavaFX、FXML、生产 mock 或测试页面资源；
包装脚本会先执行干净 Maven 构建，并在复制 sidecar JAR 时再次执行同类门禁。
