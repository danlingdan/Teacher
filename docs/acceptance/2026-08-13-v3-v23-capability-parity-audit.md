# SQLTeacher 3.0 对照旧版能力审计

> 审计日期：2026-08-13  
> 结论：**当前 3.0 不能判定为完整达到 2.3 及更早版本的全部能力。** 本地学习、SQL 安全、题库、知识和基础班级管理已接通；课程协作、云端任务提交闭环、反馈/掌握度/站内通知、成果档案与课程包仍有桌面端入口或 IPC 缺口。

## 对照范围与方法

本次直接以旧版现行文档作为能力基线，而不是以 3.0 页面是否存在作为完成依据：

- `docs/guide/08-user-manual.md`、`09-teacher-manual.md`；
- `docs/guide/13-v1.4-course-collaboration.md` 至 `19-beta-learning-contracts.md`；
- `docs/releases/v2.3.0.md` 的 UI-001 至 UI-009；
- 当前 React 路由、IPC v1 清单、`DefaultLocalAppApi`、应用服务和 Cloud API 客户端。

“完成”要求页面、IPC、Java 服务与权限链都存在；只有服务端模型或只有页面展示不算完成。涉及真实云端的操作还需要候选包和测试账号复验，静态代码审计不能替代生产验证。

## 本轮已经修复

- 知识页删除不可操作的菱形装饰，重做空状态与助教输入区，并为文档列表分页；
- 设置帮助主题中文化；顶部增加始终可见的通知中心；
- 云端同步状态、任务状态与时间显示中文化，异常 1970 时间改为“时间未知”；
- 账号治理拆分为密码、会话、数据导出与删除三个区域；
- 数据库连接管理面板加宽、表单改为单列，避免窄栏挤压；
- 练习目录与教师题库增加搜索和分页，题目编辑紧邻题库；
- 班级任务自动加载，学生可从已发布任务进入对应练习，教师学情操作不再暴露给学生。

## 发布阻断项

若 3.0 的正式目标是“功能实现度和便利度不低于 2.3”，以下五项必须在正式发布前补齐并做角色 E2E：

1. 班级任务上下文进入练习、提交写入本地 outbox、同步到服务器并回显提交确认；
2. 共享课程/章节/知识点、版本化题目和冻结任务快照；
3. 教师反馈、学生反馈查看、掌握度与练习建议；
4. 四类教学云通知的同步、账号隔离缓存、已读和顶部提示；
5. 成果档案与安全课程包工作流，以及旧教师学情筛选/导出入口。

在这些阻断项完成前，发布说明不得继续使用“所有旧版功能均已完整迁移”或同义表述。
