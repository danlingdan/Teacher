## 发布边界

正式 Release 必须为非 draft、非 prerelease 并标记 Latest。生产更新必须先在线备份并验证完整性，以原 `2.0.0-alpha.7` release 和发布前备份为回滚点；Java API 继续只监听 `127.0.0.1:18080`。

GA 没有再次完成独立 Windows 10/11、100%/125%/150% 的人工设备矩阵；本轮使用完整自动化、Windows 打包、app-image 冒烟和既有 RC 证据完成发布。Cloud 也未经过独立预生产环境，而是在用户明确授权后，以生产在线备份和自动回滚脚本直接更新；这些偏差不应在后续版本中被当作已补齐的人工证据。
