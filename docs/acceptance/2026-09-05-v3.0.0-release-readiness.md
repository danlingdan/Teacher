## 本轮范围(2026-08-24 基线之后的提交)

- `9563f5d` fix(infrastructure):回环 HTTP 客户端锁定 HTTP/1.1 并为云端请求加 30 秒超时(修复 JDK HttpClient h2c POST 死锁)。
- `7a23fe3` style(ui):设计令牌统一,组件库获得完整深色主题支持。
- `4a0e464` feat(ui):交互重整——练习草稿按题持久化与 URL 恢复、全局操作 toast、教师创建即发布与状态变更确认、结果表格、设置防丢失、知识 AI 上下文。
- `800ba21` fix(infrastructure):学习事件时间戳统一 ISO(修复诊断链路崩溃)、SQLite busy_timeout/WAL 与快照事务、更新下载跟随重定向、sidecar 崩溃后可恢复、IPC 协议服务器加固。
- `da0d764` perf(infrastructure):云同步上传水位消除全量重传、Lucene 常驻 writer/SearcherManager、评价归一化外提、惰性 delegate 缓存、SQL 结果缓存上限。
- `c0a9fa8` perf(ui):输入防抖、结果表 memo、Monaco provider 只注册一次、i18n 单遍正则、路由级 ErrorBoundary。
