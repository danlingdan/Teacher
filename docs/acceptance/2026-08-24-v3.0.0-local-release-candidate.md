## 启动与安装边界

`packaging/test-v3-no-console.ps1` 通过：Tauri 主窗口可启动，Java sidecar 窗口句柄为 0，退出后无遗留进程。生成的 NSIS 脚本也通过包装脚本中的 per-machine、Program Files、旧 WiX 和 3.0 Alpha/Beta 卸载合同检查。

本轮没有直接运行 NSIS 安装/卸载，以免改变当前机器的已安装应用状态。以下门禁仍需在正式发布前完成：

1. 干净 Windows 10/11 上的全新安装、启动、卸载和数据保留检查。
2. 从真实 v2.3、3.0 Alpha/Beta 安装状态升级，核对旧程序、快捷方式和注册表无残留。
3. 使用专用教师与学生账号完成生产云端班级、任务、反馈、掌握度和通知贯通。
4. 使用发布密钥生成签名更新清单，并在获准后执行标签、GitHub Actions 与公开 Release 验证。
