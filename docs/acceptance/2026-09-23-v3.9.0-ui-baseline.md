## G1 当前设计选择

保留七个主入口；本轮先修对象直达，不在缺少任务测试时重排导航。首条流为：

```text
作业/反馈通知（ASSIGNMENT id）→ /cloud?assignment=...[&view=feedback]
→ 当前账号可见班级的 cloud.assignments 查找 → 选中班级与任务
→ cloud.feedback.list → 聚焦反馈标题
```

无匹配任务、无权限或请求失败分别显示可恢复状态；URL 只负责定位，Java/云端服务继续鉴权。
该流程不改变 SQL 执行、学习判分或教师反馈写入规则。
