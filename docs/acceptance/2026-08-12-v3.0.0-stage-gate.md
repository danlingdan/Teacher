## 无控制台边界

- Tauri 正式入口声明 Windows GUI 子系统。
- Rust 启动 Java sidecar 时设置 `CREATE_NO_WINDOW`，且不继承可见 stderr 控制台。
- IPC stdin/stdout 管道保持不变，不影响请求、响应或退出回收。
- 发布工作流在打包后运行实际进程烟测，避免未来版本重新出现黑色控制台窗口。
- 单实例插件会在第二次启动时激活已有窗口；窗口状态插件保存并恢复正常窗口位置和尺寸。

## 安装升级隔离

- v1.0 至 v2.3 的正式 Windows 包统一使用产品名 `SQLTeacher`、发布者 `SQLTeacher Project`、程序目录
  `%LOCALAPPDATA%\SQLTeacher-App`；3.0 生成的 NSIS 脚本使用相同产品身份识别并调用其 WiX 卸载项。
- 3.0 使用 `perMachine` 模式安装到 `%ProgramFiles%\SQLTeacher`，不会再与 `%LOCALAPPDATA%\SQLTeacher`
  用户数据库、账号和设置目录重叠。
- 包装脚本会直接检查最终渲染的 NSIS 脚本；发布者、安装模式、Program Files 路径、WiX 匹配或卸载调用任一缺失都会终止打包。
- 安装前钩子只接受 HKCU 中产品名 `SQLTeacher 3 Alpha`、`SQLTeacher 3 Beta` 或 `SQLTeacher`，且发布者为
  历史值 `sqlteacher` 或 `SQLTeacher Project` 的 3.0 预发布 NSIS 登记项，并调用其已登记卸载器；钩子不包含
  目录递归删除或注册表强删逻辑。
- 本轮未直接改动当前 Windows 的已安装应用；旧程序目录、注册表项和快捷方式的真实清理仍需在干净 Windows
  升级矩阵中以 v2.3 安装包执行后确认。
