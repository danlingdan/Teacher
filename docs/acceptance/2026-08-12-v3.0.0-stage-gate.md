## 无控制台边界

- Tauri 正式入口声明 Windows GUI 子系统。
- Rust 启动 Java sidecar 时设置 `CREATE_NO_WINDOW`，且不继承可见 stderr 控制台。
- IPC stdin/stdout 管道保持不变，不影响请求、响应或退出回收。
- 发布工作流在打包后运行实际进程烟测，避免未来版本重新出现黑色控制台窗口。
- 单实例插件会在第二次启动时激活已有窗口；窗口状态插件保存并恢复正常窗口位置和尺寸。

## 2.3 功能与便利性对齐

- 首页诊断、课程知识、两阶段练习、SQL 工作台、非 SQL 活动、教师题库/学情和云端班级均通过真实桌面 E2E 或 Java 服务测试。
- 课程活动先选课程再选活动，确认预览后才进入交互；访客不显示教师空间，服务端仍独立校验写权限。
- 中英文切换、主题、字体、密度、高对比度、减少动态效果、快速导航、单实例、窗口状态和原生通知均保留。
- 正式源树和候选制品均不含 JavaFX/FXML；生产 Java 源树不含 mock 服务，设计系统、迁移状态和知识样例测试入口均已删除。
- 包装脚本使用 `mvn clean`，并在生成 sidecar 时拒绝任何旧桌面或测试条目，防止增量构建残留重新进入正式包。
