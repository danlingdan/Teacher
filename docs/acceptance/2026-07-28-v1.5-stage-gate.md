```powershell
mvn -q "-Dtest=DesktopAccessProfileTest,UiPreferencesServiceTest,DesktopFxmlResourceTest,DesktopVisualResourceTest" test
```

结果：通过。覆盖角色页面/设置项权限、主题偏好持久化与损坏回退、Windows 主题解析、FXML/CSS 资源和 emoji 替换。

结果：应用窗口成功显示且无启动/FXML 异常。桌面走查覆盖访客侧栏、设置入口、深色/浅色即时切换、主题下拉弹层、登录页、设置页以及版本/维护页；访客可查看版本信息，但备份、恢复和刷新操作均禁用并显示原因。走查期间发现并修复持久会话启动后窗口未显示、深色下拉弹层低对比度和浅色登录/设置页级联冲突。
