# V13-04 按任务学情与一致性导出

## 统一筛选口径

任务学情页面 API 与 CSV 导出共用 `AssignmentAnalyticsFilter`：

- 学生状态：全部、未提交、已提交、已通过、未通过；
- 服务端提交时间起止范围；
- 页码和每页数量，每页限制 1 至 200 条。

时间范围只作用于正式提交的服务端 `submittedAt`，不信任客户端时间。导出忽略分页但保留相同的状态和时间筛选，因此页面筛选结果与 CSV 口径一致。

## 统计内容

- 班级学生数；
- 已提交学生数和完成率；
- 已通过学生数和通过率；
- 总尝试次数；
- 常见稳定错误码及次数；
- 学生状态、尝试数、通过次数和最后提交时间。

完成率按已提交学生数除以班级学生数计算；通过率按已通过学生数除以已提交学生数计算，分母为零时返回 0。

## 权限、导出与审计

- 仅本班教师和管理员可以查询或导出；
- 学生和其他班级教师返回 403；
- CSV 使用 UTF-8 BOM，并继续防止 `=+-@` 公式注入；
- `export_audit` 记录任务 ID、导出类型、筛选摘要、行数、操作者和时间，不记录令牌、SQL 或凭据。

## 数据升级

既有 `export_audit` 原位增加：

- `assignment_id`；
- `export_type`；
- `filter_summary`。

原有班级级导出继续使用默认类型，旧记录不丢失。
