# v1.3 桌面教学与管理员操作面板

云端教学页现已覆盖 v1.3 已交付 API 的主要日常操作，不要求教师或管理员使用命令行调用接口。

## 教师操作

- 创建任务时填写本地题目 ID、标题、说明和可选截止时间。
- 保存草稿，或通过“草稿 → 发布”状态转换发布任务。
- 复制所选任务为新草稿，避免重复录入。
- 编辑任务标题、说明和截止时间；状态更新继续携带版本号，冲突不静默覆盖。
- 查看所选任务的学生数、提交数、通过数、尝试次数、完成率和通过率。
- 导出与当前任务一致的 UTF-8 CSV；导出仍由服务端做班级授权和审计。

## 管理员操作

- 查看非敏感健康摘要、账号列表和最近 50 条结构化审计。
- 使用受控原因码禁用/恢复账号或撤销全部会话。
- 选择数据类别和截止时间预览清理影响，填写外部备份引用后确认执行。
- 恢复当前界面最近完成的清理作业。

管理员清理确认令牌只保存在当前控制器内存，不显示在界面、不写入日志或本地数据库。服务端权限、最后管理员保护、最短保留期、自动安全快照和影响范围复核仍是最终安全边界。
