# v1.7 学习诊断闭环实施记录

> 日期：2026-07-30
> 目标版本：v1.7.0
> 状态：功能、自动化与 Windows 本地产物验证完成，等待远端发布

## 已完成

- 新增 learning 应用契约：掌握快照、证据、原因码、学习行动、学生队列和教师干预状态。
- 实现固定 `v1.7.0-r1` 策略：30 天窗口、每知识点最近 20 次有效提交、最少 3 条证据、四档掌握状态。
- 新增 schema 7：会话所有者、可重算掌握快照、学习行动状态和教师干预状态。
- 首页接入学生学习队列；本机练习、云端任务和未读反馈稳定排序、去重并限制为 7 项。
- 学情看板接入授权班级教师干预队列、处理状态、工作区入口和字段白名单 CSV。
- 云端失败采用全有或全无合并：失败时只返回本机队列，不展示不完整云端数据。
- 学习数据清理同步删除派生诊断与行动状态，不影响题库、连接配置和知识文档。

## 安全边界

- 诊断服务不依赖 JavaFX、HTTP 或 AI；所有事实计算均可离线重放。
- AI 不修改掌握度、原因码、优先级或干预状态；既有反馈 AI 仍只生成待审核草稿。
- 教师候选仅通过现有授权班级 API 读取，未新增客户端越权查询通道。
- CSV 转义 `= + - @` 前缀，且只导出聚合字段和证据摘要。

## P1 取舍

本次完成 P0 闭环与 P1 的脱敏导出、键盘可达入口和主题语义样式。学习目标、诊断 AI 个性化措辞和教师批量发布未进入正式版：它们不影响核心闭环，并分别存在诱导性目标、外发隐私和批量误操作风险。v1.7.0 保留确定性模板及既有逐项审核反馈流程，不以未完成占位控件伪装已交付能力。
